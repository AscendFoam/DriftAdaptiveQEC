## 4. Related Work 写作边界

| 主题组 | 可以写 | 不能写 |
| --- | --- | --- |
| GKP analog / soft information | analog syndrome / soft information 已有成熟路线，本项目是在 physical-layer affine calibration 上定位 | 本项目首次使用 analog GKP syndrome |
| GKP logical-channel / fidelity analysis | logical-channel probability、infidelity、loss/amplification performance 是外部 fidelity 参照；当前稿件只能承认未测 | 当前 `final_ler` proxy 已经等价于 logical-channel fidelity 或 process infidelity |
| Adaptive / calibration decoders | syndrome statistics 和 decoder prior/noise calibration 已有相关工作，本项目把更新对象限制为 GKP affine fast-path parameters | 本项目开创所有 adaptive decoder 思路 |
| Learned QEC decoders | learned modules 可服务 QEC decoding；本项目把 learned branch 放在 slow calibration loop | 本项目是 full neural decoder 或 universal learned decoder |
| FPGA / real-time decoders | 真实硬件论文必须报告 latency、resource、throughput、closed-loop 与 hardware provenance | 当前项目已有 real-time FPGA result |
