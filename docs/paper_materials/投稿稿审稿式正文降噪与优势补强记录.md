## 主要改写

1. 正文和附录语言降噪：
   - 删除 planned hardware figure 宏和硬件占位图调用；
   - 把结论之后的 Data/Code、Validation、Source-Data、Risk、Reference 等内容明确转为 appendix；
   - 清理 `draft`、`project results`、`project terms`、`placeholder`、任务号和 review verdict 类内部语言。

2. 理论有效域补强：
   - 在 approximate GKP syndrome model 中补入 full finite-energy/logical-channel simulation 与当前 effective wrapped-displacement model 的区别；
   - 明确 affine calibration 成立条件：branch error 概率小、条件残差近似单峰、漂移慢于 commit window；
   - 明确失效模式：posterior split、半晶格边界附近 finite-energy tails、漂移快于更新窗口。

3. 指标解释补强：
   - 把 `final_ler` 写成 half-lattice residual-boundary crossing proxy；
   - 明确它不能外推为完整 logical-channel tomography、outer-code performance、真实硬件 logical error rate 或置信区间。

4. 优势边界补强：
   - 外部比较表只作为 metric / target context，不作为本研究结果；
   - 当前优势限定为 affine fast path 的架构动机：低维 `(K,b)` calibration surface、每 shot clipped matrix-vector correction、较低 arithmetic / state footprint；
   - 低延迟、低成本和硬件友好仍是待 synthesis / board measurement 验证的优势假设。

5. statcalib 层级降权：
   - 把 statistical-calibration rows 写成 supplementary estimator-protocol observation；
   - 明确它不属于主 ranking protocol，不是成熟 comparator，不替代 neural hybrid residual branch；
   - 成熟比较仍需要预声明统一协议、固定 candidate generation / selection / repeat / uncertainty reporting。

6. 结果措辞收敛：
   - 把主结果写成 “hybrid residual branch ranks lowest by mean `final_ler` under the current two-repeat software-HIL protocol”；
   - 避免写成 statistically significant improvement、SOTA logical error rate、hardware latency/resource result 或 deployment closure。
