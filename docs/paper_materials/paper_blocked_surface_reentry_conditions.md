# T89 Blocked Surface Reentry Conditions

本表只回答一件事：哪些 blocked surface 未来如果要重开，最低需要什么新证据，以及哪些 shortcut 明确不被允许。

| reentry_id | blocked_surface | current_block_reason | minimum_new_evidence_needed | candidate_future_task_type | must_not_shortcut |
| --- | --- | --- | --- | --- | --- |
| `RE01` | real-board execution / timing / resource | 当前只有 read-only gate / regeneration / provenance；本机仍是 `NO_GO_REAL_BOARD_HOST_OR_DEVICE_PATH_UNAVAILABLE`；没有 `Linux + FPGA` 宿主、可打开设备路径、实测 timing/resource 行 | 至少需要一台可访问的 `Linux + FPGA` 主机、真实 board execution 日志、设备路径可达证据、可回链的 timing/resource 实测表、以及独立 review | bounded real-board execution evidence task | 不能把 host-side `NO_GO`、regeneration manifest 或 transfer pack 写成 board success；不能用模拟结果替代实测 timing/resource |
| `RE02` | default-env / cross-host `.tflite` portability | 当前只有 isolated current-host true runtime for selected preserved artifacts；没有 default-env、第二宿主或跨环境一致性证据 | 至少需要 preserved `.tflite` 在默认环境或第二宿主上的 load+invoke 证据、环境清单、失败矩阵与 review；最好覆盖独立于当前宿主的一条验证链 | bounded `.tflite` portability evidence task | 不能把单机 true-runtime probe、单环境 smoke、或 isolated host 成功直接回写成 portability closure |
| `RE03` | full training reproducibility | 当前最强证据只是 canonical chain intact + one clean CPU-only bounded rerun；没有 repeated-run closure、跨宿主复现或全链多次一致性 | 至少需要 clean-main 条件下的重复 rerun、关键产物一致性对账、必要时跨宿主复现、以及独立 reproducibility review | bounded training reproducibility evidence task | 不能把单次 bounded rerun、材料齐全、或 provenance 完整性写成 full reproducibility closure |
| `RE04` | `FR8/statcalib` mature comparator / unique clean threshold | 当前只允许 extension lane / no-promotion / persistent tie set；没有公平协议下的 promoted winner 或 unique clean threshold | 至少需要预先定义的公平 benchmark protocol、重复 seed/paired-seed 结果、无歧义晋升条件、promotion review，以及能解释 tie-set 收敛的证据 | bounded `statcalib` comparator promotion evidence task | 不能把 extension-lane 结果、单次优胜、或口头偏好写成 mature comparator；不能跳过 no-promotion review |
| `RE05` | expanded benchmark / stronger oracle baseline | 当前 frozen set 只覆盖已收口的主线范围；expanded benchmark 与 stronger oracle baseline 仍是 future lane | 至少需要新 protocol、明确 baseline 集合、额外 scenario/ranking 结果、与 frozen set 的公平对照、以及独立 review | bounded expanded-benchmark evidence task | 不能把 `T24` frozen-set 排名、补充说明、或旧表重解读写成 expanded benchmark closure |
| `RE06` | theory-branch content mergeback into main | 当前 theory 分支与 main 仍隔离；没有 mergeback 审核、冲突对账与 claim 重新校准 | 至少需要单独 branch-integration task、theory-to-main claim mapping、冲突段落审计、必要的 note/material 回链更新与 review | bounded theory-mergeback integration task | 不能直接复制 theory prose 到 main；不能把“理论解释更完整”当作已自动升级主线证据 |
| `RE07` | unified portability / deployment closure figure or prose | 当前主线故意保留 appendix 与 supplement 的分层 route；没有单一闭环 deployment story 支撑 | 至少需要把 `.tflite` portability、software-HIL、real-board execution/resource 三类证据都补齐，并通过新的 route-integration review | bounded deployment-closure evidence-and-authoring task | 不能用 schematic 重画、caption 改写或 narrative 压缩假装闭环已经成立 |
