# 投稿稿读者入口改写记录

日期：2026-07-02

对象：`docs/paper_notes/CNN_FPGA_GKP_submission_draft.tex`

性质：投稿稿 title / abstract / introduction 的 reader-facing 改写记录；不新增实验，不重跑 benchmark，不升级任何 HIL、`.tflite`、real-board、statcalib 或统计证据等级。

## 一句话结论

本轮把稿件入口从“内部治理后的主线材料说明”进一步转成外部读者可读的系统方法论文入口。核心改法是减少 `locked`、`frozen`、`extension lane` 等内部治理词，把它们改写为 `predeclared software-HIL benchmark`、`supplementary statistical-calibration analysis` 和 `evidence levels` 等论文语言。

## 改写范围

| 位置 | 改写内容 | 目的 | 边界 |
| --- | --- | --- | --- |
| Title | 从 `Runtime-Consistent Affine Calibration for Drift-Adaptive GKP Decoding` 改为 `Affine Runtime Calibration for Drift-Adaptive Gottesman--Kitaev--Preskill Decoding` | 提高外部检索性，首屏展开 GKP 全称 | 不暗示硬件或 broad benchmark 已完成 |
| Abstract paragraph 1 | 以 finite-energy/noisy-measurement/drift 的问题开场，再引出 affine runtime calibration | 让非仓库读者先理解问题和方法 | 不加入新结果 |
| Abstract paragraph 2 | 把主结果写成 `predeclared four-scenario software-HIL benchmark`，把 statcalib 写成 supplementary analysis | 减少内部治理语言，保留证据等级 | 不把 statcalib 晋升为主比较 |
| Introduction central claim | 把 `frozen main comparison` 转成 `main comparison`，把 `extension` 转成 supplementary evidence | 让证据层级更像论文，不像任务台账 | 不弱化硬件 placeholder 和 deployment 边界 |
| Contributions | 把 `wins all frozen scenarios` 改成 `has the lowest mean final_ler in all tested scenarios` | 减少 winner 语言，补 metric 和测试范围 | 不写显著性或泛化 |

## 术语替换表

| 原内部/治理式表达 | 投稿稿入口替代表达 | 理由 |
| --- | --- | --- |
| locked four-scenario protocol | predeclared four-scenario software-HIL benchmark | 外部读者能理解 protocol 预声明，而不是仓库冻结状态 |
| frozen drift scenario | tested drift scenario | 避免把治理状态当作科学属性 |
| extension lane | supplementary statistical-calibration analysis | 保留“非主比较”的证据等级 |
| wins all scenarios | has the lowest mean `final_ler` in all tested scenarios | 加上 metric 和范围，避免过强胜利叙事 |
| board-level validation completed | hardware timing/resource measurements remain placeholders | 明确硬件未完成 |

## 当前仍不能解决的问题

1. 这次改写只处理读者入口，不补 expanded benchmark、stronger baselines、holdout drift 或 CI。
2. Abstract 仍必须保留 hardware placeholder 句，否则容易被读成 FPGA/hardware paper。
3. Introduction 后续仍需要继续压缩内部 provenance 表和长 boundary table，把它们迁移到 supplement-style surfaces。
4. 若用户指定具体期刊，还需要按该期刊重写 title、abstract 长度、reference style 和 highlights / significance paragraph。

- 改善：摘要不再把 `statcalib` 写成内部 extension lane，而是 supplementary analysis。
- 保留：主结果仍只是 predeclared software-HIL ranking。
- 保留：硬件、CI、holdout 和 stronger baselines 仍是后续材料，不是当前完成事实。
