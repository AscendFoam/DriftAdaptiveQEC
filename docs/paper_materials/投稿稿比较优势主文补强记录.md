## 可写边界

- 可以写：投稿稿现在更集中地说明了当前可支持的比较优势，即 per-shot affine fast path、slow-loop calibration、analytical cost / Q4.20 software parity、residual-boundary metric bridge 和 future FPGA measurement surface。
- 可以写：这些优势仍是 software / analytical / protocol 层面的证据，不是硬件完成态。
