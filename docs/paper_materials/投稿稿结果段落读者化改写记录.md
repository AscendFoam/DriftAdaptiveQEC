## 一句话结论

本轮把主 Results 中的内部治理词进一步转成外部论文语言：主结果从 `locked/frozen` 叙事改为 `predeclared software-HIL benchmark` / `tested scenario set`，statcalib 从 `extension lane` 改为 `supplementary statistical-calibration analysis`，并把 `wins` 改为 `has the lowest mean final_ler`。

## 术语替换表

| 原表达 | 新表达 | 理由 |
| --- | --- | --- |
| locked four-scenario protocol | predeclared four-scenario protocol | 投稿读者关心是否预声明，而不是仓库冻结状态 |
| frozen set | tested scenario set | 避免治理词进入主结果解释 |
| extension lane | supplementary statistical-calibration analysis | 说明它是补充分析，不是主比较 |
| wins all scenarios | has the lowest mean `final_ler` in all tested scenarios | 加上 metric、均值和范围 |
| promoted main comparison | main comparison / mature comparator | 减少内部 promotion 术语 |
| hardware-result placeholder | planned hardware-measurement table | 占位符保留为未来测量要求，不写成已完成结果 |
