# 投稿稿主张证据与源数据对照表

## 1. 作用域

本文服务于 `docs/paper_notes/CNN_FPGA_GKP_submission_draft.tex`，把投稿稿中的主要 claim、表格、计划图和当前仓库证据逐项对齐。

本文不是新实验报告，不升级任何证据等级。硬件实验仍是占位；`statcalib` 仍是 supplement-side extension lane；当前主结果仍只支持 frozen mock-backed software-HIL 范围内的排名。

## 2. 核心一句话

投稿稿当前应坚持的核心命题是：

> Runtime-consistent affine calibration can improve drift-adaptive GKP correction in a predeclared mock-backed software-HIL setting while preserving a deterministic affine fast path; hardware, full reproducibility and broad benchmark claims remain future evidence surfaces.

## 5. 投稿前仍缺的最小材料

1. `Fig. 1` 到 `Fig. 4` 已有 Python 草图、source data 和 manifest；硬件部分当前只保留 planned measurement requirements table，直到真实板级材料存在。
2. `T24` 主结果已有 per-seed paired deltas、non-inferential paired-bootstrap envelope 和 LER advantage-margin descriptive readout；若要升级为强统计材料，仍需更多 repeats、预声明 inferential CI / hypothesis-test protocol 和 repeat-expanded uncertainty。
3. 参考文献 DOI/arXiv/BibTeX 核对，尤其是当前 `thebibliography` 中的 preprint / future-year 条目。
4. 一个 fallback / artifact-type audit，证明主表没有混入 stub、fallback 或非预期 runtime path。
5. 当前已有 one-step 与 short-sequence controlled local-Gaussian nearest-syndrome / oracle-affine / wrapped-Gaussian sanity checks；若要升级为 reviewer-strong baseline，仍需要预声明的 known-noise affine / tuned nearest-lattice / tuned sequence-level wrapped-Gaussian benchmark protocol，而不是当前受控 CSV。
6. 当前已有 controlled non-hardware holdout drift stress diagnostic；若要升级为正式泛化证据，仍需要 trained branch 的预声明 expanded/holdout benchmark、更多 repeats 和不确定性估计。
7. 当前 residual-boundary Pauli-event surrogate 与 lattice logical-channel sanity summary 只用于解释 `final_ler` proxy 与 channel 语言之间的关系及其方法级聚合；若要写真正的 logical-channel fidelity / process infidelity，仍需要 finite-energy GKP channel simulation、logical-channel tomography 或等价 source data。
8. 若要把 fast-path cost / fixed-point parity 从 analytical/software-emulation model 升级为硬件优势，需要 FPGA synthesis/resource、timing closure、power、source-vs-board agreement 和真实 board-level latency distribution。
9. 如果标题或摘要保留 hardware-facing 语言，必须继续保留硬件占位符，直到 board logs、bitstream hash、latency/resource 和 source-vs-board vectors 真实存在。
