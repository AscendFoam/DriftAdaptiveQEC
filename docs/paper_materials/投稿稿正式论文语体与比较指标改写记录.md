- 主 benchmark 的 paired confidence intervals / bootstrap intervals、更多 repeats 和 holdout drift family。
- 至少一个理论 baseline，例如 oracle / known-noise affine、nearest-lattice 或 wrapped-Gaussian decoder baseline。
- 完整 source-data manifest：per-row artifact hash、runner version、environment notes、table-to-artifact audit。
- 若保留硬件方向，需要真实板级 logs、bitstream 或 RTL hash、DMA contract、fast-path latency distribution、resource/power/timing closure 和 source-vs-board vectors。
- 最终投稿前需要按目标期刊格式重新核对 BibTeX / `.bbl`，尤其是 2026 preprint 和未稳定的硬件条目。
