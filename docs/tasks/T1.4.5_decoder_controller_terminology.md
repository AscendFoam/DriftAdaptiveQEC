## 3. 关键语义

### 3.1 三种上界

- decoder oracle：读取当步真实 `DriftState`，在声明的 decoder model 内做 Bayes/MAP；
- control oracle：在固定 sBs ansatz/model/short horizon 内优化 causal measurement tree；
- channel-recovery bound：给 encoding+noise 允许任意 recovery，输出 channel fidelity bound。

三者的额外信息、自由度、输出和分母均不同。control tree 节点若读取未来 outcome，必须降名为
`hindsight trajectory bound`。

### 3.2 Teacher 与 student

Feedback-GRAPE RNN/GRU 输出 sBs control residual，因此是 controller teacher，不是 decoder；
它不是 oracle，也尚未实现。student 是 teacher-dependent 的低维递推/FSM，只有通过
gain-retention、fixed-point、RTL、post-route、board 和 fault gates 后才可写 deployable。

### 3.3 Host 与 fast path

host estimator 从 observed windows 估计慢变量/状态并 proposal bank；fast path 使用 latched bank
执行 cycle-critical action、frame、FSM 与 fallback。host 不进入 critical path，fast path 不在线训练。

## 4. 反简化复核

源码审计发现两个不能只靠普通 glossary 解决的旧命名：

- `oracle_delayed` 实际读取 mock `target_params`、延迟窗口并输出 NoisePrediction；它既不计算
  syndrome MAP，也不优化 sBs control policy。冻结为 test-only hidden-truth parameter reference。
- `teacher_mode` 实际在 window/EKF/UKF/PF 中选择 classical reference estimator，供 residual/
  statcalib 构造 features/K/b；没有 Feedback-GRAPE、RNN hidden state 或 sBs action。冻结为
  legacy reference-estimator feature source。

本 task 保留历史 config/artifact 兼容性，没有贸然重命名破坏旧证据；但新 prose、主表和 artifact
必须携带 canonical role/qualifier。新增 R-N024 跟踪迁移风险。

因此产物不是 demo 级词汇表：测试会读取真实源码/任务行，检查 planned roles 只有 task-board
bindings、upper references 的 inputs/outputs/roles 唯一、legacy aliases 不得升格、control oracle
保持 causal tree。
