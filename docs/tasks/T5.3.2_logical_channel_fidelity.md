## 输入与执行方案

输入为 T5.3.1 的 24 条六态 CPTNI channel lanes、本地
`Real-time_quantum_error_correction_beyond_break-even` 正文/补充公式和任务板边界。执行时不从历史
异构指标拼表，而是逐 cycle 回读六个未归一化 code outputs 与 PTM：用
`F_e=Tr(R)/4`、`F_avg=(2F_e+R_II)/3` 计算 leakage-inclusive fidelity，并以六态 direct overlap 独立复核。

短时率冻结为 `Gamma=-2 dF_avg/dt|0` 的三点二阶 forward difference；一/四点估计构成离散化 envelope，
不做指数拟合。统计不确定度因 exact deterministic propagation 保持 null，36/40 cutoff spread 只作系统
数值敏感度。开始时预期可能给 on/off 两者报告短时寿命，但正式曲线显示 qec-on 初期强瞬态，故增加
monotonicity+多阶 rate spread 合格门并把主动寿命置空，而不是降低门槛或隐藏结果。
