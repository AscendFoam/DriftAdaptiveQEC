## 输入与执行方案

输入为 T2.3.7 的 strict-split MF/NMF simulator、schema-v3 PASS artifact/checkpoint、任务板
`T3.2.7` 合同和 R-N044。先审计旧 MF 后发现其仅有 70,159 参数、二元 g/e scalar 输入，不能
证明与 72,853 参数 history GRU 的精确预算公平性。因此不改写旧证据，新增 static 390-param
front，使 front/总参数/dense MAC 分别精确匹配 GRU 的 `390/72,853/72,266`，再按相同训练与
held-out trace 重跑五 agents。

失败分支预先冻结为：无论 NMF−MF 正负均保留；不把 test 用于 checkpoint selection；若
leakage 未在物理模型出现则只声明接口支持，不声明 robustness；若 cutoff 排序反转则升级风险，
不挑选有利 cutoff。

- 5×300 epoch exact MF 训练，2 validation/8 test/4 confirmation seeds 严格隔离；

- 加入 exact budget、prefix invariance、token failure、全参数梯度、checkpoint/hash、summary
  recomputation 与 cutoff direction-reversal tests；
