# T4.1.5：实现 offline teacher / online student 分离

## 状态

Done（2026-07-15）。

## 输入与通过标准

输入为 T2.3.7 hash-bound 5-agent frozen NMF ensemble、任务板的 offline-only teacher 边界和 T4.1.3
host/fast-path 分层。通过标准是 teacher 不进入在线 artifact/runtime，训练/validation/evaluation 隔离，
student 有确定资源账本和安全 fallback，且模仿结果、失败路径和未验证物理 claim 均可审计。

## 实际完成

实现 75-trainable/105-stored-scalar 的 15-control 指数递推 student、3-restart validation-only 蒸馏、
15,360-row Source Data、hash-bound checkpoint 和 observed-outcome/health-only online API。恢复 teacher 时逐一
验证 checkpoint、manifest 和 5 个 model hash；在线模块无 torch/simulator 依赖，并拒绝 teacher object。

## 验证与深审计

生产 benchmark 21/21 gates、28 focused tests、207 adjacent（2 skipped）通过；显式全量 `tests/` 为
`1283 passed, 14 skipped, 4 failed`，4 个失败仍仅为 R-N012 缺失旧 FR8/P4 文档。三个 restart 均训练全部 75 参数，best epoch
`1040/1180/1180`；tail relative validation improvement `0.000125/0.000254/0.000491`，达到 tolerance
plateau，但因最佳点接近 1200 上限，不宣称 optimizer/global convergence。

冻结 evaluation student/latest-only/zero-safe MSE 为
`1.453624e-6/1.404389e-4/5.265504e-3`，MSE-defined imitation retention 为 `0.999724`。same-prefix
causality、online/batch bit-exact、deterministic replay、invalid/CRC/stale/deadline/leakage 零 residual fallback、
artifact tamper 和 import boundary 均通过。初版 600 epoch 全在上限选中，已通过延长训练与 plateau gate 修复。

## 产物

核心/benchmark、两份 tests、主说明、21-gate JSON、15,360-row CSV 和 hash-bound student checkpoint，
并同步 terminology、README、benchmark README、protocol hierarchy、风险和任务板。
