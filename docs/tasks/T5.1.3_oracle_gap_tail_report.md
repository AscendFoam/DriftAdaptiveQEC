## 输入、通过标准与失败分支

输入是 T5.1.2 的六个 decoder scenarios/36 seed aggregates、T4.4.4 cutoff12/16 exact two-cycle lane、
T3.2.9 finite-horizon control reference 与 `physics/oracle_gap.py` 的 signed denominator contract。

任务必须报告 syndrome-level `P_L`、worst/95% window LER、paired decoder-oracle gap、独立 short control-
oracle/reference gap、bootstrap CI、paired seeds 和多重比较。若 T5.1.2 没有逐 window outcome，禁止从 seed
平均值伪造 tail；若把 windows 当独立 seeds、裁剪 ratio、把 control branches 当 sampling units、扩展 control
horizon 或漏做 multiplicity，必须 fail closed。

## 执行方案

审计确认 T5.1.2 只保存 seed aggregates，不能支持 tail。因此新 runner 完整镜像其 calibration、evaluation、
observation-update 与 RNG 顺序，保存逐 window failure counts，并用 trace hash 和六种 seed rates 双重核对重放。

每场景 6 个 evaluation seeds 是独立 cluster。20,000 次 bootstrap 重采样整条 seed trajectory，重算 average
`P_L`、192-window p95、每-seed worst 均值和 decoder-oracle ratio。observed global maximum 只作描述，不对
192 个相关 windows 使用 iid maximum CI。

预注册多重比较 family 为 standard/window/EWMA/Kalman vs static × 6 scenarios，共 24 项；每项做全部
`2^6` two-sided exact sign flips，再统一 Holm-Bonferroni。control lane 单独读取 cutoff12/16 的 16-branch
exact expectation；因为 branch probability 随 policy 改变，明确不生成 fake bootstrap CI。

## 关键结果与反证

- calibration shift：Kalman average/p95 `0.005941/0.013672` 低于 static `0.021637/0.054688`，但
  worst 为 `55/512=0.107422`，高于 static `37/512=0.072266`；
- burst/outlier：adaptive average 略降，但 worst 与 static 同为 `0.091797`；
- Kalman point gap-closed fraction 约 `0.803--0.997`，但小 denominator 场景 CI 宽且 24-test Holm 为 0 discovery；
- control reference 不是数学上界：cutoff12 handcrafted terminal gap `+0.030878`，但 selection/lifetime 为负；
  cutoff16 handcrafted terminal gap `-0.135242`。negative values 原样保留。
