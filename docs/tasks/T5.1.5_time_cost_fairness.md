- Task ID：T5.1.5
- 日期：2026-07-16
- 状态：Done

## 输入、通过标准与失败分支

输入为 T3.2.8 common-700 μs autonomous/feedback benchmark、T5.1.1 no-correction probe、T4.4.4
matched-controller lifetime/burden/cost、T4.1.1 host estimator profiles、T2.4.1 dual latency budget 与
T5.1.4 fallback verdict。

必须同时报告 per-cycle、per-microsecond、measurement/reset、active-control 和 classical latency；不同
protocol、decision target、horizon 或 evidence class 不得混成统一排名。unmeasured latency 必须保持 null，
`e` outcome 不得冒充 reset，two-cycle control reference 不得外推 ten cycles。

## 执行方案

建立只读、hash-bound consolidation runner。将 700 μs protocol、100 μs controller 与 host estimator 分成
三条 lane；从 parent 原字段抽取 lifetime/events/cost/profile，并对 cycle×duration、cycles-to-μs、event
rate、software ceiling 和 target-null 做机器复核。no-correction 30 μs probe 和 control reference 单独标为
不进入主表。semantic mutations 封住 rescale、填零、跨 lane 和硬件升级。

## 实际完成

- 新增 `cnn_fpga/benchmark/time_cost_fairness.py`；
- 绑定 6 个 parent artifacts、machine gates、source/code/artifact hashes；
- 形成 12 个 protocol rows：2 methods×2 cutoffs×3 noise profiles；

- 将 observed `e` events、multilevel leakage、analytic scalars/MAC 与 classical latency 分列；
- 形成 6 个 estimator host-profile rows，不赋 physical lifetime/events；
- 保留 7 个 target-board/physical-front-end latency null fields；
- 输出 537-row Source Data、18-gate JSON、人类报告和 25 项 direct/mutation tests。

## 关键结果

- autonomous logical lifetime 按 cycle ratio `1.151287--1.346101`，按 μs ratio `0.805901--0.942271`；
- 100 μs controller table 保留 teacher/student/MF/standard/recurrence 全部 cycles 与 μs；
- `e` burden 变化不改变每策略固定 20 reset 的 protocol cost；
- T4.1.1 host medians `2.101--724.369 μs/update` 只属于 estimator software profile；
- controller latency、target board latency 与 physical frontend latency 均未测，不填 0。
