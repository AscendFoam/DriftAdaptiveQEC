# T3.2.5：run-length FSM / parameter-bank baseline

- **日期：** 2026-07-15
- **状态：** Done

## 输入与通过标准

- 新任务板 T3.2.5、T2.0.3 observed `g/e/leakage`、T2.1.1 syndrome stream、T2.4.2
  conflict-safe `ParamBank`；
- 必须实现可执行确定性 FSM、显式阈值/优先级/失败分支和同 trace comparator；
- 在线输入不得读取 hidden truth，不能只画状态图或把 run=1 memoryless 重命名为 run-length；
- 结果只作事件控制 baseline，不冒充 LER、RTL、综合或板测。

## 执行方案与实际完成

1. 实现 3-bit X/Z e-run、leakage/clean/health-good counters，normal/X recovery/Z recovery/
   leakage hold/fallback 五态和 phase-bit tie-break。
2. 接入真实 double `ParamBank`。requested mode 与 active bank 不一致时才 stage/commit；版本单调且
   每次成功 switch 只写一次。
3. 深审修复真实缺陷：外部 pending writer 冲突后，旧实现只在第一拍用 local-safe ROM，下一拍可能
   回读旧 active bank。现在实际状态进入 fallback，并在每拍检测 bank mismatch；直到 pending 完成且
   可原子重新同步前始终使用 local safe ROM。
4. 把 `run=1` 单列为 memoryless comparator，training-only 网格只扫描 `e_run=2/3/4`，同时扫描
   leakage enter/clear 与 fallback clear；以 24 组真实 FSM replay 冻结生产阈值。
5. 在现有 protocol-aligned syndrome stream 上建立 4 场景、8 evaluation seed、384k same-trace
   controller comparison，另外保留 hidden-truth oracle 仅作 evaluator lower bound。
6. 显式报告事件代价、write cost、accuracy、unsafe miss、false intervention、detection delay、bank writes、
   paired seed-cluster CI 和负排序。

## 验证与反简化检查

- training base 49,152 cycles，24-grid 真实 FSM replay 共 1,179,648 cycles；evaluation 384,000
  cycles / 32 unique traces / 32 Source Data rows；
- 生产选择 `e_enter=2, leakage_enter=1, leakage_clear=2, fallback_clear=1`；
- run-length cost `0.202829`，相对 static gain `0.401710 [0.399014,0.404407]`；
- memoryless minus run-length `-0.179911 [-0.180782,-0.179041]`，证明 run-length 明显较弱；该负结果
  原样保留；
- run-length unsafe miss 为 0，false intervention `0.007888`，平均每 12k cycle 写 bank `3126.66`
  次；版本与写入逐 trace 精确一致；
- 15/15 machine gates、40 focused、54 registry+focused、131 adjacent、源码 compile 通过；
- 显式 `tests/` 全量 `1046 passed, 4 skipped, 4 failed`；4 个失败仍仅为 R-N012 的两份历史
  FR8/P4 文档缺失，没有 T3.2.5 新回归；
- conflict probe 连续三拍 local-safe，第四拍在 external version 1 后原子同步到 FSM version 2。

## 风险与 claim 影响

新增 R-N056：事件代价矩阵与 simulator target 是 synthetic evaluator contract，且当前 FSM 不反向影响
物理 stream。非退化 run-length 明显弱于 memoryless，不能包装成性能最强方法或 LER gain。

只允许称 hardware-mappable software event-controller baseline 和 atomic-bank/failure-path evidence；
RTL/综合/板测、物理 recovery/lifetime、device-calibrated cost 均保持未实现。
