## 3. 关键协议语义

### 3.1 sBs 主数字孪生

- full QEC cycle 是两个 rank-2 X/Z constituent 的 rank-4 composite；
- `4.924 us` 是 constituent 文献时长，`9.848 us` 是完整 X+Z 文献时长，实板值为 `null`；
- full-cycle Kraus 标签是 `K_gg/K_ge/K_eg/K_ee`，不能用孤立 `g/e` 替代；
- `f` 属于实验 readout/reset/leakage control branch，不是第五个理想 Kraus operator；
- action 覆盖 sBs、测量反馈、条件 reset、`g/e/f` virtual rotation、X/Z switch 和 Pauli-frame tracking；
- gradual error-space trickle-down 不能简化为一步投影恢复。

### 3.2 sharpen--trim 交叉验证

- 周期是两个 sharpen 加两个 trim 的四轮 block；
- 每轮 native observation 是 `+y/-y`，不与 sBs outcome alphabet 共用；
- 一手文本没有可直接迁移的完整 round/block 时长，因此 timing 保持 `null`；
- 只用于 finite-energy、peak/envelope 和 feedback 趋势交叉验证，不进入主协议排名。

### 3.3 secondary 协议

Knill/qunaught 与 ME/P-Steane 当前只有 secondary local evidence。`10^-8` 等价尺度与 `2a=b` 条件均只是待一手核验线索。FPGA 选择 `(a,b)` 索引不等于实现物理 squeezing。
