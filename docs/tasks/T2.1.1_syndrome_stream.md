## 1. 输入与执行方案

输入为 T1.3.1 的完整 `DriftState`、T1.1.1 shared modular convention、T2.0.1 sBs protocol contract、T2.0.3 `PairedSyndrome` vocabulary 和任务板规定的 observed/truth 输出。

执行前将问题拆成六条独立证据链：

1. continuous state：mean/covariance/correlation/outlier mixture 必须直接采样而非压成 scalar sigma；
2. loss：必须有 `sqrt(eta)` state attenuation 和独立 environment-noise 记录，不能调用 legacy `gamma/2` proxy；
3. modular/logical：必须复用 shared standard binning，并验证 q→X、p→Z 的 Pauli composition；
4. discrete regime：burst/loss 进入 leakage hazard，regime/provenance 只留 truth；
5. recovery：depth、pending quadrature、g/e/leakage 和 physical residual 必须跨周期因果一致；
6. schema：deployable record 结构上不允许 hidden/truth 字段。

## 2. 实际完成内容

- 实现 process/explicit-state 双入口与严格 step contract；
- 实现 loss→correlated Gaussian-mixture channel→modular truth→measurement→recovery/leakage→logical update 的固定顺序；
- 输出 analog/residual q-p、X/Z phase、`g/e/leakage` 与 observed runs；
- 输出独立、只读的 full `DriftState`、outlier、loss noise、hidden regime、leakage、recovery depth/quadrature 和 logical truth；
- 实现 `I/X/Z/Y` Pauli truth 累积；
- 实现 f/higher leakage persistence 与 geometric duration；
- 修复审查中发现的两类简化错误：泄漏后 positive depth 可能无 pending quadrature 的 deadlock，以及一次 X/Z 动作同时缩小两个 residual axis；
- public API 接入 `physics/__init__.py`；
- protocol hierarchy 增加 T2.1.1 machine-readable contract/update。
