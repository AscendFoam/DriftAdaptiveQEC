## 1. 任务范围与证据等级

本任务建立 decoder/oracle/benchmark 共用的 synthetic hidden-truth contract，覆盖：

1. mean drift；
2. variance/correlation drift；
3. loss drift；
4. outlier-rate drift；
5. step drift；
6. telegraph drift；
7. burst drift。

产物属于 `syndrome/displacement-level synthetic drift model`。它不模拟 cavity--ancilla
Hamiltonian、finite-energy envelope 在 loss 下的完整演化、readout IQ、reset/leakage 或真实
设备校准后的噪声谱；这些边界不得从类名或 `loss_gamma` 字段外推。

## 2. DriftState 真值契约

每个时间步返回不可变 `DriftState`：

| 字段 | 语义 | 约束 |
| --- | --- | --- |
| `step`, `time` | 离散索引与 `step*dt` 物理时间 | 非负；`dt>0` |
| `mu_q`, `mu_p` | core/outlier 共用的位移均值 | 有限 |
| `sigma_q`, `sigma_p`, `rho` | core Gaussian 的轴向标准差与相关系数 | sigma 正；`-1<rho<1` |
| `loss_gamma` | `gamma=kappa*t` 口径的 loss hidden truth | 非负；`eta=exp(-gamma)` |
| `p_outlier`, `outlier_scale` | 重尾 mixture 权重与标准差倍率 | `p` 在 `[0,1]`；scale 至少 1 |
| `burst_active` | 当前是否位于 burst episode | boolean |
| `source`, `regime`, `seed`, `event_id` | truth provenance 与事件编号 | 非空/非负 |

core covariance 为

\[
\Sigma_t=
\begin{bmatrix}
\sigma_{q,t}^2 & \rho_t\sigma_{q,t}\sigma_{p,t}\\
\rho_t\sigma_{q,t}\sigma_{p,t} & \sigma_{p,t}^2
\end{bmatrix}.
\]

outlier component 使用同一均值和 `a_t^2 Sigma_t` covariance，因此 mixture covariance 是

\[
\Sigma_{mix,t}=\left[(1-p_t)+p_t a_t^2\right]\Sigma_t.
\]

代码同时提供 core/outlier/mixture covariance、mean、`eta` 和 covariance principal-axis
angle。T1.3.2 oracle 应直接读取这些真值，不经过 scalar sigma 压缩。

## 3. 七类过程与时间语义

| 过程 | 实现 | 行为 |
| --- | --- | --- |
| mean | `MeanDriftProcess` | 线性趋势，可叠加有显式 period/phase 的正弦项 |
| variance | `VarianceDriftProcess` | 在 log-sigma 与 Fisher-rho 坐标线性演化，保持 sigma 正和 covariance 正定 |
| loss | `LossDriftProcess` | 从 base gamma 指数松弛到非负 target gamma |
| outlier rate | `OutlierRateDriftProcess` | 从 base probability 指数松弛到 `[0,1]` 内 target |
| step | `StepDriftProcess` | `step<change_step` 用 before，边界及之后严格用 after |
| telegraph | `TelegraphDriftProcess` | 二态 Markov chain，支持不对称 `p(a->b)`/`p(b->a)` |
| burst | `BurstDriftProcess` | onset hazard + 整数 episode duration + episode 后 cooldown |

另提供 `ConstantDriftProcess` 作为稳定状态/reference。

所有 stochastic process 的 `generate(N)` 都从自身 seed 重新生成前缀；因此
`generate(n) == generate(N)[:n]`，也不依赖调用先后。`state_at(t)` 与同 seed trajectory
的第 `t` 项一致。

telegraph 并非每步独立抽两个 regime：当前 regime 决定本步 transition probability，只有
发生 transition 才切换和递增 `event_id`。burst 也不是独立 Bernoulli mask：onset 后连续
保持 burst template `min_duration..max_duration` 步，结束后至少保持 `cooldown_steps`
个 baseline 步。

## 4. Mixture sampler

`sample_displacements` 先抽 outlier mask，再分别从 core covariance 或
`outlier_scale^2 * covariance` 采样，最后加共同均值。返回位移数组和 mask，允许后续数据
生成器分别核验总体分布与 hidden component 标签。

固定 30 万样本检查结果：

| 量 | 目标 | 经验值 |
| --- | ---: | ---: |
| mean q | 0.2000 | 0.19911 |
| mean p | -0.1000 | -0.10196 |
| outlier rate | 0.0800 | 0.07992 |
| covariance qq | 0.1980 | 0.19724 |
| covariance qp | 0.1155 | 0.11568 |
| covariance pp | 0.5500 | 0.54909 |

采样器不把 `loss_gamma` 自动转成 additive Gaussian；这是为了避免在核心新接口里把真实
loss channel 偷换成位移噪声。

| stationary B occupancy | 0.250 | 0.25048 |

burst 固定为 onset 0.12、duration 2--6、cooldown 3、2 万步、seed 2718：

## 6. 旧 run_with_drift 适配层

仓库旧 `QECSimulator.run_with_drift` 的回调只接受
`t -> (sigma, delta, theta)`，并在每步从零均值 isotropic Gaussian 重采 1000 点。为保持
旧 smoke 可运行，`LegacyRunWithDriftAdapter` 使用

\[
\sigma_{legacy}^2=
\frac{1}{2}\operatorname{tr}(\Sigma_{mix})
+\frac{\mu_q^2+\mu_p^2}{2}
+\frac{\gamma}{2},
\]

其中最后一项只复用旧 `CombinedNoiseModel` 的 effective-sigma proxy；`theta` 取 core
covariance principal-axis angle，`delta` 由 adapter 显式固定。

该压缩会丢失 mean 的符号/方向、mixture component、非圆对称 covariance 的完整信息和
真实 loss 机制。adapter 保留 `state_at()` 与 `last_state` 供审计，但只允许旧 smoke，
禁止用于 oracle 或论文主结果。测试已把 adapter 直接接入现有 `QECSimulator.run_with_drift`
并验证三元回调契约。

## 8. 反简化/伪实现复核

| 检查 | 结果 |
| --- | --- |
| telegraph 是否是逐点 iid regime | 否；显式二态 Markov transition，统计回收转移律 |
| burst 是否是 iid outlier mask | 否；onset、duration、cooldown 三状态量跨步保存 |
| 随机过程是否受调用顺序影响 | 否；固定 seed 前缀可复现 |
| variance 是否可能静默变负 | 否；log-sigma 演化 |
| correlation 是否可能静默越界 | 否；Fisher-rho 演化，状态层再次 fail-closed |
| loss/outlier target 是否用 clip 隐藏非法输入 | 否；构造时拒绝非法 target |
| 是否只生成曲线、不提供样本真值 | 否；完整 `DriftState`、mixture sampler 和 provenance |
| 是否把 legacy scalar sigma 当完整漂移 | 否；adapter 明确标为 lossy，oracle 必须读 state |
| 是否冒充实验校准 drift | 否；证据等级固定为 synthetic effective model |

结论：本任务提供可复现、有状态、可统计检验和失败分支完整的 generator，不是 demo 级
若干正弦曲线。
