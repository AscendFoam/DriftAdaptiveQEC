## 执行方案与实际完成

实现 `2L x 2L` joint periodic Bayesian state、correlated-Gaussian FFT prediction、modulo-L
likelihood update、四 parity-region logical posterior 与末端一次 decision。冻结 20-cycle history、
known-zero episode start、`residual_q/p` 两观测字段、process/measurement covariance 与 no-
intermediate-action 语义。`ObservedSyndromeStep` adapter 对类型、连续性、valid 和 wrap consistency
fail closed。

static comparator 使用相同离散 H-step transition prior，只接收末次 residual；standard row 与
full-episode truth reference 也注册为不同角色。主来源只迁移 multi-round posterior/final correction
机制，明确不复刻 finite-energy Glancy–Knill circuit 或论文 fidelity。

## 反简化检查与修复

1. 小网格首轮 gate 失败后修正 boundary-node parity bias，使用 cell-centred grid 与四邻 zero split。
2. 删除每 cycle 全 likelihood exponential 重算，改用 precomputed cyclic template；用 finer grid
   验证量化误差，不把优化当无误差近似。
3. seed-cluster CI 从 normal 改为 Student-t (`df=7`)。
4. cost 拆分 one-time quadratic-form precompute 与 per-cycle quantization/table lookup。
5. 修复 static/oracle validators 的跨任务角色强绑：registry 现显式声明 task-specific static 和
   nondeployable reference anchors，并有 omission/duplicate/misplacement 负测。
6. 刷新 T3.1.1--T3.1.5 所有受 registry hash 影响的 artifacts；static-protocol 640k 重跑在首个
   180 s host timeout 后以同规模延长上限完成，未缩减规模。
