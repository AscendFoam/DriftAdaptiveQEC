## 1. 模型、单位和 logical class

沿用 T1.1.1/T1.1.2 已冻结的 operational spacing

\[
\lambda=\texttt{LATTICE\_CONST}=\sqrt{2\pi}.
\]

二维隐藏位移、均值和 centered syndrome 为

\[
X=(X_q,X_p)^\top\sim\mathcal N_2(\mu,\Sigma),\qquad
X=s+\lambda k,
\]

其中 `s_q,s_p in [-lambda/2,lambda/2)`、`k=(k_q,k_p) in Z^2`。四个
logical cosets 由

\[
(b_q,b_p)=(k_q\bmod2,k_p\bmod2)
\]

标记，并用 `logical_class=2*b_q+b_p` 编码为 `00,01,10,11`。这只是
ideal syndrome-level square-GKP 位移模型，不是 finite-energy Wigner/Fock simulation。

## 2. Covariance contract

`covariance_from_sigmas` 构造

\[
\Sigma=\begin{pmatrix}
\sigma_q^2 & \rho\sigma_q\sigma_p\\
\rho\sigma_q\sigma_p & \sigma_p^2
\end{pmatrix}.
\]

要求 `sigma_q>0`、`sigma_p>0`、`|rho|<1`。任意直接传入的 covariance 必须为
有限、对称、严格正定的 `(2,2)` 矩阵；通过 Cholesky 检验。`rho=+/-1` 的奇异分布
不会被静默加 jitter，因为那会改变用户指定的统计模型。对称性容差按矩阵自身尺度
计算，避免小量级 covariance 把显著非对称误差误判为可接受。

## 3. 四陪集 likelihood 与 joint posterior

对 `a,b in {0,1}`，joint likelihood 为

\[
L_{ab}(s)=
\sum_{k_q\bmod2=a}\sum_{k_p\bmod2=b}
\frac{\exp[-\tfrac12 r_k^\top\Sigma^{-1}r_k]}
{2\pi\sqrt{\det\Sigma}},
\quad r_k=s+\lambda k-\mu.
\]

给定严格为正且归一化后的四类 prior `pi_ab`，posterior 为

\[
P_{ab}(s)=\frac{L_{ab}(s)\pi_{ab}}
{\sum_{i,j}L_{ij}(s)\pi_{ij}}.
\]

所有 alias sums 和 evidence normalization 均在 log domain 完成。hard MAP 选择
posterior 最大类；精确 tie 固定按 `00,01,10,11` 顺序选择。`confidence` 定义为
top-1 与 top-2 posterior 的差，不使用未经归一化的 density gap。

## 4. 截断、复杂度与失败关闭

每个样本先找到 q/p 轴最接近 `mu` 的 alias，再构造覆盖默认 `10 sigma_q` 与
`10 sigma_p` 的 rectangle，并额外保留两个 cells。即便 q/p 有相关性，rectangle
之外的遗漏概率仍可由两个 marginal Gaussian tails 的 union bound 控制。

为了避免有限但极端 `sigma` 或超大 batch 在创建 alias 张量前耗尽内存，实现对
`batch_size * aliases_per_item` 设定 `10,000,000` 次评估安全门。超过时显式
`ValueError`，调用方应减小噪声域或分块；测试中的 12,000 样本 Monte Carlo 也按
1,500 分块，证明分块是正常受支持路径，而不是只为小数组工作的接口。

## 5. Joint 与 independent 对照

`independent_map_decode_2d` 使用 covariance 的两个 marginal variances，但故意忽略
off-diagonal correlation，分别计算 q/p 的 1D periodic MAP，再形成四类 factorized
posterior。它是同输入、同 mean、同 lattice 的受控对照，不是另一套 truth。

当 `rho=0` 时，必须满足

\[
L_{ab}^{(2D)}(s_q,s_p)=L_a^{(q)}(s_q)L_b^{(p)}(s_p),
\]

并且 joint/independent 的 log likelihood、posterior 和 hard class 全部一致。相关
covariance 下 independent decoder 保持只消费 marginals，测试验证把 `rho` 从 0 改为
0.88 不会改变其输出。

## 6. 实际接口

- `MAPDecode2DResult`：返回 syndrome、q/p parity、logical flips、class、完整
  `(2,2)` posterior、confidence、四类 log likelihood 和 method；
- `covariance_from_sigmas`：显式 marginal/correlation 参数化；
- `coset_likelihood_2d`：指定四陪集 raw/log likelihood，支持 batch；
- `map_decode_2d`：correlated joint MAP；
- `independent_map_decode_2d`：忽略 off-diagonal 的直接 baseline；
- `physics.__init__` 已登记惰性公开导出。

## 8. 反简化/伪实现复核

| 检查 | 结果 |
| --- | --- |
| 是否把 correlated noise 拆成两个 1D 后冒充 joint | 否；joint 使用完整 Mahalanobis quadratic，另保留 independent baseline |
| 是否只判断四个最近 peaks | 否；按 marginal tails 做四陪集二维 alias sum |
| 是否只返回 hard class | 否；返回四类 log likelihood、posterior 和 top-two confidence |
| 是否只测 `rho=0` | 否；独立 correlated 穷举、负相关归一化和 `rho=0.9` 配对 MC |
| gain 是否来自两批随机样本 | 否；同一批样本、配对 discordant counts 和 McNemar 统计量 |
| covariance 错误是否静默修正 | 否；非对称、非正定和奇异矩阵全部失败关闭 |
| 极端参数是否可无界分配 | 否；alias workload 在分配前有显式安全门并测试 |
| 是否偷换 finite-energy/实验 claim | 否；文档限定 ideal correlated Gaussian reference |

结论：T1.1.3 是可复用、可审计且有直接独立对照的 2D MAP reference，不是把两个
1D 判决拼接后改名的 demo。

## 9. 对论文 claim 的影响

现在允许声称：在 ideal square-GKP syndrome-level correlated Gaussian 模型中，仓库
实现了完整四陪集 joint MAP，并在 `rho=0` 退化、独立 alias 穷举、概率归一化和固定
强相关配对 Monte Carlo 上得到验证。仍不能声称 finite-energy optimality、真实
measurement channel、non-Gaussian drift robustness、multi-round lifetime gain 或硬件实测。
