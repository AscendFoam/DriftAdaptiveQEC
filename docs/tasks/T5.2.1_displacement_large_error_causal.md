# T5.2.1 任务记录：displacement / large-distance 因果故障注入

- Task ID：T5.2.1
- 日期：2026-07-16
- 状态：Done

## 输入、通过标准与失败分支

输入为 T2.0.5/T5.1.2 coarse component evidence、T2.3.3 coordinate cross-check、T5.1.6 feasibility contract
与一手 source anchors。通过要求是 recovery depth、e-run、logical failure 随最近逻辑操作距离呈可解释趋势，且
不能用预设趋势、单 seed、shot 伪重复或 component proxy 冒充正式因果结果。

失败分支包括：旧 calibration seeds 混入 evaluation、非 17 点 grid、同时改变 readout/recovery、truth 进入 controller、
logical failure 与 recovery censoring 混名、只报 nearest-target 而隐藏 identity flip、parent/source/hash 漂移，以及
coarse simulation 升级为 physical-memory/device claim。

## 执行方案

1. 冻结 `epsilon/l_S=0:1/32:1/2`、8 个新 seed clusters、4096 shots 与 20 cycles；
2. 每个 seed 内用 common random numbers 只改变 displacement severity；
3. 复用 T2.0.5 注册的 error-space/observation/reset core，但不复用旧 evaluation samples；
4. 用 whole-seed 20k bootstrap 汇总 recovery/e-run；
5. 冻结 `sigma/l_S=0.040/0.025` 两个 logical injection-jitter profiles；
6. 同报 nearest-operation misclassification 与 identity-reference flip；
7. 用独立 Gaussian boundary formula、unaffected axis、mirror/monotonicity 和 mutation suite 验证。

## 实际完成与关键结果

- 136 recovery rows、272 logical rows、1,863-row Source Data、20/20 gates；
- midpoint depth `6.00000`、observed e-run `4.84512`，两侧严格随 logical distance 收缩；
- primary nearest-op midpoint failure `0.495300 [0.490448,0.501099]`；confirmation 为
  `0.497864`，两 profile 的 exact target 0.5 均在 cluster CI；
- identity-reference flip 从 0 单调升到 1，未把 `l_S/2` logical operation 隐藏；
- Monte Carlo 与解析 boundary formula 最大绝对差 `<0.005`；
- 所有点 20-cycle recovered fraction 为 1，但该值未被重命名为 logical failure。

## 开发期详细检查

初版即 20/20 PASS。测试审计发现若要求解析值落入全部 34 个 pointwise 95% CI，会错误地把逐点区间当 simultaneous
band；实际只有 primary `epsilon/l_S=0.3125` 的解析值轻微超出 pointwise CI，但差仅约 `0.00293`。处理方式不是
放宽/删除物理趋势，而是保留全网格最大误差 `<0.012` 的预注册 gate，并单独要求两个 midpoint 的 exact 0.5 被 CI
覆盖。另收紧 validator，能重算 seed-summary 均值、趋势、解析差和 binding，拒绝同步篡改。
