## 1. 冻结结论

第一篇论文采用五层 claim ladder：

1. `CL1 simulation`；
2. `CL2 synthesis estimate`；
3. `CL3 board measurement`；
4. `CL4 board HIL/replay`；
5. `CL5 quantum experiment`。

当前最高证据层只到 `CL1=supported_bounded`。T24 frozen-set 与 T1.3.4 属于 simulation
层；Q4.20 parity 仍是 software emulation。当前没有综合/实现 report、bitstream 或真实板测，
T72 current-host verdict 仍为 `NO_GO_REAL_BOARD_HOST_OR_DEVICE_PATH_UNAVAILABLE`，也没有本项目
量子实验数据。

## 2. 防止伪升级的结构

五层是 claim-specific promotion ladder，不是把所有证据压成一个 maturity 分数：

- mock-backed software-HIL 明确归 `CL1`，不归 board HIL；
- T48 isolated host true `.tflite` runtime 是 `OL1` 正交 lane，不晋升综合/板测/HIL；
- T49/T71/T72 read-only gate/provenance 是 `OL2` 正交 lane，current-host `NO_GO`；
- analytical operation count 与 fixed-point software parity 不能冒充 synthesis；
- external quantum experiments 只能作为 literature fact，不能赋予本项目 `CL5`。

`PC01`--`PC08` 逐条冻结 allowed/forbidden wording。blocked claim 没有虚构
`current_level`，而是保留 `[Evidence needed: ...]`。

## 6. 对论文 claim 的影响

当前第一篇论文只能以 bounded simulation/software-HIL 为结果主层。真实 FPGA 的综合、资源、
时序、板测、HIL/replay 和量子实验必须等待对应任务产物；完成一个较高层的局部测量也不会
自动升级物理性能、统计充分性或跨场景泛化。
