3. 在 core 底层禁止 address>256、活动 bank 写入、非可信 bank commit、同 bank commit、版本回退/

   retired-bank drain guard；

   state word；主动淘汰了首版 144-bit 长组合 CRC；
8. 新增独立 Python 时序 reference、CXXRTL driver、1,681-cycle 审计、Source Data 和 11 类
   fail-closed rejection coverage；

## 深审与非简化实现检查

首版 production top 已经逐周期 0 mismatch，但深审发现 management state 的 144-bit 组合 CRC
会形成不必要的长管理路径；因此没有以“仿真通过”结束，而是改为冻结一致快照、每周期处理 1 byte、
18 cycles 完成，并重新跑完整 CXXRTL。第二轮虽然 0 mismatch，但 snapshot 等待消耗了 drain guard，
导致 rejection coverage gate FAIL；没有放宽 gate，而是修正测试时序并第三次重跑，最终 11 类拒绝
全部覆盖。core 原有 version>7 与 age>64 的 demo-scale hardcode、raw address 及 active-bank 写入也均
已在 production 路径消除。
