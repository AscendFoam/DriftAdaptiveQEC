## 冻结结果

- `CD1` FPGA deterministic/safety domain：逐周期 action、本地 event/health、active bank 与
  cycle-boundary commit；不等待 host。
- `CD2` host estimation/optimization domain：observed-window estimator、完整 inactive-bank
  proposal 和跨窗口/跨 run 优化；不进入 fast critical path。
- `TS1` per-subcycle、`TS2` window event/health、`TS3` host slow 三尺度有明确 I/O、deadline、
  atomicity 和 failure branch。

## 代码证据

- scheduler 真实执行顺序在 fast callback 前 commit；direct test 证明 callback 只见完整新版本；
- slow exception 会记录 `slow_update_failed` 且不 stage；
- bounded queue 在 depth=2 时 drop oldest，不停止 fast tick；
- fast budget violation 目前只记录，callback 仍执行；
- A/B bank 尚缺 schema/CRC/CAS/age/ack/rollback；
- mock `target_params` 只允许 explicit oracle/test lane，deployable estimator 禁读。
