## 状态

Done（2026-07-15）。

## 输入与通过标准

输入为 T1.1.2 periodic Gaussian LLR、canonical decoder cell、真实 `DecoderRuntimeParams/ParamBank` 和
T4.2.1 的 syndrome/phase/bank/worst-case-latency 要求。通过标准是 active K/b 可追溯编译、逐周期路径

## 实际完成

实现 slow compiler 与 integer runtime：从 active K/b 反解 mean/covariance，并生成两张 257-entry
X/Z Q9.12 ROM；10-bit ADC 用 8-bit address + half-bin-corrected 2-bit linear interpolation。image 绑定
ParamBank version、source SHA、CRC/SHA；5-stage pipeline 固定 latency 5 cycles、II=1，并锁存 in-flight
bank image。
