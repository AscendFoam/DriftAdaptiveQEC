# T2.4.3：fixed-point/LUT/parameter-bank error model

- **日期：** 2026-07-15
- **状态：** Done

## 输入与通过标准

- `LinearRuntime(Q4.20)`、`FastLoopEmulator`、`ParamBank` 和 AXI fixed-point helper；
- `physics.ideal_gkp_decoder.llr_1d` 的稳定 periodic Gaussian LLR；
- T2.4.1 双 latency boundary 与 T2.4.2 timing-fault state machine；
- 生成 ADC/replay input、LUT、LLR、threshold、state estimate、update granularity 的
  precision--resource--LER 曲线，并覆盖 parameter-bank error；不得冒充 synthesis/board。

## 执行方案与实际完成

1. 强化共享 `FixedPointFormat`：explicit signed code、word width、ties-to-even、decode、saturation、
   nonfinite/range failure；保持现有 Q4.20 语义。
2. 新增 bounded ADC/state code、3--8 address-bit LUT、Q3.F LLR、Q0.F threshold 和 observed-only
   circular state estimator。
3. 实现 double-buffered integer `LUTParameterBank`，故障在 sign/MSB/stale/torn 的真实 code/image
   上发生，不用 float perturbation 冒充 bit fault。
4. 预注册 6 个 OAT axes × 6 levels、5 个 joint profiles、4 类 bank faults；8 paired seeds ×
   65,536 samples，共 368 runs。
5. 资源只计算 exact representation/storage/replay/update/comparator bit proxy；所有 synthesis fields
   保持 null。
6. nature-figure Python contract 生成 183 mm SVG/PDF/600-dpi TIFF/PNG；figure audit 绑定 source
   artifact 与输出 hashes。该工作流促使 severe-fault gate 升级为相对 no-fault base 的 paired CI。
