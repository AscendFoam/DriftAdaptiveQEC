## 执行方案

实现只读、hash-bound verdict runner，不新增随机样本、不重跑或重选 T5.1.2/T5.1.3 数据。runner 统一适配
mapping/list/gate-summary 三类 parent gate schema，核验 parent artifact/source/code/composite hashes；从 parent
原位提取 executed comparators、Holm family、static/calibration tail 和 T4.4.5 scope，再按八项逻辑合取选择
唯一分支。

另设 semantic validator 和 mutation suite，防止直接编辑 JSON 把 false verdict 改成 strong、把 controller
证据跨用为 decoder、删反证或降低 reopen contract。
