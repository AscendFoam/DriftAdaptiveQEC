## 实际完成内容

### 1. 独立 dense split-channel 物理求解器

- 新增 `physics/phase9_backend_b.py`，状态仍为 finite-Fock oscillator × `g/e/f` qutrit joint density，但所有 operators、partial trace、pulse/sense/action Hamiltonian 和 channel 都在 B 内独立构造。
- 每个 segment 使用 midpoint Hamiltonian 的 dense unitary half-step、解析噪声 channel、第二个 unitary half-step组成 Strang split。
- pure-loss 直接实现有限 Fock Kraus \(A_l\)；`e→g`、`f→e`、`g→e` 使用两 Kraus amplitude channel；oscillator/qutrit dephasing 使用解析 Gaussian Schur multiplier。
- segment 在任何舍入清理前检查 raw trace；故障测试把 channel 变成 `2ρ` 后必须抛出 trace-preservation error，禁止以事后归一化掩盖非保迹实现。

### 2. 独立 RNG、IQ likelihood 与 measurement backaction

- round random record 由 `BLAKE2b(BACKEND_B_RNG_ID|seed|round)` 地址化到 Python `random.Random`，normal variate 由手写 Box–Muller 生成。
- 静态审计禁止 `phase9_backend_a`、`fock_density_model`、`fock_sbs_cycle`、`finite_energy_gkp`、`np.random` 和 `default_rng` 出现在 B 的运行时代码路径。
- IQ 从物理 ancilla population mixture 采样；对整段 I/Q samples 计算三态 product complex-Gaussian log likelihood，再以对应对角 Kraus operator更新 joint density。
- 观测强制标记为 `synthetic_backend_b_analog_pre_frontend`；integrated I/Q 必须等于 sample mean，posterior、leakage confidence 与 truth record 必须一致。
- oscillator Fock 0/1 的 syndrome level TV=`0.16483670`；条件 measurement 对 oscillator superposition 的 backaction trace distance=`0.20911314`，排除了 label-noise demo。

### 3. reset、leakage 与 action-conditioned drift

- reset 由完整 success/failure quantum instrument实现；large-reset 得到 `P(g)=1`，forced failure 和 no-reset 均保持 `P(f)=1`，hidden outcome 与 noisy acknowledgement 分离。
- 共同随机 record 下 X 相对 IDLE 产生 action-induced `f` population差=`0.51468005`、joint-state trace distance=`0.11347383`、drift L2=`0.00342637`。
- drift 仍是 `drive_q/drive_p/readout_i/readout_q/leakage_detuning` 五维状态，但其更新函数和 RNG 均为 B 独立实现。

### 4. 独立六态 evaluator

- B 不调用既有 GKP projector，而用独立 squeezed coherent-comb construction，在 Fock basis 内生成两列正交 isometry。
- 六个 Pauli eigenstate 的 minimum initial fidelity=`0.9999999999999999`。
- evaluator 强制检查 target label 与 target density 一致，Bloch vector 与 corrected density 一致，logical error 必须由 fidelity `<0.5` 唯一导出。
- 相同 state/action/random record 下，改变或删除 evaluator 不改变 joint density 和 IQ；truth/future/backend-A output 均不在 `step` API。
