## 输入与通过标准

输入为 T4.3.1 cadence、T4.3.2 full-image atomic bank/ack/readback、T4.2 bit-accurate MAP/health/event/frame fallback 和 T2.4.2 legacy timing-fault lessons。通过标准是 drift、burst、leakage、host timeout、通信中断、坏包和更新竞态下每周期动作定义、blocking fault 不纠错、bank/frame 有界、fallback/recovery/ack 可追溯；不得把 software stress 写成 RTL/board 或物理稳定性。

## 实际完成

实现 `ClosedLoopFaultRecoverySupervisor`：逐周期组合 atomic commit 与 bit-accurate fallback；ack 丢失保持 uncertain 并阻止新 writer；post-commit guard 保存 LKG；恢复用 prior LKG contents 的新单调 version republish，不做 version rollback；timeout/stale 可由 LKG 或 fresh confirmed candidate 在 guard 后恢复。相同 version 但未注册到 fast path 的 image fail closed。

深审计修复三处非 demo 问题：短配置构造不应被无关 production residency 预构造阻塞；24k 首轮发现单次 commit 在 host 在线时也会超过 8192 freshness，改为完整 monotonic cadence refresh；坏包后 fresh candidate 虽已健康，旧 recovery flag 未在无故障 guard 后关闭，现仅对 stale/timeout 原因清除。另将 implementation hash 与无关 public exports 解耦，public API 由 direct test 锁定。
