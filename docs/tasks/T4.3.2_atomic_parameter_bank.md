# T4.3.2：实现双参数库、原子切换和 hysteresis

## 状态

Done（2026-07-15）。

## 输入与通过标准

输入为 T4.2.1 完整 parametric MAP-LUT image、T4.2.3 trusted image/health contract、T4.2.4 bit-accurate pipeline 和 T4.3.1 cadence。通过标准是参数携带 version、CRC/SHA、cycle timestamp 和 provenance；partial/torn/stale/race payload 不激活；切换只发生在安全边界；hysteresis、CAS、ack/readback 与 in-flight version latch 可复验；不得冒充 RTL/board 或自动回滚。

## 实际完成

实现 thread-safe `AtomicParameterImageBank`、canonical image serialization、带 anti-replay transaction ID 的 sealed manifest、A/B valid slots 外 transfer buffer、out-of-order/idempotent chunk、complete-image finalize、apply/safe-boundary/minimum-residency commit、两窗同 key hysteresis、CAS/freshness recheck 和 ack/readback verification。runtime public API 同步导出 T4.3.1 cadence 与新原子库。

深审计补了两项初版遗漏：一是 header 中合法范围字段 bit flip 不能只依赖 payload integrity，因此增加 manifest CRC32/SHA256，并独立负测 SHA 自身篡改；二是 thread-safe 声明扩展到公共只读属性。实现仍明确保留 legacy scheduler/ParamBank，T4.3.3 前不声称全 runtime 已迁移。

## 验证与非 demo 审计

17/17 production gates、7518-row Source Data：穷举 3745 个 proper prefix 与 3745 个单字节翻转，另有 10 个 forward/reverse chunk/order cases、15 个 semantic negatives、A:v0→B:v1→A:v2、T4.2 pipeline v0/v1 latch、two-writer race、两次独立 evidence hash。所有 incomplete/corrupt/negative case 保持 active v0，partial 阶段 inactive slot 未发布。

focused `37 passed`，T4.2/T4.3/双域相邻回归 `115 passed`；显式全量 `tests/` 为 `1441 passed, 14 skipped, 4 failed`，4 个失败仍仅是 R-N012 缺失旧 FR8/P4 文档。生产 validator 独立 CLI 为 PASS，JSON 绑定实现源码与 CSV SHA256。
