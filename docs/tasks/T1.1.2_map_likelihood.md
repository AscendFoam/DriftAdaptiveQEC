## 1. 输入模型与边界

本任务延续 T1.1.1 已与当前 `physics/` 对齐的 operational convention：

\[
\lambda=\texttt{LATTICE\_CONST}=\sqrt{2\pi}.
\]

输入 `s` 是已经 centered 的 modular syndrome，必须满足
`s in [-lambda/2, lambda/2)`；代码不会静默 wrap 越界输入，因为 wrap 时跨过的
cell 会改变 logical parity。旧进度日志中曾写“默认 `sqrt(pi)`”，那是与当前主表、
共享常数和当前代码不一致的历史记录，不能作为本轮验收依据。若使用论文中的
canonical-quadrature `sqrt(pi)`/`2sqrt(pi)` convention，必须同时缩放坐标、均值和
噪声标准差。

本任务的隐藏位移模型为

\[
X\sim\mathcal N(\mu,\sigma^2),\qquad
X=s+k\lambda,\quad k\in\mathbb Z.
\]

`k mod 2` 是单轴 logical coset。该模型是 ideal syndrome-level reference，不包含
finite-energy envelope、measurement noise、loss/outlier mixture、二维相关性或多轮
滤波；这些由 T1.1.3、T1.2 和后续 drift tasks 覆盖。

## 2. 偶/奇陪集似然与 LLR

对 `b in {0,1}`，periodic Gaussian coset likelihood 定义为

\[
L_b(s)=\sum_{k\bmod 2=b}
\frac{1}{\sqrt{2\pi}\sigma}
\exp\left[-\frac{(s+k\lambda-\mu)^2}{2\sigma^2}\right].
\]

给定 even prior `pi_e`，代码统一使用

\[
\operatorname{LLR}(s)
=\log L_0(s)-\log L_1(s)
+\log\frac{\pi_e}{1-\pi_e}.
\]

因此：

- `LLR > 0`：MAP 选择 even；
- `LLR < 0`：MAP 选择 odd；
- 精确 `LLR = 0`：固定选择 even，保证重放确定性；
- `P(even|s)=sigmoid(LLR)`，`P(odd|s)=1-P(even|s)`；
- `confidence=|P(even|s)-P(odd|s)|`，不把 raw density 冒充 posterior。

非零 `mu` 可以跨越多个 lattice cells；代码按全局 alias index 判断 parity，而不是
先把 `mu` 取模后丢失陪集信息。`mu` 平移一个 `lambda` 时 even/odd likelihood 必须
交换，这一物理恒等式已有直接测试。

## 3. 数值实现

### 3.1 稳定 alias 求和

每个 observation 先定位最接近 `mu` 的 alias，再向两侧覆盖至少
`tail_sigma * sigma`（默认 10 sigma）并额外保留两个 cells。偶/奇分支分别使用
log-sum-exp：

\[
\log L_b=m_b+\log\sum_{k\bmod2=b}\exp(a_k-m_b).
\]

因此小噪声时远端 odd density 即使在 `exp(log L_1)` 后下溢为 0，LLR 仍保持有限；
MAP 不通过两个 raw likelihood 相除。posterior sigmoid 也按 LLR 正负分支计算，避免
`exp(large)` 溢出。

### 3.2 输入与表示防护

- `sigma` 必须有限且严格为正；
- `prior_even` 必须严格位于 `(0,1)`；
- `mean` 必须有限并与 syndrome shape 可广播；
- `lattice` 和 `tail_sigma` 必须有限且为正；
- syndrome 必须位于冻结的半开区间；
- 超出可安全表示 `int64` lattice index 的有限大数会显式 `ValueError`，不允许静默
  cast overflow；底层浮点 overflow warning 被转换为统一的 API 错误。

## 4. API 与模式契约

新增/完成接口：

- `coset_likelihood_1d`：even/odd raw likelihood 或 log-likelihood；
- `llr_1d`：稳定 even-vs-odd posterior LLR；
- `map_decode_1d`：同时返回 hard parity、logical flip、LLR、posterior、confidence 和
  两个 log-likelihood；
- `decode_1d`：三模式统一入口。

三模式输入语义故意不混用：

| mode | 输入 | 输出 | `sigma` |
| --- | --- | --- | --- |
| `standard` | raw displacement | `StandardBinningResult` | 禁止传入 |
| `map` | centered syndrome | `MAPDecodeResult` | 必须显式传入 |
| `soft` | centered syndrome | even-vs-odd LLR | 必须显式传入 |

若 `standard` 静默接收 `sigma` 或 MAP 静默采用默认噪声，就会把两个不同问题混成
表面统一的 demo API，因此代码显式拒绝这两种用法。
