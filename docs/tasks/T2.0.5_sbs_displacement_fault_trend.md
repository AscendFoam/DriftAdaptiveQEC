## 1. 输入与执行方案

输入包括 Sivak 2023 Fig. 4(c) caption、正文第 137/139 行、T2.0.2 error-space instrument、T2.0.3 hidden/observed/reset kernel，以及任务板对非单调 amplitude→e-run/recovery-depth、seed、容差和失败诊断的要求。

执行前冻结三条关键语义：

1. 自变量是 `epsilon/l_S`，逻辑操作间隔为 `0.5`；
2. 到最近逻辑操作的距离在 `0`/`0.5` 为零，在 `0.25` 达最大，不能错误实现为“位移越大 syndrome 越长”；
3. position displacement 由 Z syndrome 检测，chronological `(X,Z)=(g,e)`，full-cycle Kraus label 为 `K_eg`。

## 2. 实际完成内容

- 实现对负位移和多逻辑周期均成立的 periodic nearest-logical-operation distance；
- 用显式 `Binomial(max_depth=6,p=distance)` assumption 生成初始 recovery depth；
- recovery trajectory 直接消费 T2.0.2 四 branch transition matrices；
- observed trajectory 逐 constituent 消费 T2.0.3 preparation/readout/reset kernels；
- 分开记录 initial depth、ideal/observed same-quadrature max e-run、restricted recovery time、recovered fraction 与 affected/unaffected `P_e(t)`；
- 预注册 9 幅度×4096 shots×20 cycles、simulation/bootstrap seeds、500 次 95% percentile bootstrap 和 10 个 acceptance gates；
- JSON 保存完整 trace statistics、tolerances、check diagnostics、source anchors 和 limitations；CSV 保存紧凑趋势表；
- protocol hierarchy 新增三条一手 source anchor 和 fault diagnostic contract。

## 3. 反简化检查

没有用手写 `sin` 曲线或固定 PASS 表冒充仿真：

- `K_eg[0,1]=0.88`、`K_gg[1,1]=0.12`，`K_ge/K_ee=0` 的 position-fault kernel 有 direct test；
- observed class 通过 full preparation/readout/reset categorical sampling，而非把 ideal e 原样复制；
- sampled mean depth 与独立解析 `E[D]=6d` 对齐；restricted recovery time 与负二项 `E[T]=D/0.88` 对齐；
- midpoint/endpoint 使用 bootstrap interval separation，不只比较点估计；
- 左右分支分别做 Spearman gate，并做镜像误差门；
- X 未受影响象限是独立 negative control，可捕获 label/quadrature mixing 和 reset carry；
- changed-seed 与 X-fault variant 保持结论；把 false-e/e-detection 均改为 0.5 会产生具名 gate failures；
- committed production JSON 必须与同 seed 全量重跑逐字段相同。
