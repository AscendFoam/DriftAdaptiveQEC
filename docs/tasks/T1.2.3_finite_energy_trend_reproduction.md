## 1. 要复现的有界趋势

本任务不复现某篇论文的绝对 fidelity 数字，而是在明确的 syndrome-level effective
model 中复现以下已知 qualitative behavior：

1. finite-energy syndrome uncertainty 较大时，直接用 measured syndrome 全量纠正
   （standard gain `g=1`）会把 measurement/peak uncertainty 注入 data；
2. 在同一模型中，`0<=g<1` 的 state/noise-aware shrinkage action 可降低 continuous
   residual MSE，并在较宽 finite-energy peaks 时降低 logical parity error；
3. 当 `Delta` 下降、finite-energy peaks 变窄时，fitted gain 向 1 方向移动，shrinkage
   相对 `g=1` 的 logical advantage 收缩并最终低于当前 Monte Carlo 分辨率。

这满足任务板“至少一条 finite-energy 或 memory-assisted trend”的要求；没有把它写成
完整 approximate-GKP recovery 文献数值复现。

## 2. Effective model 与 action

隐藏 data displacement 为

\[
x\sim\mathcal N(0,\sigma_{ch}^2).
\]

finite-energy syndrome noise 的标准差直接来自 T1.2.1 damped-projector state 的
隔离 probability peak variance：

\[
\sigma_\Delta^2=\frac{\tanh(\Delta^2)}{2}.
\]

观测和 centered syndrome 为

\[
y=x+n_\Delta,\qquad
n_\Delta\sim\mathcal N(0,\sigma_\Delta^2),
\]

\[
s=y-\lambda\left\lfloor\frac{y}{\lambda}+\frac12\right\rfloor.
\]

correction action 与 residual data shift 定义为

\[
c_g=g s,
\qquad
r_g=x-c_g.
\]

- standard：`g=1`；
- shrinkage：`g` 在 `[0,1]` 内，以独立训练样本最小化 `E[(x-gs)^2]`；
- logical outcome：对 held-out `r_g` 用 T1.1.1 cell-parity standard binning 判定。

这个 action 修正的是 data truth `x`，syndrome noise 只进入观测；没有错误地把
`x+n_Delta-gs` 当 residual data state。

## 3. Gain fitting 与 wrapping

训练集上的 unconstrained least-squares gain 是

\[
g_{fit}=\frac{\sum_i x_i s_i}{\sum_i s_i^2},
\]

再 clip 到 `[0,1]`。如果忽略 modular wrapping，linear-Gaussian MMSE gain 为

\[
g_{unwrapped}=\frac{\sigma_{ch}^2}
{\sigma_{ch}^2+\sigma_\Delta^2}.
\]

代码同时报告两者。默认场景中 fitted gain 低于 unwrapped gain，因为 centered
syndrome 已丢失 alias index；不能把 unwrapped 公式冒充 periodic decoder optimum。

## 4. 防止选择偏差的 protocol

默认冻结：

- `Delta=(0.60,0.50,0.40,0.30,0.22)`，按大到小；
- `sigma_ch=0.18 lambda`；
- train `n=120000`；
- held-out eval `n=300000`；
- seed `20260714`；
- 所有 Delta 共用相同 standard-normal draws（common random numbers），降低趋势差分
  方差；
- gain 只在 train 上拟合，所有报告指标只来自 eval。

每个 eval sample 同时计算 standard 与 shrinkage outcomes。logical gain 的 paired
变量为

\[
d_i=1[standard\ wrong]-1[shrinkage\ wrong],
\]

并报告 paired standard error、95% CI、standard-only/shrinkage-only wrong counts 与
McNemar z。没有用两个独立样本 error bars 夸大显著性。

## 7. 反简化/伪实现复核

| 检查 | 结果 |
| --- | --- |
| 是否预设一个随 Delta 变化的 gain | 否；每个 gain 由独立 train samples 闭式拟合 |
| 是否 train/eval 同集 | 否；12 万 train、30 万 held-out eval |
| finite-energy sigma 是否随手指定 | 否；直接读取 damped-projector amplitude variance/2 |
| 是否只报告 MSE | 否；同时报告 cell-parity logical error、paired CI/McNemar |
| 是否只报告 logical error | 否；最后两点用 MSE 揭示连续 action 仍不同 |
| 是否用两个独立 MC 比较 | 否；standard/shrinkage 使用同一 eval samples |
| wrapping 是否被忽略 | 否；fit 使用 centered syndrome，并同时报告 unwrapped reference |
| 是否只跑一个 Delta | 否；五点 sweep，趋势由机器检查 |
| 是否冒充完整物理复现 | 否；scope 固定为 syndrome-level effective model |

结论：复现是 train/eval 分离、有统计量和失败分支的趋势 harness，不是手写一张单调表。

## 8. 对论文 claim 的影响

允许声称：在已冻结的 syndrome-level effective finite-energy-noise model 中，MSE-fitted
shrinkage correction 在宽峰 regime 优于 standard gain=1，且 logical advantage 随
Delta 降低而收缩。不能声称复现了某实验的绝对 fidelity、完整 damped-projector
recovery、memory-assisted decoder、loss/ancilla dynamics 或真实硬件趋势。
