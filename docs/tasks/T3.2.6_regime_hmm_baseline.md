# T3.2.6：HMM / change-point regime baseline

- **日期：** 2026-07-15
- **状态：** Done

## 输入与通过标准

- T2.1.1 observed/truth-separated syndrome stream、T3.2.2/T3.2.3 window budget 经验、T1.4.3
  hidden-truth contract 和 T3.2.6 task row；
- 输出 normal/burst/leakage/calibration-shift posterior；
- 训练/validation/evaluation 严格隔离，online API 不读取 truth；
- 与 memoryless comparator 使用同一 emission/raw window，并冻结未来 CNN 的共享 input/cadence/
  operation-state budget；
- 不把 host float HMM 写成 FPGA、decoder 或 controller。

## 实际完成

1. 实现 32×8 observed window、14-summary fixed featurizer、supervised full-covariance Gaussian emissions、
   smoothed four-state transition 和严格 causal forward recursion。
2. 分离 trajectory initial prior 与 training occupancy class prior，避免 memoryless comparator 使用错误
   先验；calibrated output 不回灌内部 filter state。
3. 构建 normal/burst/leakage/calibration-shift semi-Markov trajectories，使用 3/3/8 disjoint seeds；
   deployable/truth trace 分别 hash。
4. 以 validation NLL 扫描 54 个 covariance/transition 组合和 10 个 temperatures；两轮扩大边界后，
   四个 selected hyperparameters 均为内部点。
5. 对 static prior、same-emission memoryless、causal HMM 报告 accuracy/F1/NLL/Brier/ECE、四类 recall、
   transition delay、false-switch rate 和 seed-cluster CI。
6. 固定 `4096 MAC + 4096-byte float32 state` 的未来 CNN comparator ceiling；HMM 为 800 MAC proxy、
   3584-byte proxy，明确不是 bit-accurate/综合/板测。

## 验证与结果

- 全 simulator 229,376 cycles；evaluation 131,072 cycles / 4,096 windows/rows / 8 unique
  deployable + 8 truth hashes；
- HMM/memoryless accuracy `0.846191/0.660889`；accuracy gain CI `[0.173322,0.197284]`；
- HMM/memoryless NLL `0.446282/0.847796`；NLL gain CI `[0.366352,0.436676]`；
- 四类 recall 最低为 burst `0.807395`；false switch `0.108816`，但 detection delay `1.802333`
  windows，高于 memoryless `0.573579`；
- 15/15 machine gates、37 focused tests、51 focused+governance、131 adjacent；显式全量为
  `1083 passed, 4 skipped, 4 failed`，4 个失败均为已登记 R-N012 的两份历史治理文档缺失；源码 compile 通过；
- selected covariance/smoothing/HMM-temp/memoryless-temp 为 `1/10/0.8/0.6`，全部为 expanded grid 内点。
