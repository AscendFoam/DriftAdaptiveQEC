## 反简化实现复核

本任务不是只把三个 legacy label 改名：

1. migration 从 parent 动态提取全 29 行，并按 lane 区分重名 null output；删一行、重复一行或把 tail/no-go 映到 GO 都 fail closed。
2. external 不是 registered 状态的别名；eligible=0、任一九字段失败、unresolved comparator>0 或缺 independent audit 均返回 incomplete null。
3. official、physical 和 measured 不接受低 evidence grade 替代；paper-constrained、simulation、CXXRTL/P&R、recorded replay 与六周期 fast-path 均有直接攻击测试。
4. predicate 使用 exact bool、64 位小写十六进制 hash、正整数计数和 exact integer zero；空字符串、伪 hash、bool-as-int、float、NaN/Inf、对象或非正计数均 fail closed。
5. 通用 state evaluator 永不产生 GO/value：完整非 fixture mapping 也只能返回 `SCHEMA_COMPLETE_NONPROMOTIONAL_NULL`；27 条 fixture 均无法填充 current result。
6. 撤销传播由真实函数执行；verifier 精确重算 closure、sequence 与 previous-entry chain，并强制消费外部固定的 prior snapshot anchor。即使篡改者重建全部行 hash，仍无法绕过原 anchor；broader state 回 null，不用 NO-GO 掩盖失效，也不允许新 comparator 静默保持旧 external SOTA。
7. protocol PASS 与 performance fields 结构上分离；报告中所有真实 LER/lifetime/HIL/rank/official/Puviani/physical/external 字段仍为 typed null。
