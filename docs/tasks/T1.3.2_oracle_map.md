## 1. Oracle 定义与边界

本任务的 oracle 是 synthetic syndrome/displacement model 内的不可部署 Bayes reference：
它在每个时间步直接读取隐藏真值 `DriftState` 的

- `mu_q, mu_p`；
- `sigma_q, sigma_p, rho`；
- `p_outlier, outlier_scale`；
- 可选、显式声明的 loss displacement proxy。

实际部署算法看不到这些真值，必须从历史 syndrome/readout 中估计。因此该 oracle 只能作为
T1.3.3 regret/oracle-gap 的分母参考和后续不可部署上界，不能列入 deployable 方法。

它也不是 bosonic recovery 的 fundamental/channel bound：当前仍是 square-GKP periodic
Gaussian-mixture observation model，没有 finite-energy envelope deformation、ancilla/reset/
leakage、完整 sBs protocol 或 coherent/non-Pauli channel。

## 2. Periodic Gaussian-mixture likelihood

给定 centered syndrome `s`、逻辑陪集 `b=(b_q,b_p)` 和晶格周期 `lambda`，core component
为

\[
L_b^{core}(s)=
\sum_{k_q\bmod 2=b_q}\sum_{k_p\bmod 2=b_p}
\mathcal N_2(s+\lambda k;\mu_t,\Sigma_t).
\]

outlier component 使用同一均值和 `a_t^2 Sigma_t`。完整 likelihood 为

\[
L_b^{oracle}(s)=
(1-p_t)L_b^{core}(s)+p_tL_b^{outlier}(s).
\]

实现复用 T1.1.3 已验证的 2D correlated periodic alias sum，但分别以各 component 的
marginal sigma 决定 rectangle truncation；`tail_sigma` 对 q/p marginal omissions 提供
union-bound 控制。两个 component 在 log domain 用 `logaddexp` 合并，避免宽尾/小权重
下溢。

以下退化分支是精确分支，不依赖近似：

- `p_outlier=0`：严格等于 core correlated MAP；
- `p_outlier=1`：严格等于 outlier covariance MAP；
- `outlier_scale=1`：任意 p 严格等于单 component MAP。

alias workload 继续受 T1.1.3 的一千万 evaluation 安全门约束；极宽 covariance 或过大 batch
会在分配前 fail closed，不会静默缩短尾部。

## 3. Posterior、parity 与 action

默认不额外加入 logical prior。若调用方提供独立于当前 noise model 的历史 class prior，
必须是严格正的 `2x2` 概率表。posterior 为

\[
P(b\mid s,\theta_t)=
\frac{L_b^{oracle}(s)\pi_b}
{\sum_{b'}L_{b'}^{oracle}(s)\pi_{b'}}.
\]

返回值包括：

- 四类 `posterior[b_q,b_p]` 和 log likelihood；
- hard parity、`logical_class=2*b_q+b_p`；
- confidence：最大与次大 posterior 差；
- `logical_action`：`00->I`、`01->Z`、`10->X`、`11->Y`；
- `analog_correction`：要从 data displacement 中减去的 centered syndrome；
- state step/source、mixture weights、loss model 和
  `nondeployable_full_state_oracle` evidence label。

这里 q parity 映射 logical X、p parity 映射 logical Z，与 T1.2.2 logical channel 一致。
Pauli action 表示逻辑 frame correction/追踪；analog correction 与 logical action 没有混成
一个连续 displacement 数字。

## 4. Loss policy

默认 `loss_model="separate"`：`loss_gamma` 留作独立 hidden truth，不会被静默塞进
Gaussian likelihood。若调用方明确选择
`loss_model="additive_displacement_proxy"`，则按旧 `CombinedNoiseModel` 口径向两个
components 各自加入

\[
\Sigma_{loss}=\frac{\gamma}{2}I.
\]

独立 loss contribution 不随 outlier scale 放大。结果记录所选 policy；不存在隐式 fallback。
该 proxy 仍不能替代 photon-loss channel 或 finite-energy state evolution。

## 5. Time-aligned trajectory

`oracle_map_trajectory(syndrome[t], states[t])` 要求时间长度严格一致，逐步读取完整 state，
返回堆叠 posterior/parity/action 和 `state_steps/state_sources`。它不接受 legacy
`LegacyRunWithDriftAdapter`，从接口层阻断 R-N016 的 scalar RMS 信息丢失。

step-drift 测试使用小噪声、`change_step=3`、mean q 从 0 跳到一个 lattice cell：

```text
logical class:  [0, 0, 0, 2, 2, 2]
logical action: [I, I, I, X, X, X]
```

这直接证明 trajectory oracle 消费了当步 truth，而非只读取初态或全局平均参数。

## 6. 数值验证

### 6.1 独立 alias 穷举

测试不调用 oracle/ideal helper 的求和逻辑，而是在 `[-30,30]^2` alias grid 上逐点计算
两个 normalized bivariate Gaussian densities、按 parity 过滤并手工混合。四个 coset
likelihood 与 oracle 的差均小于 `5e-15`。

另验证一个 lattice 的 q-mean translation 只交换 q parity 两行，不交换 p parity。

### 6.2 Monte Carlo posterior calibration

固定模型：

- `mu=(0.30,-0.20) lambda`；
- `sigma_q=0.32 lambda`、`sigma_p=0.45 lambda`、`rho=0.60`；
- outlier probability 0.12、scale 2.5；
- 40000 个独立 mixture samples，seed 77。

从真实 displacement 用 standard cell index 得到 parity truth，再只把 centered syndrome
交给 oracle：

| 量 | 数值 |
| --- | ---: |
| empirical oracle error | 0.318725 |
| mean predicted Bayes risk `1-max posterior` | 0.318930 |
| difference | -0.000205 |
| paired residual SE | 0.002204 |
| z | -0.093 |

经验 error 与 posterior 预测 Bayes risk 一致，避免“posterior 归一化但概率校准错误”的伪实现。


## 7. 反简化/伪实现复核

| 检查 | 结果 |
| --- | --- |
| 是否把 covariance 压成 scalar sigma | 否；直接做 2D correlated likelihood |
| 是否忽略 mean | 否；跨 cell mean translation 恒等式已验证 |
| 是否把 outlier mixture 改成平均 sigma | 否；两 component 分别 alias sum 后 log-sum-exp |
| 是否只测 `p=0` | 否；独立穷举和 4 万 MC 均使用非零 mixture |
| posterior 是否只检查和为 1 | 否；与独立 MC Bayes risk 校准 |
| trajectory 是否复用单一 state | 否；step truth 使 action 在精确边界改变 |
| loss 是否被悄悄 Gaussian 化 | 否；默认 separate，proxy 必须显式选择并记录 |
| oracle 是否被包装成 deployable | 否；结果和文档固定 nondeployable label |
| 是否冒充 fundamental recovery bound | 否；限定为 assumed synthetic model 内 Bayes reference |

结论：oracle 是 mean/covariance/mixture-aware、数值稳定且有独立概率校准的 reference，
不是把 static MAP 改名或传入一个 scalar truth 的 demo。

## 8. 对论文 claim 的影响

允许声称：在已定义的 synthetic periodic Gaussian-mixture model 内，实现了逐时读取完整
hidden state 的不可部署 Bayes oracle，并通过独立 alias sum 与 posterior-risk calibration。

不允许声称：oracle 是真实硬件可用算法、完整 finite-energy recovery optimum、channel
recovery bound，或包含未经显式 proxy 的 photon-loss dynamics。
