## 实际完成内容

新增 `route_a_causal_headroom.py`，逐 decision 独立复算全部 1,464 条 V4 formal trajectory，并逐条对回 observed/truth SHA、五方法 Pauli window counts 和 error-trace SHA。由真实对齐 actions 重新聚合 family、cell、activation-period、per-decision oracle 与 pairwise disagreement，不用 stored aggregate 反推。

建立全新 non-formal `v5_headroom_development`：31 个 off-grid cells、6 个新 seed clusters、186 条 trajectory。实现 leave-one-seed-cluster-out 外层与训练 seeds 内部 CV 的 strict-causal selector；在线只消费 Window sufficient state、expert causal state 和上一 activation period hard disagreement，不消费 family/cell/truth/future，也不重复 MAP。实现 36 个冻结 one-hot/pair/uniform posterior mixture candidates、held-out fixed-mixture 与 truth-privileged candidate-set oracle，并在 2,000-decision真实 activation 与 8,192 MAC/B matched caps 下分解 regret。

首轮深审发现，若用 expanded candidate oracle 相对 baseline 的 overall `17.61%` 作为 action-space 门，会把已有 hard experts 的 truth-privileged per-decision switching 错算成 posterior-mixture 增益。已修正为纯增量：mixture 超出 hard decision oracle 仅避免 9 个错误，相对 baseline 为 `0.02549%`；同时删除 selector 中预算未计入的重复 MAP history decode，改为 sufficient-state reuse，完整重跑 development v2。

最终 nested selector 相对训练 fold 选择的 strongest baseline 为 `-0.2322%`，held-out fixed posterior mixture 为 `+0.4587%`，均不足；verdict 为 `NO_GO_V5_INSUFFICIENT_ACTION_SPACE_HEADROOM`。
