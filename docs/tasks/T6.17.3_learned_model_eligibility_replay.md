## 深度检查与修正

- 初版只列 13 个家族。对仓库内所有已登记 `.pt/.npz/JSON` model artifacts 做反查后，发现遗漏 T3.2.7 latest-outcome FNN、T3.2.10 learned recurrence 和 T4.1.5 distilled student。没有因它们明显 ineligible 而省略，已扩成 16-family universe，并新增 parent report/checkpoint live bindings。
- 初版 G04 只重算 mismatch list，没有验证已存 `signature_checks.match`；人工把一个 false 改成 true 仍可能绕过。现已逐字段重建完整 `{required, actual, match}` 并 exact 比较。
- 初版 G10 只要求五次 repeat hashes 相同，没有要求主 `output_sha256` 等于 repeat hash；现已加入等式，伪造主 hash 会 fail closed。
- 初版 G11 对 Puviani source 使用不成立的单-row查找，可能抛 `StopIteration`；现按 Wang/Sivak 的 absent checkpoint 和 GQF unreplayed 状态分别验证。
- 相邻治理测试曾发现任务板摘要把锁定边界短语缩写成“9.9 dB threshold”；已恢复为 ``9.9 dB` full surface–GKP threshold`，防止 gate-level reproduction 被误读为 outer-code threshold。
- focused test 的一次失败来自测试期望遗漏了每个 null metric 的 `INELIGIBLE_TASK_SIGNATURE` reason；实现输出正确，测试已加强为四字段 exact equality。
- 未因“没有 eligible checkpoint”把 task 降为清单 demo：真实执行了可重放 checkpoint、逐样本 raw output、重复 hash、父任务 exact comparison、全预算/签名投影和 16 类针对性篡改。
