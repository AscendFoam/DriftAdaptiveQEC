- **日期：** 2026-07-15
- **状态：** Done

## 输入与通过标准

- T2.3.4 的 joint cavity--ancilla differentiable trajectory；
- T2.3.5 的 reward/score Feedback-GRAPE gradient；
- T2.3.6 验证可运行的 72,913 参数 GRU teacher envelope；
- Puviani *et al.*, *Phys. Rev. Lett.* **134**, 020601 (2025) 及官方 GQF
  实现中的 MF/NMF 架构与训练协议；
- 任务板要求：在同一 simulator、相同噪声、相同 10-cycle 物理时间下比较
  standard、memoryless MF 与 NMF；失败时不得保留性能 claim。

## 执行方案与实际完成

1. 冻结 `T237-V3-STRICT-SPLIT-AREA-EQUIVALENT-10-CYCLE-LIFETIME` 合同，分别使用
   train、validation、test、cutoff-confirmation seed，禁止训练数据参与挑模或评分。
2. 实现论文尺度的 MF Dense256--256--15（70,159 参数）与
   NMF GRU10--Dense256--256--15（72,853 参数），采用 train-only no-grad warm-up、
   Feedback-GRAPE、EMA baseline、Adam、gradient clipping、residual/slew penalty。
3. 每个 family 独立训练 5 个 agents，共 `300 x 6 x 5 = 9,000` 条 update
   trajectories；只用 validation history 选择 checkpoint，再用 8 个 test seeds、每 agent
   512 条轨迹评分，并用 4 个独立 confirmation seeds、每 agent 128 条轨迹检查 cutoff 16。
4. 使用 finite-horizon area-equivalent lifetime 作为主指标；log-linear lifetime 仅作非指数
   诊断。同步报告 logical-Z、physical fidelity、code-space survival、ancilla `p(g)`、trace、
   Hermiticity、PSD、控制幅度与 slew。
5. 加入 hidden-reset 反事实 lane、paired bootstrap、逐 agent 配对、5/5 gate、checkpoint
   schema/source/config/model hash、atomic write/resume 和 artifact 复核。
6. 首轮 V2 审计发现 score baseline 由 validation final fidelity 初始化；尽管理论期望不变，
   finite-batch 更新仍受 validation 影响。该批结果全部作废并移至
   `runs/t237_v2_validation_baseline_audit/`，V3 从严格 train-only baseline 重新训练。
7. 正式 V3 运行在第八个 agent 后遭遇 Windows `os.replace` 临时拒绝；逐模型 SHA、source
   hash、schema 和已写 checkpoint 全部核验后，将恢复证据留在
   `runs/t237_v3_checkpoint_replace_recovery/`，从 8 个合法 checkpoint resume，只新训 2 个，
   未复用任何 V2 模型。

## 主要结果

主 cutoff 12 的 area-equivalent logical-Z lifetime 为：standard `2.747662`、MF
`6.534671`、NMF `6.740785`、NMF hidden-reset `6.031675`。NMF--MF paired mean
为 `+0.206114`，95% bootstrap CI `[0.084161, 0.328067]`，5/5 个 NMF agents
均高于配对 MF；NMF--reset 为 `+0.709110`，CI `[0.563764, 0.901654]`。

cutoff 16 confirmation 中总排序仍为 standard `5.144172` < MF `7.245903` <
NMF `7.708351`，但 hidden-reset 达 `8.271987`，反而高于 full-history NMF。另有 MF
相对 standard 的幅度远大于原论文中“MF 约等于 standard”的现象。因此本 task 只通过
**当前 finite-cutoff 模型内的方向性总排序**，没有证明 history-specific 机制跨 cutoff 稳健，
也没有复现原论文幅度。

数值诊断中最大 trace error `5.55e-16`、最大 Hermiticity error `0`、最小 final
eigenvalue `0`；所有 14 个 production gates 通过。4/5 个 NMF 的 best epoch 位于上限
300，故不声称 optimizer convergence 或最优控制。

## 对论文 claim 的影响

允许写：在当前 finite-cutoff、10-cycle、严格 seed split 的同模型比较中，NMF 的总
logical-Z lifetime 方向上高于 MF，且 MF 高于 standard。不得写：完整复现 PRL 增益幅度、
记忆机制已被跨 cutoff 证实、NMF 已收敛到最优策略、该数值等于真实装置或 FPGA 性能。
