## 执行方案与实际完成

1. 冻结 `dual-latency-budget-v1`，建立恰好两个不可组合 lane：
   `literature_system` 与 `project_control_plane`。
2. 文献 lane 保留 Sivak 外部 X6-1000M/Virtex-6 装置身份、DAC 500 MS/s/16 bit、
   readout `700 ns`、travel `300 ns`、acquisition `1400 ns`、FPGA DSP `332 ns`、
   bit distribution `100 ns`。因 pulse/acquisition 存在未定义 overlap，measurement 总和
   主动保持 `null`，不制造 `2832 ns` 伪总时延。
3. 分开记录 Sivak `1546 ns` SBS prose、`1548 ns` layer sum、`1596 ns` table block，
   以及 `2332/2380 ns` reset scope；由 Table S3 独立复算 constituent/full X+Z 为
   `4924/9848 ns`。
4. 将 Puviani `0.1+0.5+0.7+0.3+0.1+2.3+1.0=5 us` half cycle 和
   `10 us` full cycle 标为 `external_model_assumption`；保留 numerical reset/no-pulse
   边界。
5. 项目 lane live-bind `hardware_hil.yaml`：5 us slot、1.5 us fast budget、2048-sample
   window、10.24 ms content、20 ms emission/update、5 ms slow budget、1.0 +/- 0.12 us
   fast software model，以及 `10+60+900+20+5=995 us` slow-stage mean sum。
6. 复算 UART 8N1：2048 B raw-count payload `177.7778 ms`，当前 4096 B float32
   software payload `355.5556 ms`；前者已经无法满足 20 ms window，USB-SPI 仍无实测值。
7. Tang Nano 20K core、transport、end-to-end、quantum measurement、ADC、AWG/DAC 与
   physical action 七类字段全部机器化保持 `null/unmeasured`。
8. 实现 23 项 executable gates、source-line expected-fragment、live YAML binding、唯一 ID、
   closed evidence-class、跨 lane 禁止聚合与多类 mutation negative tests；生成绑定预算
   SHA256 的 audit snapshot，防止陈旧验证结果继续通过。
