## 2. 实际实现

### 2.1 Grouped CPTP instrument

实现 `SBSErrorSpaceInstrument`。输入 `T_b[target,source]` 必须非负，并对每个 source 满足全部 branch/target 总和为 1。每个非零 transition 构造

\[
M_{b,j\leftarrow i}=\sqrt{T_b[j,i]}|C_j\rangle\langle C_i|\otimes X_LZ_L.
\]

代码构造完整 Hilbert-space matrices，可直接检查 `sum M^dagger M=I`、branch Choi positivity 和 trace-nonincreasing effect。

### 2.2 `C_i` hierarchy 与 trickle-down

- `K_gg`：保持同一 `C_i`/同一 depth；
- `K_ge/K_eg`：严格下降一层；
- `K_ee`：严格下降两层；
- C0：只允许 `K_gg=1`；
- 支持多个 `C_i` 共享相同 depth，例如 `C1/C2` 同属 first error level；
- general transition topology 与可复现 chain builder 分开。

`make_trickle_down_chain` 要求显式给出 one-step、two-step 和 `ge_fraction` modeling assumptions；无装置式默认恢复率，不裁剪非法概率，C1 不会把不可行的 two-step 概率暗中重分配。

### 2.3 Pauli frame 与 API

每个 branch 保留 full-cycle `X_LZ_L=-iY_L` 的 density-matrix effect，`PauliFrame` 同时翻转 x/z bit。结果区分 physical `unconditional_state` 与只撤销本周期 deterministic flip 的 `cycle_frame_corrected_state`。

另实现：

- classical population marginal；
- seeded ideal-Kraus trajectories；
- expected recovery depth；
- logical state 到指定 `C_i` 的嵌入；
- `physics.__init__` lazy exports。

## 3. 反简化审计

本模型不是整数 `depth -= 1` demo：

- quantum path 对随机复 density matrix 保持 PSD/trace，并与 population marginal 一致；
- branch Choi matrix 直接验正；
- `C_i` label 与 recovery depth 分离；
- 大误差第一次 channel application 不得直接全部回到 C0；
- inter-subspace coherence 被主动去除并由 `preserves_inter_subspace_coherence=False` 标记；
- `device_calibrated=False`，readout/reset/Fock/timing 明确不在本 task；
- `normalization_tolerance` 上限为 `1e-8`，任意非零错误跳层即使小于 tolerance 也被拒绝；
- Monte Carlo frequency 与解析 branch probability 独立对齐。

首轮 focused test 唯一失败来自测试手算：C4 分布 `0.2 C4 + 0.6 C3 + 0.2 C2` 的期望深度应为 `3.0` 而非 `3.4`。只修正测试算术，模型参数和行为未改变。
