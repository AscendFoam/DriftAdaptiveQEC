## 1. 输入与执行方案

输入为完整 `DriftState` round schedule、T2.1.1 residual/recovery/leakage/logical semantics、T2.1.2 multi-round state 要求，以及任务板对 `P_L`、CI、seed、1e5/1e6 cycles 和 rare-event sampling 的通过标准。

执行方案：

1. 用 `rounds × vectorized trajectories` 保留多轮 state，同时避免 1e6 次 Python object loop；
2. primary `P_L` 以 cycle logical events 定义，并同时输出 q/p 与 trajectory failure；
3. CI 以 trajectory 为 cluster 做 seeded bootstrap；
4. zero-event stratum 加保守 failed-trajectory upper floor；
5. rare burst/leakage 定义为已知 trajectory probability 的两层 mixture；
6. simulation allocation 与 target weight 分离，禁止抄 raw oversampled fraction；
7. production artifact 真跑 1e6 cycles，不只验证配置字段。
