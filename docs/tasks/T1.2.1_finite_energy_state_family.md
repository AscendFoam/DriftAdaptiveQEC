## 1. 既有实现审计

`physics/gkp_state.py` 的 Strawberry Fields 路径可以在依赖可用时生成 Fock-backend
state；但其无 SF fallback 只是以下 heuristic signed grid：对二维 lattice blobs 加

1. 没有 normalized position wavefunction；
2. 输出按 `max(abs(W))=1` 归一化，不满足 Wigner 总质量或 marginal contract；
3. analytical `apply_displacement` 只记录属性，没有把位移作用于图或态。

因此本任务没有把既有可视化 smoke 冒充 finite-energy state family，而是新增独立
reference 模块；旧文件的说明也已改为 `legacy heuristic visualization`。其数值行为
保持不变，避免破坏历史调用。

## 2. Operational lattice 与 logical states

继续使用当前仓库已冻结的 correction-cell spacing

\[
\lambda=\texttt{LATTICE\_CONST}=\sqrt{2\pi}.
\]

在 position-wavefunction reference 中：

- `|0>_L` 的 ideal centers 为偶整数倍 `2n lambda`；
- `|1>_L` 的 ideal centers 为奇整数倍 `(2n+1)lambda`；
- stabilizer period 为 `2 lambda`；
- `|+>_L`/`|->_L` 是分别归一化后的 `|0>_L +/- |1>_L` 相干叠加，不是两个
  probability densities 的混合。

这套 operational coordinate 与文献其他 quadrature normalization 比较时仍需整体
缩放；本任务不声称它是所有论文的唯一记号。

## 3. Gaussian peaks + Gaussian envelope model

对 basis parity `j in {0,1}`，未归一化 wavefunction 写成

\[
u_j(q)=\sum_{m\bmod2=j}
\exp\left[-\frac{(\kappa m\lambda)^2}{2}\right]
\exp\left[-\frac{(q-m\lambda)^2}{4\sigma^2}\right].
\]

其中 `sigma=peak_sigma` 是隔离 peak 的 probability standard deviation，`kappa` 是
amplitude envelope inverse width；省略 `kappa` 时取 `kappa=sigma`，形成常用
symmetric parameterization。代码没有把“peak width”与“envelope width”混成一个
无法解耦的参数，后续可分别研究 broad peaks 与 finite extent。

## 4. Damped finite-energy projector model

实验/理论常用 finite-energy envelope operator

\[
N_\Delta=\exp(-\Delta^2 a^\dagger a)
\]

作用于 ideal codewords；本任务以 `epsilon=Delta^2` 的 harmonic-oscillator
imaginary-time Mehler kernel 实现：

\[
K_\epsilon(q,x)\propto
\exp\left[-\frac{(q^2+x^2)\cosh\epsilon-2qx}
{2\sinh\epsilon}\right].
\]

对 ideal center `x=m lambda` 完全平方后得到：

\[
K_\epsilon(q,x)\propto
\exp\left[-\frac{x^2\tanh\epsilon}{2}\right]
\exp\left[-\frac{(q-x\operatorname{sech}\epsilon)^2}
{2\tanh\epsilon}\right].
\]

因此该态族同时包含：

- `amplitude_variance=tanh(Delta^2)` 的 finite peaks；
- `exp[-x^2 tanh(Delta^2)/2]` envelope；
- peak-center contraction `sech(Delta^2)`。

测试不仅检查完成平方后的内部参数，还从原始 Mehler kernel 独立重算 wavefunction，
与实现归一化后逐点一致。`Delta -> 0` 时 peak 变窄、envelope 展宽、center contraction
趋近 1、所需 comb components 增加，测试覆盖该趋势。

## 5. 解析归一化与截断

每个 component 统一写为

\[
g_i(q)=\exp[-(q-c_i)^2/(2v_i)].
\]

任意两个 components 的 overlap 解析为

\[
\int g_i(q)g_j(q)dq=
\sqrt{\frac{2\pi v_i v_j}{v_i+v_j}}
\exp\left[-\frac{(c_i-c_j)^2}{2(v_i+v_j)}\right].
\]

代码用完整 Gram matrix 归一化，而不是假设相邻 peaks 无 overlap。`0/1` basis 先各自
归一化，`+/-` 再作相干叠加并重新归一化。

无限 comb 以 envelope amplitude 的 `tail_tolerance`（默认 `1e-12`）截断；最大每个
basis 512 components。极小、不可表示或需要过多 peaks 的参数在创建数组前失败关闭。
`tail_tolerance=1e-8` 与 `1e-14` 的两模型 state overlap 均大于
`1-1e-13`，证明默认截断不依赖某个偶然 peak count。

## 6. 输出接口

### 6.1 Wavefunction 与 probability

- `wavefunction(q)`：normalized real position wavefunction，支持标量/任意 shape；
- `probability_density(q)`：由同一 wavefunction 平方得到；
- `inner_product(other)`：用解析 Gaussian overlaps 计算；
- `PeakTable`：暴露 ideal indices、physical centers、normalized coefficients 和
  amplitude variance，便于审计而不修改内部数组。

### 6.2 Syndrome distribution

对 centered syndrome cell，计算

\[
p_S(s)=\sum_{k\in\mathbb Z}|\psi(s+k\lambda)|^2,
\quad s\in[-\lambda/2,\lambda/2).
\]

API 使用 full-period midpoint grid，返回 normalized density、归一化前
`captured_mass` 和实际 alias 范围。它折叠的是 coherent wavefunction 的 probability，
不是手写一个与态无关的 Gaussian syndrome proxy。

### 6.3 Sampled Wigner-like grid

`wigner_like_grid` 从同一个 sampled wavefunction 计算

\[
W(q,p)=\frac1\pi\int dy\,e^{-2ipy}\psi(q+y)\psi(q-y)
\]

的 discrete FFT approximation。p-grid 由 q spacing 唯一决定，因此不做任意插值；
返回：signed grid、q probability、从 Wigner 积分恢复的 q marginal、captured
probability、total mass 和 negative volume。它是 finite-window numerical reference，
明确不叫 Fock-space tomography。

## 10. T-RISK-20260714-01 坐标勘误

上式 Mehler kernel 与 `amplitude_variance=tanh(Delta^2)` 明确属于 canonical
`[x,p]=i`。默认 decoder chart 的坐标尺度为 `sqrt(2)`，因此 amplitude variance 必须为
`2*tanh(Delta^2)`、probability variance 为 `tanh(Delta^2)`，envelope inverse width
同步除以 `sqrt(2)`。实现、direct Mehler test 和四逻辑态 dilation test 已回灌；原先只缩
comb centers 的行为不再作为物理 `N_Delta` 映射。
