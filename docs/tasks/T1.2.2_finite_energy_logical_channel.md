## 1. 指标边界

本任务回答的是：给定 q/p 的真实 logical parity 与某个 decoder 输出 parity，残余
logical operation 对应怎样的 Pauli-twirled effective qubit channel。它不是完整
approximate-GKP recovery tomography，原因是 classical parity outputs 不能恢复：

- coherent/non-Pauli logical terms；
- code-space leakage；
- finite-energy recovery 过程中的 state deformation；
- ancilla/reset/loss dynamics；
- Fock-space CPTP map 的完整 Choi/PTM。

因此类名为 `PauliChannel`，产物记录始终带 `Pauli-twirled effective` 边界。后续
T5.3.1 仍需六 Pauli eigenstates 或等价完整 PTM 数据与 non-Pauli/leakage diagnostics。

## 2. Residual parity 到 Pauli 的映射

沿用 square-GKP operational mapping：

| residual q parity | residual p parity | logical Pauli |
| ---: | ---: | --- |
| 0 | 0 | I |
| 1 | 0 | X |
| 0 | 1 | Z |
| 1 | 1 | Y（忽略全局相位） |

真实 parity `t=(t_q,t_p)`、decoder decision `d=(d_q,d_p)` 的 residual 必须是

\[
r=t\oplus d,
\]

而不是直接把 decision class 当成 error class。`pauli_channel_from_joint_confusion`
按四类 truth x decision confusion 做 XOR 聚合；测试包含 truth=`01`、decision=`00`
必须映射 Z 的非平凡样例。

`pauli_channel_from_parity_samples` 支持 paired samples 和非负权重。joint correlated
decoder 的 `(1,1)` residual 会保留为 Y，不会静默改成独立轴乘积。只有显式调用
`pauli_channel_from_axis_confusions` 时，才应用 independent-axis 假设。

## 3. Pauli channel、PTM 与 fidelities

令 Pauli probabilities 为 `p_I,p_X,p_Y,p_Z`，均非负且和为 1。Pauli basis
`(I,X,Y,Z)` 下的 PTM 是

\[
R=\operatorname{diag}(1,\lambda_X,\lambda_Y,\lambda_Z),
\]

其中

\[
\lambda_X=p_I+p_X-p_Y-p_Z,
\]

\[
\lambda_Y=p_I-p_X+p_Y-p_Z,
\]

\[
\lambda_Z=p_I-p_X-p_Y+p_Z.
\]

相对于 identity target，qubit Pauli channel 满足

\[
F_e=p_I,
\qquad
F_{avg}=\frac{2F_e+1}{3},
\qquad
P_L=1-p_I.
\]

代码对 direct constructor 和所有 factory 同时验证有限性、非负性和 normalization；
不会对明显不合法的概率向量静默 renormalize。

## 4. Finite-energy alias response

### 4.1 为什么不是 half-cell crossing proxy

对 T1.2.1 的 normalized logical `0/1` position state，设 nominal ideal lattice parity
为 `j`。任意 position outcome 写成

\[
q=s+k\lambda,
\quad s\in[-\lambda/2,\lambda/2),
\]

真实 residual parity 是

\[
t=(k\bmod2)\oplus j.
\]

代码对所有 aliases 求和形成 joint density

\[
p(s,t)=\sum_{k:(k\bmod2)\oplus j=t}\rho(q=s+k\lambda),
\]

再计算 posterior `p(t|s)` 与 deterministic MAP decision。这消费了完整 normalized
finite-envelope wavefunction density；不是只对一个 Gaussian displacement 判断
`abs(x)>lambda/2`。

`+/-` position wavefunction 没有单一 nominal lattice parity，因此该 1D response API
显式拒绝它们；不能为了凑四态接口而赋予错误 truth label。四态的完整 channel 需要
更高保真度 recovery/PTM task。

### 4.2 外加 Gaussian displacement 的解析卷积

T1.2.1 state wavefunction 为同一 amplitude variance `v` 的 Gaussian sum：

\[
\psi(q)=\sum_i c_i\exp[-(q-c_i)^2/(2v)].
\]

其 probability 的每个 pair term 可写成中心 `(c_i+c_j)/2`、variance `v/2` 的
Gaussian，权重包含

\[
c_ic_j\exp[-(c_i-c_j)^2/(4v)].
\]

与 variance `sigma_d^2` 的外加 Gaussian displacement 卷积后，variance 变为
`v/2+sigma_d^2`，并乘保持积分不变的 scale。代码对所有 pair terms 精确执行该
卷积，再做 alias folding；不是把 `peak_sigma` 与 external sigma 随手平方相加后丢掉
coherent cross terms。

### 4.3 任意 parity decoder 的 confusion

`ParityResponse1D` 返回 syndrome grid、`p(s,t)`、posterior、MAP decisions、captured
mass 和 alias range。`parity_confusion_from_response` 可以消费：

- 内置 finite-energy MAP decisions；
- 与 grid 同 shape 的任意 binary decision array；
- 任意 deterministic callable `decoder(syndrome)->parity`。

confusion 行为 true residual parity、列为 decision。公共 response/confusion 对
shape、uniform grid、posterior normalization、binary output、captured mass 和极端
workload 都有失败关闭；超大 sigma/points/alias/pair workload 不会无界分配。

## 6. 反简化/伪实现复核

| 检查 | 结果 |
| --- | --- |
| 是否把 decoder decision 直接当 error | 否；统一 truth XOR decision |
| 是否只输出一个 LER | 否；输出 `p_I/p_X/p_Y/p_Z`、PTM、`F_e/F_avg` |
| 是否默认 q/p 独立 | 否；joint samples/confusion 保留相关 residual；独立仅显式 factory |
| finite-energy 是否只改 sigma | 否；消费 normalized state 的全部 Gaussian pair/cross terms |
| 是否只跨半格判断 | 否；所有 aliases 按 relative logical parity fold |
| 是否只接受内置 decoder | 否；任意 binary array/callable parity decoder 可评估 |
| 解析结果是否循环自证 | 否；独立 Gaussian-mixture MC 在 1.74 SE 内一致 |
| 是否把 Pauli twirl 写成完整 channel | 否；模块、API、风险和 claim 均显式降级 |
| 极端输入是否可拖垮内存 | 否；points/alias/pair workload 在分配前失败关闭 |

结论：T1.2.2 建立了可审计的 parity-to-channel contract，但诚实保留了非 Pauli、
leakage 和 full recovery tomography 的后续缺口。

## 7. 对论文 claim 的影响

允许声称：任意 parity-output decoder 可被一致地映射为 Pauli-twirled effective
logical channel，并报告四 Pauli probabilities、PTM、`F_e`、`F_avg`；finite-energy
1D response 由 normalized state/noise density 与 alias folding 得到，且经独立 MC

已测量或真实实验 channel fidelity。
