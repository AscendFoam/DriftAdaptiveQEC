# T0.1.3 双回路接口冻结：host slow estimator 与 FPGA deterministic fast path

**Task ID：** `T0.1.3`  
**接口版本：** `DLIF-v1`  
**日期：** 2026-07-14  
**状态：** `Done`  
**前置 contract：** `T0.1.1` scope、`T0.1.2` platform abstraction

## 1. 冻结结论

双回路分工冻结为：

- **FPGA fast path**：每个有效 syndrome 子周期只读取已提交的 active parameter bank，执行确定性的限幅、定点 `Delta = K s + b`、event/FSM safety gate、frame/correction 输出与 trace；不做在线训练或重型状态估计。
- **host slow path**：按窗口接收 syndrome/event/health 统计，运行 CNN/TCN/GRU、Kalman/HMM、window estimator 或其它候选模型，输出一个完整、受约束、带版本与校验的 parameter bank；不直接控制已经过去的快周期。
- **原子更新**：host 只写 inactive bank；FPGA 在 schema、CRC、版本、范围和 apply-epoch 全部通过后，于 cycle boundary 原子切换；任一失败均保持 last-known-good 或转入预验证的 safe-static bank。

任务名称沿用“CNN 慢回路”，但 `DLIF-v1` **不把 CNN 冻结为唯一模型**。后续 T4.1 必须在相同输入/history/参数/latency budget 下比较 CNN/TCN、GRU、Kalman/HMM、指数递推和 run-length FSM，再决定 slow estimator；wire contract 不随模型选择变化。

## 3. Q4.20 位宽解释

当前 `FixedPointFormat` 把 `Q4.20` 解释为：

- 1 个符号位；
- 4 个整数位；
- 20 个小数位；
- 总宽度 25 bit；
- 步长 `2^-20`；
- 数值范围 `[-16, 16-2^-20]`。

本 contract 采用该仓库既有解释，避免把某些工具链中“总位宽为 24”的另一种 Q notation 静默混入。RTL、Python golden、trace schema 和文档都必须写明 `signed(25, frac=20)`，不能只写裸字符串 `Q4.20`。

这只是 v1 baseline 位宽。T5.5.3 必须扫描更窄位宽的 precision–resource–LER Pareto；只有新版本 contract、bit-accurate regression 和 claim 更新通过后才能改变部署点。

| 接口 | 字段 | canonical wire representation | 软件兼容表示 | 更新频率 | fallback policy |
| --- | --- | --- | --- | --- | --- |

默认 `uint16` histogram payload 为 2048 B，header/health 另计；当前 `float32[1024]` 兼容 payload 为 4096 B。二者通过 host-side normalization adapter 对齐，不能在同一 schema version 下仅凭 buffer size 猜格式。

## 5. 更新频率与预算

| 时间尺度 | 冻结语义 | 当前默认配置 | 证据边界 |
| --- | --- | --- | --- |
| fast subcycle | 每个 syndrome observation 至多一个 action；active bank 在整个周期内不变 | `t_fast_us=5.0`，fast budget `1.5 us` | 配置/延迟模型目标，不是板级实测 |
| window emission | 对最近 W 个有效样本构造统计，可与 stride 独立 | W=2048；stride=4000 cycles；在 5 us reference 下窗口内容 10.24 ms、发射间隔 20 ms | 当前 software-HIL contract |
| slow update | 单一 in-flight job；模型推理/估计完成后生成完整 bank | nominal period 20 ms；slow budget 5 ms；queue depth 2 | 配置/注入延迟，不是 host/board 测量 |
| commit | staging 完整并验证后，在未来安全 cycle boundary 原子切换 | current `commit_delay_cycles=1` | Python scheduler 已实现语义；RTL/board 待验证 |
| health/recalibration | 窗口级 health；更慢跨 run/minute 重标定由后续三时间尺度 task 冻结 | 尚未统一 | T1.4.3/T4.3 |

`5 us`、`20 ms` 和 `1.5 us` 均为当前配置 baseline，不继承任何实验论文装置的已测身份。T2.4/T6 必须分开报告 literature timing、software timing model、FPGA core、transport 和 end-to-end timing。

## 6. 原子性与一致性规则

1. fast path 在 cycle start 锁存 `active_bank + active_version`，本周期结束前不得变化；
2. host 写入 inactive bank payload，随后写 header/CRC，最后置 staged-valid；
3. FPGA 对 schema、length、CRC、version monotonicity、range、age 和 `apply_epoch` 完整验证；
4. commit 采用 expected-current-version compare-and-swap，避免 host/FPGA 状态分叉；
5. commit 只发生在没有半完成 action 的 cycle boundary；
6. ack 必须 read-back active bank/version；host timeout 时不能把“已发送”当“已生效”；
7. old active bank 至少保留到新 bank 通过 post-commit guard window，支持立即 rollback；
8. trace 的 `params_used` 必须记录 actual quantized K/b 或其 version+hash，而不是 host proposed float 值。

## 7. Fallback policy

| 事件 | 必须动作 | 禁止行为 | 当前实现差距 |
| --- | --- | --- | --- |
| boot / no valid update | 使用预验证 `safe_static` bank v0 | 默认 identity bank 未验证就用于论文主实验 | 当前 `ParamBank` 默认 identity；正式配置需显式 safe bank |
| slow inference/DMA/AXI failure | 不 stage；active last-known-good 继续，记录 reason | 写入部分参数或把 failure 当零预测 | slow failure no-stage 已有 |
| schema/CRC/version/length/range failure | reject inactive bank；active 不变 | silent coercion、silent downgrade | 尚缺 header/CRC/CAS |
| active bank 超过 `max_bank_age` | 切到 `safe_static`，标记 stale | 无限期使用未知失配参数 | age contract 待实现 |
| invalid/non-finite observation | frame-only hold 或 protocol-defined reset request | 将 NaN/invalid 当 0 syndrome | validity gate 待实现 |
| finite observation 超量程 | saturate + flag；窗口统计用 overflow count；持续超限触发 safe-static/health degrade | 只 clip 不记录 | clip/flag 已有，自动降级待实现 |
| correction saturation/aggressive bank | 本周期 bounded clip + flag；超阈值拒绝/回滚 bank | 将饱和 correction 当正常增益 | 诊断已有，拒绝/回滚待实现 |
| fast deadline miss | 丢弃迟到 action；不能移到下一周期；health counter++ | late correction 作用于错误 cycle | 当前只记录 budget violation |
| host timeout | last-known-good 维持到 age limit，随后 safe-static | fast path 阻塞等待 host | scheduler 非阻塞已有，age fallback 待实现 |
| window queue full | 丢最旧未处理窗口，保留最新，计数 | 阻塞 fast path | 当前已实现 |
| commit ack timeout | active version read-back；不明时保持/回滚 | host 单方面宣布 commit success | 真实 I/O 待 T6 |
