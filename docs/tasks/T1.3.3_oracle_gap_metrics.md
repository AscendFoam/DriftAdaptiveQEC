## 1. 指标命名

对同一 paired sample set 上的 static、dual/adaptive candidate 和不可部署 decoder oracle，
定义

\[
D=P_L^{static}-P_L^{oracle},
\]

\[
R=P_L^{dual}-P_L^{oracle},
\]

\[
I=P_L^{static}-P_L^{dual}.
\]

任务板给出的

\[
G_{remaining}=\frac{R}{D}
=\frac{P_L^{dual}-P_L^{oracle}}
{P_L^{static}-P_L^{oracle}}
\]

表示“剩余 static-to-oracle gap 比例”，不是关闭比例。代码同时返回

\[
G_{closed}=\frac{I}{D}=1-G_{remaining}.
\]

为避免报告歧义，字段明确命名为 `gap_remaining_ratio` 和
`gap_closed_fraction`。不再把两者都简称 `G_oracle`。

## 2. 点估计与异常顺序

`oracle_gap_from_rates` 支持已有同口径聚合 error rates，但不提供统计推断。除分母近零外，
所有比值保持原始值，不 clip 到 `[0,1]`：

| 情况 | remaining | closed | 状态 |
| --- | ---: | ---: | --- |
| `oracle <= dual <= static` | `[0,1]` | `[0,1]` | within bracket |
| `dual > static` | `>1` | `<0` | dual worse than static |
| `dual < oracle` | `<0` | `>1` | dual better than oracle point estimate |
| `static = oracle` | undefined | undefined | zero reference gap |
| `static < oracle` | 原始 signed ratio | 原始 signed ratio | reference order inverted |

“dual 优于 oracle”只描述有限样本点估计或模型/路由不一致，不能据此声称超越 oracle。
“oracle 差于 static”使 reference ordering 失效，不能把其 ratio 当 gap closure。

默认 `denominator_epsilon=1e-12`；近零分母返回 `None` 和
`zero_static_oracle_gap`，不返回极大伪精度数值。

## 3. Paired sample inference

`compute_oracle_gap_metrics` 要求三组长度相同的逐样本 failure indicators，最少两个样本。
每个样本必须是 boolean 或精确 `0/1`。由 paired differences

\[
d_i^{s-d}=e_i^{static}-e_i^{dual},
\]

\[
d_i^{s-o}=e_i^{static}-e_i^{oracle},
\]

\[
d_i^{d-o}=e_i^{dual}-e_i^{oracle}
\]

计算 estimate、sample standard error 和 normal confidence interval。CI 不裁剪到
概率区间，因为它对应 signed difference，不是单个 Bernoulli rate。

同时报告：

- `static_only_failure_count`：static 错而 dual 对；
- `dual_only_failure_count`：dual 错而 static 对；
- signed McNemar z；正值表示 dual 减少的错误多于新增错误；
- 八种 `(static,dual,oracle)` 联合 outcome counts。

单样本 paired API 会 fail closed，避免 sample variance 被错误写成 0；若只有聚合率，应调用
point-estimate API 并明确“不含推断”。

## 4. Ratio paired bootstrap

ratio CI 不能由三个独立 rate error bars 拼接。实现对八类联合 outcome 做 multinomial
resampling；这是逐样本 paired bootstrap 的充分统计等价形式，但只分配 `B x 8` counts，
不分配 `B x N` indices。

每个 bootstrap replicate 重新计算三个 rates 和分母。只有正的 static-oracle denominator
进入 ratio percentile CI；同时记录 `bootstrap_valid_replicates`。`ratio_ci_reliable=True`
要求：

1. paired `D` 的 normal CI 下界高于 epsilon；
2. 至少 95% bootstrap replicates 保持正分母；
3. ratio 两个 CI 均成功计算。

这不是把不稳定 replicates 悄悄删除：有效数和 reliability flag 都是结果字段。若 reference
gap 很小，point ratio 仍保留，但 CI 标为不可靠。

## 5. 解析与统计测试

canonical example：

```text
P_static=0.20, P_dual=0.12, P_oracle=0.05
D=0.15, R=0.07, I=0.08
remaining=7/15=0.466666...
closed=8/15=0.533333...
```

paired 1000 样本构造为 nested failures：static 200、dual 120、oracle 50。验证：

- static-minus-dual = 0.08；
- paired SE = `sqrt(0.08*0.92/999)`；
- static-only/dual-only = `80/0`；
- McNemar z = `sqrt(80)`；
- 5000 次 fixed-seed bootstrap 的 point 均位于 percentile CI 内；
- denominator stable 且超过 95% replicates 有效。

另构造两组 static/dual/oracle rates 完全相同、但 dual failures 分别嵌套和错开的样本。
两组 point estimates 完全相同，错开组 paired SE 更大，证明实现没有丢失配对结构。

小分母测试只差 `1/40`，point closure 为 1，但 denominator CI 穿过 0 且不足 95%
bootstrap replicates 保持正分母，因此 `ratio_ci_reliable=False`。

## 7. 反简化/伪实现复核

| 检查 | 结果 |
| --- | --- |
| 是否只实现任务板一个比值 | 否；同时输出 raw gaps、remaining、closed 和状态 |
| 是否 clip 到 `[0,1]` | 否；负 closure、`>1` 与反转全部保留并标旗 |
| zero denominator 是否加任意小数继续除 | 否；显式 undefined |
| 是否把三个 rates 当独立样本 | 否；差值、McNemar、bootstrap 全部 paired |
| ratio CI 是否逐样本分配巨大矩阵 | 否；八类联合 outcome multinomial sufficient statistics |
| 小分母是否仍宣称精确 closure | 否；denominator stability 与 valid replicate gate |
| 单样本是否报告零 SE | 否；paired inference 最少两个样本 |
| dual point 优于 oracle 是否写成真实超越 | 否；专用异常 flag 和 claim guard |

结论：指标实现覆盖数值定义、配对不确定性和失败语义，不是一个 demo 级除法函数。

## 8. 对论文 claim 的影响

后续只有在同 seed/同 trace、positive stable denominator、paired ratio CI 可用时，才能报告
static-to-oracle gap closure。否则只报告 raw error rates/gaps 和对应异常状态。任何
`closed>1` 都不能写成“超过 oracle”，任何负 closure 都不得被裁掉后包装成 0。
