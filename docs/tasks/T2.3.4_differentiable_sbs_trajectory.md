# T2.3.4：构造短时域可微 sBs trajectory simulator

- **日期：** 2026-07-14
- **状态：** Done
- **目标：** 在可控 Fock cutoff 下实现随机 `g/e`、15 个可微 sBs 控制、固定 cycle timing、reward、trajectory probability 与资源画像。

## 输入材料

- `docs/new_task_board.md` 的 T2.3.4 验收条件；
- 本地 Puviani et al. 一手全文 411--434、451--459、467--527 行；
- T2.3.1 finite-Fock state preparation、T-RISK quadrature contract；
- `physics/fock_sbs_cycle.py` 的 fail-closed finite-cutoff边界（未复用其固定参数 Kraus 冒充可微门）。

## 实际完成内容

1. 新增 joint cavity--two-level-ancilla `2N x 2N` batched density simulator。
2. 显式实现 4 个 qubit rotation、3 个 complex ECD、固定 layer-4 displacement 和 VR，共 15 个可微控制。
3. 按 Table S1 冻结 7 段 `5 us` half-cycle，逐段加入 cavity loss、ancilla T1/Tphi CPTP channel。
4. 实现随机/强制 `g/e` projection、conditional reset、seeded replay、`sum log p_j` 和 pure-target fidelity reward。
5. 增加 causal history-conditioned policy API；未来控制不能读取当前/未来 outcome，策略参数的 reward/log-prob graph 均贯通。
6. 输出实际资源计数、tensor bytes、autograd lower bound、host time 与 CUDA peak；显式标为非硬件测量。
7. 增加 37 项专门测试与 CPU/CUDA 各 17 个 production gates。
