# T5.2.3 任务记录：leakage 与 reset failure 独立因果注入

- Task ID：T5.2.3
- 日期：2026-07-16
- 状态：Done

## 输入、通过标准与失败分支

输入为 T2.0.3 hidden/observed/reset kernel、T2.0.6 occupancy/correlation component、T5.1.2 leakage lane、
T5.1.6 feasibility contract、T5.2.2 one-channel causal contract和 Sivak 2023 leakage source anchors。

通过要求：leakage injection 与 reset failure 分别改变一个通道；报告 detection delay、false alarm、observed
correlation tail、declared/safe availability、raw reset cost；提供 leakage-free matched ablation和 whole-seed CI。

失败分支：改名复用 post-selection component、同时改变 injection/reset、truth 触发 detector、无 episode 时把 delay
填 0、perfect classifier 隐藏 false alarm、shots 伪重复、只报单一 cost score、parent/source/code stale 或 device/LER
claim promotion。

## 执行方案

1. 两族各 6 rates、8 新 seeds、256 trajectories、128+512 cycles；
2. 复用 4×3 classifier 与 persistent reset kernel，balanced g/e schedule；
3. family/seed 内 CRN pairing，whole-seed 20k bootstrap；
4. 反算 empirical injection hazard 和 reset failure，检查固定通道；
5. 主指标不做 trajectory removal，leakage-free control 保留 false alarms；
6. mutation suite 拒绝 channel mixing、fake null、truth/global-score/postselection 漂移。

## 实际完成与结果

- 96 seed rows、12 summaries、2,508-row Source Data、23/23 gates；
- leakage-free：hidden occupancy/reset attempts `0/0`，false alarm `2.136e-4`，delay `null`；
- injection 0.004：occupancy `0.042331`、run `10.948 steps`、long correlation `0.224123`、safe availability `0.957461`；
- reset failure 0 -> 0.95：run `1.055 -> 20.471`，long correlation `-0.000384 -> 0.404017`，safe availability `0.997639 -> 0.958522`；
- finite formal sample 的 detection fraction 为 1，mean delay 约 `0.053--0.055` step，同时保留 5% false-negative assumption。

## 开发期详细检查

初版 22/22 PASS 后补入 empirical injection probability，并同时核对 leakage family 固定 0.9 reset-failure 与 reset
family 固定 0.002 injection，升级为 23 gates。direct test 初版错误要求 noise-floor long-correlation 六点全严格单调；
检查发现 0 与 0.25 的点都在约 `5e-4` 噪声层。修正为保留 endpoint/CI 级 tail 增长和 0.25 后严格方向，
occupancy/run/reset-failure/availability 仍全网格严格有序，不通过删点或放宽核心因果门解决。
