## 输入、通过标准与失败分支

输入为任务板冻结的 10 类场景：static Gaussian、mean/variance/correlation drift、loss、readout/ancilla
drift、burst/outlier、large-error recovery、leakage、calibration shift；同时继承 T5.1.1 的 19-comparator/
8-lane nonmixing contract 和 T2/T3 的生产执行器。

通过标准不是某种算法必须获胜，而是：十类场景均真实执行；decoder 场景 train/eval seed 分离、同
scenario-seed-window shared trace、当前窗解码后才更新；非 decoder 场景保留原生物理量和 native gates；
component/oracle/secondary 不得混入全局排名；所有代码/parent/source-data provenance 当前。任一类别缺失、
seed overlap、trace 复用、联合概率未定义却填值、component ranking promotion 或 stale hash 均须 fail closed。

## 执行方案

先审计现有模块后，将矩阵拆成四条不可混排车道：

1. decoder lane：static、mean、variance、correlation、burst/outlier、calibration shift；
2. loss lane：`GKPNoiseTransferSurrogate` 的 transmissivity sweep；
3. readout/ancilla lane：protocol-native sBs fault overlay 的四级 rate drift，加独立 sBs/sharpen--trim endpoint；
4. large-error 与 leakage：复用 protocol-native component simulators，只保留 component status。

decoder 冻结 3 个 training seeds、6 个 evaluation seeds、32 windows、每窗 256 个 observation 和 512 个
held-out decisions；EWMA/Kalman/static 参数只在原 T3.2.2 training scenarios 上选择。六种方法在每条 trace
上共享 displacement/residual/truth，只有 oracle 在 evaluator 中读取 hidden state。

## 两次开发期失败及修正

首轮 loss 使用相关 covariance，surrogate 正确返回 Fréchet bounds 和 `any_jump_probability=None`，production
runner 因禁止把 `None` 当数值而失败。修正为 loss isolation 使用 diagonal axes；correlation 仍由独立
decoder scenario 验证，未放宽 validator。

第二轮 diagonal 配置仍带非零 signal offset，轻度 attenuation 先抵消 offset，导致总 bias norm 非单调。
该量不能作为纯 loss gate。随后改为非零 lattice index、零 offset；calibration shift 独立承担 offset 机制。
第三轮 15/15 gates 通过。这两次失败均改变了实验隔离设计，而不是降低阈值或删除不利点。

- mutation 覆盖 scenario deletion、seed overlap、component promotion、stale artifact、global leaderboard 注入和
  native gate failure。

## 非 demo 检查

本任务不是单 seed、单 endpoint 或参数换名：decoder 有 36 个独立 trace hashes；burst 和 abrupt shift 有
显式事件结构；loss/readout/large-error/leakage 均重新运行而非只复制 parent 状态；Source Data 包含逐 seed、
逐 method、逐 loss/fault/large-error 点和 gate。算法胜负不是 task acceptance，反方向结果保留。另一方面，
四条 lane 仍不是同一 finite-energy closed-loop protocol，不能包装成端到端全噪声稳健性。
