## 1. 输入与执行方案

输入包括 Sivak Methods/S4E/S4F、T2.0.3 hidden/observed/leakage schema，以及任务板对 hidden-vs-syndrome occupancy 和 leakage-removal correlation tail 的双通过标准。

执行前将两条证据链完全拆开：

1. syndrome-only estimator 只接收 observed `all_gg` matrix，拟合 `P([gg]^n)=a lambda^n`，用 `p_err≈1-lambda`、`Pi0≈a lambda`；
2. hidden code occupancy 只作独立 truth comparison，不进入 estimator；
3. correlation 使用 observed full-cycle non-gg activity；removal 按一手文献丢弃任何出现连续 `>=2` leakage cycles 的整条 trajectory；
4. S4E 的 `p_err^2` 一阶模型误差与 statistical bootstrap CI 分开报告。

## 2. 实际完成内容

- 实现 600 shots×1200 cycles、200-cycle burn-in 的 shared hidden/observed trajectory generator；
- 两态 error/recovery 平衡与 f/higher leakage process 分离；
- 使用 primary `F_g/F_e` 对角 readout，f/higher 完美 leakage 分类保持 assumption 标签；
- higher leakage 期间 ancilla inactive，显式累计 coarse recovery depth，结束后产生 e recovery trace；
- start-of-cycle hidden depth/code/leakage truth 与 observed X/Z class 结构分离；
- 实现 sliding-window all-gg counts、log-linear `a/lambda` fit、shot-cluster bootstrap 和 `p_err^2` combined interval；
- 实现 pooled lag correlation sufficient statistics、整 trajectory leakage post-selection 和 paired shot-cluster bootstrap；
- 11 个 acceptance gates、具名 failure diagnostics、机器 JSON/CSV 和中文验证说明；
- protocol hierarchy 新增 6 个 source anchors 与 occupancy/correlation contract。

## 3. 反简化检查

- estimator 函数签名由 test 锁定，无 hidden/truth 参数；
- truth invariant 锁定为 `code=(start_depth==0 and no leakage)`，修复了首轮实现中“记录 update 后 depth、却标 start-of-cycle code”的潜在顺序不一致；
- higher event start rate/duration 在 production data 中独立复核 source-inspired `1.28e-4` / `17.2 cycles` 量级；
- all-gg probabilities 必须严格下降，`lambda` 必须在 `(0,1)`，constant/malformed inputs fail closed；
- correlation 用 per-shot sufficient statistics 和 cluster bootstrap，不把全部 cycle 当独立样本；
- higher leakage rate 置零时 retained=1、before=after、paired difference=0，并触发 shrink failures；
- fixed seed bitwise replay、changed-seed gate、报告完整重生成均通过；
- removal 明确是 post-selection，不伪装在线 controller。
