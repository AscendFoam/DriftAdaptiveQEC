**Task ID：** T2.0.4

## 1. 输入与执行方案

输入包括 `PROTO-SBS-MAIN`、T2.0.3 的 deployable observed/reset records、Sivak Supplement Table S3、本仓库 paper-parameter registry，以及“文献时间轴不得冒充低价板实测”的通过标准。

执行前将一个 constituent 拆为 18 个有序 phase，并将 X、Z 两个 constituent 按真实执行顺序组合为 full cycle。FSM 只消费 observed class、reset action 和显式 virtual-rotation calibration key；hidden/ideal/truth state 不进入 event metadata。

## 2. 实际完成内容

- 逐项实现 Table S3 的 enter/SBS 四层/measurement-reset/signal processing/distribution/branch/virtual rotation/idle/exit 18 阶段；
- constituent 参考总时长固定为 `4924 ns`，chronological X→Z full cycle 为 `9848 ns`；
- 保留 layer sum `1548 ns` 与正文 SBS `1546 ns`、Table reset block `2380 ns` 与正文 reset subroutine `2332 ns` 的 scope 差异；
- `advance()` 每次只允许推进一个合法 phase，未完成读取 trace、完成后重复推进、负 start、坏 mapping/profile 均 fail closed；
- 直接消费 T2.0.3 `SBSObservedCycle`，X/Z observed class、reset action 和 VR key 分 constituent 接线；
- constituent 与 full cycle 更新 Pauli frame，连续两个 full cycles 的 frame cancellation 可复核；
- 每个 profile/event/trace 均写入 `literature_reference_not_target_board_measurement` 和 `target_hardware_measured=False`；
- protocol hierarchy 只登记“reference timeline state machine implemented”，T2.0.5 Fock/fault trend 仍为 future work。

## 3. 反简化检查

本实现没有用单个总时长常量代替状态机：

- 18 个 phase 的顺序、逐项 duration、group sum 和连续边界均有 direct tests；
- 不同 runtime 具有独立 transition index，不共享 demo 级全局计数器；
- event metadata 只含 observed control，不泄露 hidden truth；
- VR 使用调用者显式 mapping/provenance，不虚构 `theta_g/theta_e/theta_f` 装置标定值；
- 源码无 `sleep`、`perf_counter` 或 wall-clock 测量，文献 ns 与软件运行时间严格分离；
- 首轮验证发现 primary source 路径中的目录拼写错误，已改为仓库真实的 `...beyond_break-even/...` 路径；该修复只恢复 source-anchor 校验，不改变时序数值或行为；
- 未模拟 signal-processing arithmetic、transport、jitter、pulse waveform 或目标 FPGA latency，因而不把结构完整性包装成硬件完成度。
