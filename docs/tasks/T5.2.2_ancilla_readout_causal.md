# T5.2.2 任务记录：ancilla bit/phase flip 与 readout error 独立注入

- Task ID：T5.2.2
- 日期：2026-07-16
- 状态：Done

## 输入、通过标准与失败分支

输入为 T2.2.2 sBs ancilla/readout effective overlay、T5.1.2 aggregate drift lane、T5.1.6 nonmixing/
feasibility contract、T5.2.1 causal-campaign contract和 Sivak 2023 S4I 一手行锚。通过要求是 bit、phase、
readout 三类 fault 分别注入，敏感度方向符合协议机制，并有独立 seed-cluster uncertainty、解析 rate 和全交叉负控。

失败分支包括：同一 intervention 同时改变两个概率；沿用旧 single-seed aggregate；把 phase flip 当 Z-basis
toggle；readout-only 偷加 reset-failure；shots 伪重复；truth 进入 deployable record；生成跨族总分；parent/source/
implementation 漂移；effective simulation 升级为 device/physical-LER claim。

## 执行方案

1. 冻结 bit-only、phase-only、readout-only 三族和 `0--0.08` 六点 rate grid；
2. 使用 8 个新 evaluation seeds、4,096 cycles/cell 与 balanced four-label schedule；
3. family/seed 内跨 rate 使用 common random numbers，seed 作为 bootstrap cluster；
4. 同报主效应与全部不应变化的交叉效应；
5. 解析核对 `p`、`0.5p`、`0.01p`、`0.3p`；
6. 绑定 parent/code/source/CSV hash，并以 mutation suite 拒绝 coherent rewrite。
