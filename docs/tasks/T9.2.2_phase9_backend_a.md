### 3. reset、leakage persistence 与 action-conditioned drift

6. evaluator target mutation、future suffix、wrong-round RNG、reset-ack inversion、nonpositive density、non-Hermitian H、non-TP generator、zero-duration pulse 等均有负向测试。
