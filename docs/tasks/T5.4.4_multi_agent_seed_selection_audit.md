## 风险与论文 claim

新增 R-N100。当前 selection discipline 合格，但 best-of-N 会明显夸大 agent gain，teacher 的 test ranking
确有反转，legacy predecessor 又缺 all-candidate test。只允许全体分布与冻结 candidate 结果，不能声称
无选择偏差、optimizer optimality 或 universal learned gain。
