## 执行方案与实际完成

先审计 finite-energy folded response，发现当前对称 state 的 hard MAP 在零偏置时退化为
standard，不能用 soft posterior 形式交差。因此选择 sBs 路径：精确计算
preparation/readout/reset-conditioned constituent matrices，从四个 pure carry state验证唯一
stationary distribution，再生成 9×4 branch posterior LUT。在线 decoder 只消费当前
`g/e/leakage` pair；hidden carry 被边缘化。

动作空间为 4 个 ideal Kraus branches 加 `FALLBACK`。错误 branch loss=1、正确=0、fallback
cost 显式登记；fallback 只允许 observed leakage，非 leakage 不允许 confidence rejection。
比较保留 direct observed、forced static MAP、protocol-aware cost policy 和 nondeployable truth
reference，并注册为独立 branch target，不与 logical standard binning 混表。
