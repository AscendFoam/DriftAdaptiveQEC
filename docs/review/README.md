# Review 记录

本目录保存历史任务和里程碑的独立审阅结论。Review 说明当时产物是否通过约定 gate，但不自动代表当前 claim 仍开放。

- `T*_review.md`、`T*_gate_review.md`：单任务或证据门审阅。
- `Milestone*_review.md`：阶段性审阅。

当前新任务序列的完成记录见 [`../new_tasks/README.md`](../new_tasks/README.md)；按 Task 汇合报告、Review 和机器证据请用 [`../document_catalog/README.md`](../document_catalog/README.md)。
