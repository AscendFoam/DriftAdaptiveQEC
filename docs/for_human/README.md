# 面向人的解释材料

本目录保存阶段任务的通俗解释、答辩准备和 reviewer-facing 说明。它们用于理解，不是任务状态或机器证据来源。

- `T*_explanation.md`：历史任务的简明说明。
- `T*_reviewer_explanation.md`：面向审阅者的补充解释。
- 主题长文：论文草稿逐段解释、PPT 图讲解和问答准备。

当前任务状态请读 [`../new_task_board.md`](../new_task_board.md)，新任务完成记录请读 [`../new_tasks/README.md`](../new_tasks/README.md)。
