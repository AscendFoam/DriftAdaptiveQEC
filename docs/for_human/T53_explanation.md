# T53：主线理论分析文档说明

## 1. 这次补了什么

这次补的是一份给你看的“主线理论说明书”：

- 文件：`docs/paper_materials/mainline_theory_analysis.md`

它不是论文草稿，也不是新实验报告，而是把当前项目真正正在跑的那条主线，从理论到实现完整串起来：

1. 近似 GKP 码是什么
2. syndrome 为什么是模晶格量
3. 误差怎么累积成逻辑错误
4. 为什么快回路是 `Δ = K s + b`
5. teacher 在这里到底做什么
6. CNN 为什么学的是 `residual-b`
7. `ParamMapper` 怎么把噪声参数映射成运行时 `(K, b)`
8. FPGA 快回路到底读写什么
9. 整个快慢回路如何闭环

## 2. 这份文档最重要的价值

它把项目主张收得更准了：

- 不是“CNN 取代 GKP 解码”
- 而是“在实时硬件约束下，用经典 teacher 打底，让轻量 CNN 只修正快回路真正用到的 residual-b”

这能帮助你后面无论是继续写论文、做汇报，还是继续拆实验，都更不容易把问题讲偏。

## 3. 我刻意保守处理了什么

我在文档里专门把这些边界压住了：

1. 没把真 `.tflite` runtime 写成当前已恢复
2. 没把真板写成已验证
3. 没把历史更强表述反向升级成当前事实
4. 没把 `Gated v5` 写成已经稳定成熟的新正式主线

所以这份文档可以放心作为“理解主线”的材料，但不能把它当作新的结果升级文档。
