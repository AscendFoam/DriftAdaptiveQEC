# 图件与生成脚本

本目录保存论文图、补充图和汇报图的生成脚本及渲染产物。阅读图件前应先查看对应的顶层 figure contract 或 [`../document_catalog/phase7/README.md`](../document_catalog/phase7/README.md)；图片本身不单独升级论文 claim。

- `make_*.py`：可重复生成入口。
- `t*/`、`route_a_*`、`phase6d_*`：按 task/主题保存的输出 bundle。
- [`../figure_assets/README.md`](../figure_assets/README.md)：源数据和可编辑资产说明。
