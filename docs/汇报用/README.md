# 汇报用材料

本目录保存项目汇报、阶段展示、口头讲解和 PPT 相关材料。它们主要服务于汇报表达，不承担当前计划、当前任务或实验事实入口。

## 子目录

| 子目录 | 内容 | 使用方式 |
| --- | --- | --- |
| `4月汇报材料/` | 早期项目汇报 PPT、drawio 图、口头汇报稿和相关构建 manifest | 可作历史展示材料；当前证据边界需回到治理文档与任务产物核对 |
| `5月汇报材料/` | 后续 note / 口头汇报解释材料 | 可作论文表达和汇报辅助；不作为实验完成事实来源 |

当前项目状态以 `docs/02_experiment_plan.md`、`docs/04_task_board.md`、`docs/07_handoff.md` 和 `docs/08_risks_and_open_questions.md` 为准。
