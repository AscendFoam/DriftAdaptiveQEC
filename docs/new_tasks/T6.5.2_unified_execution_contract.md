## 深审与非简化实现检查

首轮实现不是以“存在 schema 文件”作为完成条件，而是对所有方法逐字段 mutation。自检首先
发现 logical dual-bank payload 与 duplicated read-port mirrors 被错误合并为 45,232 bit；已拆成
22,616/45,232 两种口径并重新生成报告。随后发现 direct dataclass 构造可绕过 mapping validator
传入负 cost；已把类型/非负检查下沉到 accounting object。standard binning 原先写成 bypass LUT，
会形成伪共享路径；已改为 T6.6 必须编译固定 common-grid image 并做 exhaustive equivalence。

更重要的是，现有 phase-conditioned RTL LUT 不能无损表示 software full 2D joint MAP。任务没有
通过重命名掩盖它，而是将 `static_joint_map` 保留为 strong observed-only software comparator，
同时锁死 current-RTL promotion，直至有 projection proof 或新 RTL。
