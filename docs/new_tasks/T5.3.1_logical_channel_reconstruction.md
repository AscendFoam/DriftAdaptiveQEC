## 实际完成内容

实现六 Pauli eigenstate 的 finite-cutoff repeated-channel simulator；QEC-on/off 使用同 code basis、noise、
cutoff、初态和 `10 us` cycle，仅 intervention 不同。以 unnormalized code output 重构 CPTNI PTM/Choi，保留
leakage、non-Pauli、non-unital 和 state-dependent survival；用 raw signed-area/censored crossing 报三轴 lifetime。

最初 cutoff 12/16 出现性能方向与大 PTM 差，未按 demo 两点收口；正式扩展到 12/24/36/40，并用 36/40
terminal tolerance 做数值 QA。artifact validator 从 raw outputs 全链重算所有 derived tables。
