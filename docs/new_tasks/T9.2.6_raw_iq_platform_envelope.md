## 实际完成内容

1. 冻结两个严格 512 ns profile：125 MS/s × 64 与 250 MS/s × 128；只接受显式 `RateId`/`DomainId`。
2. 冻结 32-bit `TDATA`（I16/Q16、Q1.15）与无空洞 128-bit `TUSER`；后者覆盖 timestamp、window/sample/channel/rate/domain、config version、16 类 error flag 与 reset epoch。
3. 实现完整 packet validator：TVALID/TREADY 稳定、精确 TLAST/长度/index/timestamp、channel/domain/version、跨窗 replay/reset freshness 和固定错误优先级。
4. 实现 192 ACLK deadline 与状态化 quarantine：timeout 只增加一次 poison receipt；完整 sample-0 重放不能伪装 drain；只有全部 beat 属于旧事务且 sample index 非零的匹配 TLAST 尾段，或完整合法 `epoch+1/window0/config-hold` reset，才可解封。畸形 reset 不改变状态。
5. 实现 bit-exact complex matched filter（35-bit component、48-bit accumulator）和 2×2 affine calibration（66-bit product、67-bit Q19.48 sum、ties-to-even、24-bit saturation、sticky overflow）。
6. 冻结完整 A/B package：post-quantization coefficient energy、canonical little-endian payload、内部 CRC32、version/profile/activation window、exact package SHA/LKG。T9.2.4 为 NO-GO，因此 trusted qualification receipt 为 `null`，当前成功 activation 数严格为 0。
7. 对 package/bank/AXIS/rate/domain/matched-filter 的 Python `bool == int` 别名统一 fail closed。
8. 冻结四个不可混排 latency boundary；六周期/II=1 仅属于 fast core 与待复证的 discriminator-out boundary，ADC/raw-IQ source-to-trigger 仍为 typed null。
9. 冻结 ZCU111/ZCU216 的 source-confirmed 候选交集和设计 budget；GW2AR 明确只作低速数字参考。没有把候选、预算或 250 MHz target 写成综合/P&R/板测结果。

## 反简化审计

初版虽已通过自动门，独立审计仍连续发现并推动修复四类非 demo 级问题：

1. 任意非零 SHA 文本可作为 qualification receipt：改为 module-level exact trusted receipt；当前 NO-GO 下为 `null`，所以真实 commit 全封闭。
2. timeout 后可直接重发整窗：增加跨调用 quarantine 与 poison-once receipt。
3. reset 首 beat 可提前清 quarantine：改为完整 packet + reset freshness/config 全部成功后原子 clear+retire。
