## 实际完成内容

1. 给出解析证明：对 `Λ=λZ²` 和 isotropic Euclidean metric，平方距离是 q/p 两个无 cross term 的独立平方和，因此 CPD Voronoi region 为 `∏ᵢ[(kᵢ−1/2)λ,(kᵢ+1/2)λ)`，与 componentwise CI 完全一致；正半边界按冻结规则归入较大整数。
2. 实现独立 16-candidate local-enumeration CPD oracle，没有调用 CI 取得非 tie winner；只在几何 minimizer 非唯一的 exact half-integer 上显式执行 ties-up rule。
3. 穷举 production `1024×1024=1,048,576` 个 q/p code-centre pairs。CPD/CI index 与 action hash 完全一致，0 mismatch；同时明确 canonical centered cell 的 action 全为 00，这一项本身是平凡编码事实，不能冒充广义 alias/MAP 证明。
4. 另用 seed `61710001` 生成 1,000,000 个 unwrapped 2D boundary points（2,000,000 coordinates），覆盖 alias cells `[-2048,2048]`、exact half、16-ULP 上下侧和多尺度 epsilon 上下侧。含 332,386 个 exact-tie coordinates，CPD/CI 仍为 0 mismatch。
5. 构造并独立复算三类不等价反例：
   - biased：canonical one-cell mean shift 使 CI class 0、periodic likelihood MAP class 1；32-cell independent alias sum 同意。
   - correlated：固定 `σq=σp=0.42λ, ρ=0.9`，在预定 101×101 midpoint grid 上按 lexicographic first mismatch 取 witness；2,424/10,201 points 与 CI 不同，project MAP 和 radius-20 double alias sum 均给 class 2。
   - finite-energy likelihood：固定 `Δ=1.0` 的 normalized damped-projector logical-state likelihood，在 2,001-point canonical grid 上有 192 points 与 CI 不同；独立 peak-table wavefunction reconstruction 相对误差 `2.74e-16`。
6. 建立 comparator registry：`closest_integer` 与 `square_euclidean_cpd` 共用一个 equivalence class，ranking weight 总和严格为 1；`periodic_coset_map` 保持独立 decision object。
7. 对 source/ontology 使用 scientific-semantic lock，对 implementation、prereg config、physics/runtime inputs 和 Source Data 使用 exact lock；primary literature interpretation 逐项写入 58-row Source Data。

## 深度检查与修正

- 首轮 boundary brute-force 出现 83/1,000,000 mismatch。没有降低门限；逐项定位后确认它们来自 exact half-integer 两个等距平方在 float64 中相差约 `5.55e-17`。修正为显式 exact-tie handling，并用 16 ULP 区分“真正 tie”和“可表示的非 tie”，最终保持严格 0 mismatch。
- 单元测试又发现 `floor(x+0.5)` 会把 `nextafter(0.5,-∞)` 的加法舍入为 1.0。CI reference 已改为 `floor(x)` 与 fractional-part comparison，确保 one-ULP below/tie/above 三者严格区分。
- production canonical-domain 全 00 不是有内容的 decoder 胜利；报告和 gate 强制声明其平凡性，并要求独立 unwrapped boundary stratum 承担 nontrivial parity/tie 证据。
- 零 mismatch 不再只写 `0`，补充了各 stratum 的 exact one-sided 95% upper bound；runtime/memory 只标成 Python correctness workload，禁止迁移成 decoder/FPGA latency。
- correlated/finite-energy witness 不选择最大有利 margin，而按固定 grid 的第一个 mismatch；避免以反例搜索变成性能 cherry-picking。
