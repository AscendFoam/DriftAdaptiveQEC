## 非简化实现复核

首轮长跑在官方 `mwpm -> PythonCall/pymatching` 路径第 83/156 cell 出现 Windows native `EXCEPTION_ACCESS_VIOLATION`。没有靠重跑或减少 cells 回避，而是实现 d=3 全 edge-subset exhaustive T-join，并先与 official pymatching 做 128 个随机 correction 零差对拍，再用于完整长跑。复核同时发现 residual 恰为零时 `sign(0)` 会把 Gaussian edge gap 错写为零，已改为严格闭式 `1-2|r|`。

更关键的深审发现，最初探索性运行把 cell-specific spatial-pattern/variance-law loading 间接传给了 decoder；该结果被整体作废。最终运行只允许 decoder 使用过去 folded-residual 的 circular moments、当前 syndrome/residual 和 nominal base sigma，`pattern/family/latent` 仅留在 generator 与离线评分。移除 privilege 后未保护 posterior-predictive 路径显著退化；冻结 risk action 的零回退也暴露为不安全，于是按已有 contract 把 immutable trusted static bank 纳入 ambiguity set，并在 robust support 不足时 fail closed。这个修复没有改变 seeds、families、rounds、baseline 候选、统计门或读取未开放 split。最终相对 strongest baseline 的 headroom 为零，因此保留 NO-GO，没有调 amplitude、删 family、换 denominator、降低阈值或打开 pilot/formal。“causal ceiling”只代表已注册有限候选栈，不是所有因果解码器的数学上界。
