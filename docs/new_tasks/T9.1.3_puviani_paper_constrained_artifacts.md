## 反简化实现复核

本任务不是 demo-only：40 agents 真正完成 40,000 epochs、所有 checkpoint/ledger/raw events 保留，串行 release、atomic witness、live manifest、独立 validator 和 81 个可杀 mutation 都已执行。但深审确认它**仍不是性能或 lifetime 实验的完成态**，必须保留以下负边界：

1. 六态 primary/confirmation 只有 10 cycles，无法替代 paper 1,000-cycle或 Phase 9 `>=10^4` lifetime；
2. 只有 8 clusters / 56 RNG streams，不能冒充 Phase 9 统计功效和独立 cluster multiplicity；
3. MF 与 NMF 的参数量、训练/推理 compute 和 selection budget 未 matched，不能从当前数值推断 architecture/NMF 优势；
4. cutoff 12→16 的数值变化具有实质性，不能把 cutoff 12 当作已收敛 paper-scale physics；
5. 六项 tomography diagnostics 的 `passed_physicality=false`；Monte Carlo pair-sum residual 范围 `0.00975--0.05396 > 2e-8`。它们按原合同是 non-hard diagnostics，因此不推翻 artifact integrity PASS，但严格阻止 physical-channel/lifetime promotion；
6. `10^6`-cycle RTL、board HIL、QPU/real-GKP 与 external same-task speed 均未发生；
7. current action signature 与 Phase 9 matched deployable ranking 不同，qualified baseline 必须在 T9.1.4 以后重新取得 eligibility。

因此 actual outcome 映射为 `QUALIFIED_PAPER_CONSTRAINED_BASELINE`，含义仅是“artifact baseline 完整且可执行”；备选 `NO_GO_PAPER_CONSTRAINED_REIMPLEMENTATION` 同样释放 downstream，但只允许 typed-null baseline rows。两者都不开放 official、surpass、paper lifetime、physical lifetime 或 SOTA。
