## 验证方式和结果

21/21 gates、521 Source Data rows、24 direct tests、151 adjacent tests。每种精度真实执行 16M teacher 和 64M student updates；teacher
hidden `<0.383`，students 不越解析凸包，float32 最大动作误差 `1.263e-6`，120 个 reset 全在 20 half-cycles
内恢复。2-cycle 长时 worst MSE `8.14e-4` 为负结果；10/32-cycle mean+worst 均过 `5e-5` 门。

## 风险复核

新增 R-N101：长时 recurrence/imitation 不等于长时 physical gain、logical lifetime、leakage robustness 或
device/hardware evidence。必须持续保留 short-horizon failure 与 all-e worst stream。
