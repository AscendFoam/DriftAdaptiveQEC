## 实际完成内容

在既有 runtime scheduler 上实现 burst/FIFO backlog、jitter budget、communication pause、window-age
deadline 和 parameter conflict 的结构化事件与 snapshot。修复第二 writer 静默覆盖 pending update
的真实缺陷；冲突现在 transactional fail closed。构造 7 场景、8 paired seeds、64k cycles/组的
observed-only stress validation，同时报告 LER、fast/fresh/end-to-end availability、latency quantile、
逐事件计数和版本完整性。
