## 实际完成内容

### 1. 五 namespace 与 observed-only API

- 冻结 `BACKEND_LATENT`、`DEPLOYABLE_OBSERVED`、`CONTROLLER_MEMORY`、`EVALUATOR_TRUTH`、`PROVENANCE`；`ACTION_WORD` 是独立输出，不是第六输入 namespace。
- deployable 路径只有 `deployable_decision(observed, memory)`；`total_recurrence(key)` 只有一个参数。
- hidden state、future suffix、evaluator truth、seed/trace/config provenance 均被 exact allowlist 与 recursive denylist 拒绝。
- observed schema 包含 I/Q frame、matched-filter/LLR、discriminator/confidence、leakage confidence、timestamp、reset acknowledgement 和前一轮 action/key/version receipt。
- I/Q 在 T9.2.1 只冻结 transport-neutral envelope：非空、I/Q 等长、至多 65,536 samples、signed-int64 container；sample rate、窗口、ADC/系数/累加器/LLR 位宽、Q-format、rounding、saturation 明确保留 `null`，延后到 T9.2.6。

### 2. 有限 key、总递推与组合完备性

- composite key 为 24 bit：
  `K=(bank_id[2], discriminator_word[8], phase_frame[2], event_class[4], leakage/reset FSM[8])`。
- nominal `N(bank, word)` 完整枚举 `4×256=1,024` cells。
- transition `T(phase,event,FSM,nominal-action)` 完整枚举 `4×16×256×8=131,072` cells。
- 全 raw Cartesian domain 为 `16,777,216` keys；由 12 个可审计 nominal equivalence signatures 形成 `196,608` 个 lossless composition cells。
- equivalence witness 保存 1,024 个 raw N key 到 signature 的完整映射 hash、12 个 signature records、class sizes、代表 key 和 signature hash；class-size sum 精确为 1,024。
- `total_recurrence` 与 composition 枚举共同调用唯一 `_action_from_factors` 组装路径，避免“manifest 验证一套、实际 F 运行另一套”。
- 完整 syntactic T domain 中有 68 个状态从 NORMAL 图可达，192 个有效 FSM state 有 ACK-success/hysteresis reset witness、最大距离 3；该图包含 reserved event 与未经过 previous-receipt gate 的 event，明确不是 deployable-causal reachability 结论。

### 3. fail-closed fault canonicalization

- 冻结并由 runtime/config 双向核对 14 级优先级：
  `INVALID_KEY -> RESERVED_ACTION_OR_EVENT -> INPUT_CRC -> IMAGE_CRC -> IMAGE_SHA -> PARTIAL_PACKAGE -> UNKNOWN_VERSION -> VERSION_MISMATCH -> ROLLBACK_VERSION -> STALE_PACKAGE -> DEADLINE_MISS -> OOD_WORD -> RESET_ACK_UNEXPECTED -> PERSISTENT_LEAKAGE`。
- 多故障同时出现时只按这一顺序选首故障；invalid/reserved/integrity/version/deadline/OOD 进入 LKG hold，unexpected reset ack 与 persistent leakage 进入 bounded reset。
- 130 个非 legal discriminator words 被定义为可达 OOD/fallback，而不是不可达 invalid demo branch。
- `previous_composite_key` 与 `previous_action_word` 必须由同一 `F(K)` 重新计算并逐字段相等；仅 CRC 正确但 recurrence 不可达的伪造 reset receipt 被拒绝。该机制证明 deterministic semantic consistency，不宣称密码学真实性；传输认证与持久化完整性仍由后续 integration/frontend 资格化。

### 4. 80-bit action 与版本 sideband

- action payload 为连续 64 bit，加 `CRC-16/CCITT-FALSE` 16 bit，总宽 80 bit。
- action 包含 valid、action/enable/reset/fallback/hold、Pauli delta、next phase/FSM、catalog ID、zero residual、reason/error、source bank 与 16-bit factor tag。
- active image version 是 16-bit nondecision receipt sideband，不再作为 `F(K)` 的隐式决策输入。
- 构造器和 unpack 同时拒绝 reserved action/reason/FSM、非零 residual、action/flag/Pauli 矛盾以及不可达 reset 语义；篡改 payload 后重新计算 CRC 仍不能绕过语义检查。
- 现有 58/118/232-bit RTL 与本 80-bit 逻辑 action 的 adapter 资格保持 `false`，留给 T9.2.6/T9.5。

### 5. slow-path 权限边界

- slow model 只能提名一个完整预编译 package，精确字段为：
  `schema_id/package_id/bank_target/version/activation_epoch/word_count/crc32/content_sha256/provenance_sha256/release_pin_sha256/entries`。
- validator 要求 A/B inactive bank、256 个完整 entries、严格更高 version、安全 activation epoch、CRC/SHA 正确、trusted schema/package/provenance registry 与 external release pin 全部匹配。
- 单 entry patch、partial package、active-bank 写权限、逐周期 action、host callback、free-form waveform 均不在本 API 内。
- T9.2.1 只资格化 nomination validator；atomic bank integration 仍为 `false`，由 T9.3.3/T9.5.1/T9.5.3 承接。

### 6. 16 个可执行 representative probes

- 覆盖 idle、q/p 正负、alternating axes、quantizer boundary、非零 phase-frame、三步 persistent leakage、reset success/failure、CRC/integrity、stale/version、low-confidence 后 OOD、deadline 与 LKG recovery。
- reset acknowledgement 的 prior RESET 由可执行三步 leakage deployable trace 产生，未使用手工不可达 receipt。
- 每个 coverage tag 均从实际 `DecisionReceipt` 的 event/action/reason 推导；标签与实际执行结果不一致时 probe 失败。
- 所有 probe 固定 `probe_only=true`、`codebook_candidate=false`、`performance_evidence=false`、`ranking_evidence=false`。

## 反简化实现复核

本 task 在初版可运行后继续发现并修复了以下非 demo 级问题：

1. 初版 `F` 仍接受 version/integrity side inputs，导致同 K 可能不同输出；现已改成单参数纯递推并增加 upstream canonicalization。
2. 初版 fault priority 与 config 顺序不完全一致；现由 runtime tuple 与 config priority IDs 精确双向绑定。
3. 初版 OOD 被错误并入 invalid，真实 observed path 不可达；现 130 个 reserved words 明确进入 OOD/LKG。
4. 初版 probe 只是描述；现全部走真实 observed→assembler→F 路径，并从 receipt 推导 coverage witness。
5. 初版 reset probe 使用手工 receipt；现用三步 leakage 生成可执行 RESET，并用 previous K 做逐位重算一致性检查。
6. 初版 CRC 只验证传输完整性，重算 CRC 可携带 reserved/矛盾 payload；现增加 action semantic validation 与负向篡改测试。
7. 初版 composition 使用与实际 F 不同的 ActionWord 组装代码；现合并为唯一 `_action_from_factors` 路径。
8. 初版 lossless quotient 只有布尔常量；现增加完整 N-key→signature 映射、class histogram、representatives 和 hashes。
9. 初版 slow package 只检查长度/CRC；现增加 registry、ledger、provenance、release pin、epoch、bank 与 exact-field checks。
10. 初版 IQ array 无物理/传输边界；现冻结保守 container checks，同时明确 T9.2.6 未完成项为 null，未伪造 frontend 资格。

因此本 task 证明的是“接口与有限总递推合同闭合”，不是高保真 physics、最终 codebook、当前 RTL adapter、LER/lifetime、硬件实测或 SOTA。
