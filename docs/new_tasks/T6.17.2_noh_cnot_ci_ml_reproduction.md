## 实际完成内容

1. 先完成 source-sufficiency gate，而不是先写近似模拟器。一手论文完整给出 9 项必要 ingredient：有限 squeezing 方差、8 个 iid primitive shifts、q/p 四个净位移、CI rule、q/p joint ML quadratic form、odd-index failure mapping 和 Table-I anchors，因此进入预注册的 `PROJECT_NATIVE_MATCHED` 分支。
2. 对 `lambda=1` 实现 Appendix C 的 8-shift CNOT model：
   - `q1=xi1+xi2`、`q2=xi1+xi3+xi4`；
   - `p1=-xi5+xi6+xi7`、`p2=xi5+xi8`；
   - `sigma_gkp^2=0.5*10^(-dB/10)`。
3. 实现 componentwise CI 与论文 Algorithms 1/2 的两个 correlated 2D ML Voronoi classifiers；另实现独立 25-candidate likelihood oracle。后者的 radius-2 完备性由 covariance quadratic form 的 `lambda_min/lambda_max` 界证明，不依赖“随机没出错”。
4. 使用 32 个相同 seed clusters 和相同 primitive Gaussian draws 同时评价 CI/ML。每轮每 seed 2,048 trials，只在一整个 seed sweep 后检查 stopping rule，避免有利结果早停。
5. 正式结果：
   - 9 dB：65,536 trials，CI `6563/65536=0.1001434`，ML `4518/65536=0.0689392`，paired reduction `31.160%`；
   - 12 dB：589,824 trials，CI `5146/589824=0.00872464`，ML `2158/589824=0.00365872`，paired reduction `58.065%`；
   - 13 dB：2,424,832 trials，CI `6362/2424832=0.00262369`，ML `2037/2424832=0.000840058`，paired reduction `67.982%`。
6. 六个 method/point 都同时通过 frozen absolute tolerance 和 25% relative tolerance；最大 relative discrepancy 为 `1.52%`。每点保存 Wilson 95% CI、paired discordant counts、exact McNemar p、20k independent-seed-cluster bootstrap 和 task 内 Holm adjustment。
7. 构造 50,000 对真实跨越 ML Voronoi facet 的 one-sided points，q/p 各 25,000 对，共 100,000 decisions；paper algorithm 与独立 oracle 为 `0/100000` mismatch，likelihood cost gap 为 0。exact tie 因 argmin 非唯一而显式排除，不用 tie convention 制造假 mismatch。
8. 报告固定 operation topology：CI 为四次 scalar rounding；ML 为四次 rounding 加两个固定深度 2D correlated classifiers，均是 per-gate `O(1)`。Python vectorized Monte Carlo runtime 只属 correctness workload，不改写为 decoder/FPGA latency。
9. Claim registry 保持：
   - Table-I gate reproduction = `PROJECT_NATIVE_MATCHED`；
   - 9.9 dB full surface–GKP threshold = `LITERATURE_ONLY_NULL`；
   - CI `<50 ns`、ML `>1 ms` = `NULL_UNSOURCED`；
   - hardware resources = `NULL_NOT_IMPLEMENTED`；
   - Phase 6B V5 NO-GO = read-only unchanged。

## 深度检查与修正

- 初版正式运行已经复现六个 anchors，但 variance gate 因 `sigma=sqrt(v)` 后平方产生约 `2e-17` 的正常 float roundoff 而失败；没有放宽实验容差，只把“公式相等”改成 2e-15 relative machine-precision check。
- Algorithm 2 初次人工转录把 `v4/v5` 错读成 shifted-cell expression，200 万随机点出现 133,204 mismatches。根据 Appendix B Eq. (B11) 重新推导 facet 方程后修正；随后 200 万随机探针、正式 100k boundary 和 focused test 均为 0 mismatch。
- boundary 不用普通高斯样本掩盖边界错误；直接从 q/p quadratic form 的真实 facet 生成 `±2^-30 lattice` 双侧点，并由 brute oracle 先确认 pair 确实跨 cell。
- 深审发现 gate 曾过度相信已存 `joint_pass`、paired difference 和 Source Data 哈希长度。已改为从 frozen anchors、raw counts、exact McNemar/Holm、Wilson 与 live file 重新计算；手改 `joint_pass=true` 或伪造 64 位哈希均 fail closed。
- 未下载到 official code 不构成 BLOCKED：该 Table-I gate experiment 的全部模型与算法在一手论文正文/附录中完整给出，且项目实现明确标成 `PROJECT_NATIVE_MATCHED`，没有冒充 `OFFICIAL_CODE_REPRODUCTION`。
- gate-level 复现没有包含 surface-code distance、matching graph 或 crossing/bootstrap，因此没有把相近的 failure reduction 改名成 9.9 dB threshold 复现。
