## 实际完成内容

1. 新建唯一 `gkp_route_a_converged_production_top`，exact-once 实例化：
   - `gkp_parameter_bank_manager`；
   - `route_a_commit_admission`；
   - `gkp_fast_path_core`；
   - `route_a_policy_overlay`。
2. 外部只暴露高层 begin/word/finalize/abort、host commit/cancel/snapshot 与 policy posterior/event 输入；不暴露 raw `cfg_we`、`bank0_trusted`、`bank1_trusted` 或 core commit bypass。
3. 将 bank image generation 与 core activation epoch 分离。新 image 必须严格大于两 bank 的 image version；每次 activation 仍只允许 active epoch `+1`。因此旧 trusted LKG image 可以在新的单调 epoch 下恢复，而不是因“image version 较旧”失去回滚能力。
4. 形式检查发现并修复两个真实缺陷：
   - core 已完成 bank/version 切换、manager 尚未观察到 registered ACK 时，原实现会重复呈现同一 commit 一周期；现在 core-facing commit 重新检查 boundary、different bank、plus-one、no-wrap 与 trust；
   - 最初的 `host bank == policy_selected_bank` 仲裁与 policy pending 自动生成组合后使 host CAS 路径不可达；现改为 policy valid/pending 优先、host 仅在 OPEN 时进入，inactive/trust/CAS 合法性继续由 manager 独占。
5. 形式证明不是 demo trace：
   - 三个 present-state predicate 对任意状态位/输入做 SAT all-state proof；
   - k-induction 闭合 reset-reachable manager/policy invariants 与 present guards；
   - 在任意满足上述已证不变量的 predecessor state 上证明全部 transition assertions；
   - 另保留 20-cycle reset-reachable BMC 作为完整事务/反例深度回归；
   - 13 个 manager/policy witness 加1个实际核心 witness 全部可达；
   - 21 个修改真实 RTL、保留独立 checker 的 mutant 全部由 formal counterexample 杀死，编译失败不计 kill；其中删除真实 core activation-version plus-one guard 的 mutant 专门阻断 vacuous commit proof。
6. 对真实 `gkp_fast_path_core` 连续注入 deadline violation 与 parameter-age violation 两个 II=1 样本，证明连续六周期输出均为显式 fallback、零 action/frame delta、对应 fault bit 可见；另以三步任意 predecessor-state harness 证明真实 core 的 ACK、bank 与 activation version 更新严格细化 manager 的 atomic commit contract。

## 深度检查与非简化实现复核

- 没有把模块拼接成功当作 atomic 证明；checker 与 mutated RTL 分离。
- formal image 深度从 production 257 降到每 phase 2 只用于让完整 ordered CRC transaction 在短 witness 中可达；present guards、inductive invariants 和 transition refinement 不依赖 production image 内容深度。报告明确记录该 reduction，未冒充 production storage exhaustive state enumeration。
- 最初 combined/monolithic k-induction 未闭合，未写入 PASS；通过新增真实状态不变量并分解证明后才升级为 unbounded safety。仍不声称 unbounded liveness/fairness。
- near-wrap 使用 initial activation `0xfffe` 的独立可达 witness；不是在20步内伪造从0递增到 wrap。
- actual-core deadline/age 证明读取真实 LUT core，而非只证明抽象 commit model。
- 第一版 actual-core atomic harness 只跑两步，新增错误版本 mutant 存活，证明存在初始化空窗；没有放宽 mutation gate，而是把任意状态证明增至三步。正确 core 通过、删除 plus-one guard 的 core 由 counterexample 杀死后，才完整重跑并生成当前 17/17、21/21 报告。
- board latency/jitter/power、跨工作 fastest、multimode decoder in RTL 全部保持 null/false。
