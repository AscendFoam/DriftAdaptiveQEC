## 关键审计结果

- Noh 两-GKP CNOT 的 ML 相对 CI failure reduction 随 squeezing 为 `31.782%`（9 dB）、`58.458%`（12 dB）、`67.192%`（13 dB）；“约 50%”不是通用值。
- `9.9 dB` 是 finite-squeezing-only 条件下完整 concatenated surface–GKP 的 finite-size threshold，不是 Table-I 门级 ML 或本项目 single-mode threshold。
- Wang direct NN 的 threshold 为 `0.78 vs 0.50`（perfect measurement）和 `0.34 vs 0.25`（noisy measurement）；论文“decoding rate +50%”没有可移植 denominator，因此规范化值为 null。
- NN/FPGA 只保留具体边界：Overwater `87.6 ns` post-implementation core estimate；Yang `124 ns` decoder core、`550 ns` end-of-readout-to-feedback real closed loop。
- AQEC experimental lifetime gain 为 `1.14(18)`/`1.14(16)`；classical decoder latency 是 N/A 而非 0。项目 T3.2.8 对应代理在 common wall-clock 下为 `0.805901--0.942271×`，没有借用论文正值。
- Lin structured surface–GKP threshold 为 CPD `0.602` 对 analog-MWPM `0.599`；单位保留 paper sigma，未换算 dB，复杂度按 lattice structure 分层。
- 项目 T5 仅为 preboard core `6 cycles / 222.222 ns / II=37.037 ns` estimate；source-to-action/closed-loop/measured 仍 null。V5 为 `NO_GO_V5_EARLY_HEADROOM_STOP`，无 adaptive/RTL/P&R 结果。
