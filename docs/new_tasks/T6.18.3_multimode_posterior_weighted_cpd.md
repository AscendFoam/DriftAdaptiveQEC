## 执行方案与实际完成内容

1. 固定同一 d=3 structured family，不外推 single-mode V5。构造九正/九负 coordinate signs，并令 `sigma_i²=base_sigma² exp(sign_i theta)/cosh(theta)`，使每轮平均方差严格保持 `base_sigma²`，漂移只改变 mode-dependent metric。
2. 四方法共享相同 displacement、surface-code stabilizers、syndrome、logical classification 与 trial：static Euclidean CPD、nominal weighted static CPD、observed-only posterior-predictive weighted CPD、true-current-metric oracle reference。
3. adaptive filter 只消费 folded residual，使用 17-state theta grid、periodized-Gaussian likelihood 与统一 16-cycle block update。当前 block 的 decode metric 在该 block observation 更新前冻结；真实 theta/sigma 与 future samples 禁止进入 adaptive path。
4. edge metric 使用 posterior predictive `E[base_sigma²/sigma_i² | past]`；oracle 才使用当前真实 metric。官方 MWPM/stabilizer/logical operator 直接复用，project adapter 未修改官方源码。
5. formal 使用四个独立 Julia shard，完整跑 32 seeds×3 families×100,000 cycles=9,600,000 physical cycles、38,400,000 comparator decodes；每方法保留 18,720 个完整 512-cycle windows，最后 160-cycle partial tail 只进入 aggregate p_L，不进入 tail。
6. paired uncertainty 以 seed cluster 为重采样单位，20,000 bootstrap；三个 deployable contrasts 用 100,000-resample 双侧 paired sign-flip 并在 task 内 Holm。global worst 与 mean per-seed tail 分列，oracle 不参与 Holm。
