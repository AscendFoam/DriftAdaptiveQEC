## 执行方案与实际完成内容

1. 新建独立 Python composition reference：
   - 复用既有且先于 converged top 的 core/policy executable specifications；
   - 重新独立实现 admission 与完整 production parameter manager；
   - 明确建模 Verilog NBA 前/后沿语义、registered core commit ACK、policy visible version 与 manager combinational debug；
   - 覆盖 257×2 个 22-bit word 的 ordered image、CRC32、inactive-bank trust、image/activation 双版本、CAS、cancel、drain、snapshot CRC 与 11 类 reject reason。
2. 新建 202-byte/周期 trace ABI：输入 54 bytes，独立期望公开输出 148 bytes；后者覆盖全部 ACK/reject/ready、core output/state、route action/state/version、management state 与 debug 接口，不只比较最终 action。
3. 新建 CXXRTL driver，从 T6.25.2 exact top 重新生成模型并逐周期比较全部 148 bytes；同时独立检查 source-to-action=6、MAP=5、route alignment、II=1、undefined action、版本单调性与 FNV digest。
4. 冻结 10 个 family，各 100,000 cycles：nominal II=1、smooth commits、tail hysteresis、calibration/integrity、telegraph race、burst/CRC/deadline、leakage/reset、full image、management fault/snapshot、compound transport。
5. 对 transport 注入 pause/backpressure/overflow/drop/duplicate/reorder/sequence/deadline fault，并要求 overflow 全部显式计账、FIFO/marker 最终排空。
6. 将 fault coverage 分为两类：
   - 可从 production 封装注入的 0/1/2/8/9/12/13 位必须命中并恢复；
   - 被 manager/数据通路结构排除的 3/4/5/6/7/10/11 位必须保持零。没有为追求覆盖率重新暴露 raw trust/config bypass。
7. 先后两次执行完整百万周期。第二次是在收紧验证器之后从头重跑；trace SHA-256 与第一次完全一致，证明刺激与 golden 确定性。

## 深度检查与非简化实现复核

- 第一版 CXXRTL driver 对宽总线错误使用不存在的 `operator[]`；按 CXXRTL 原生 `curr.data[]/chunks` 修正后重新编译，不以缩窄比较字段绕过。
- 短跑最初要求 active-untrusted fault 必须命中；审查确认该状态恰由 converged manager 结构性禁止。通过拆分 injectable/protected fault 并新增相反方向 mutation 修正测试语义，不恢复 raw bypass 伪造覆盖。
- 最初 6-cycle gate 只检查错位计数，尾部漏输出可能留下 pending queue 而假通过；现增加输入/MAP/route/output 数量守恒、逐 family Python/CXXRTL valid count 对齐和 `drop_final_output` mutation。
- `_validate_report` 现重新计算全部 gates 与 21 个 mutations，并核验 formal anchor、生成 model/executable、trace 和 live source；不能只改存储 JSON 的 `passed=true`。
- 没有复用 legacy trace 或只修其 hash；当前 trace 由 current-source golden 重新生成。
- 仍不声称四态 X/Z/timing unknown simulation、真实 transport/CDC/pins、板测 deadline/jitter/power、跨工作 fastest 或 multimode decoder in RTL。
