## 方案与实际完成

1. 冻结六条互斥 task-signature lane：single-mode decoder、surface–GKP gate/outer code、multimode structured CPD、controller/RL/NMF、AQEC wall-clock、FPGA implementation。
2. 建立 46 个 metric contract。每项固定 family、value type、unit、方向、denominator、statistic、aggregation、allowed lanes 和 conversion policy；覆盖 `p_L/p_X/p_Y/p_Z`、average/p95/worst/CVaR、CNOT failure、两类 threshold、lifetime/break-even、adaptation、false update/fallback、avoided/induced、deadline、latency/II、LUT/FF/BRAM/DSP/power。
3. 冻结六种 timing boundary：decoder core、update compute、transport、source-to-action、closed loop、initiation interval；II 明确属于 throughput，不是 latency。
4. 冻结 LUT/FF/BRAM/DSP/power 的 qualifier：device、primitive、tool、stage、seed/profile；power 另需 voltage/clock/activity/method。
5. 冻结八种 value state：measured、estimate、reproduced、literature、null、N/A、failed、negative。后四种 value 必须为 null 且不可排名；value state 必须与 task signature 的 evidence level 一致。
6. 定义 13-field exact task signature；raw comparison 还必须同 lane、metric、unit、denominator、statistic 和 timing boundary。
7. 将 T6.16.1 的 30 条 source metric 全量 crosswalk：29 条映射，Wang “decoding rate +50%”因 denominator 未定义而显式拒绝。
8. 实现 observation/comparison validator、101-row Source Data、16 个完整性门与 16 个一一对应 mutation。

## 反简化深审

- 初版只校验“字段存在”，深审后补上 value-state/evidence-level 强一致：P&R estimate 与 board measured 即使数值/边界相同也不能直接排名。
- 不提供 global-score API；cross-family 只能进入分面 atlas，不能通过权重变成总分。
- symbolic complexity 只有 `recomputable_numeric` 或带 locator 的 `source_asymptotic` 两种依据；“低/中/高”意见不可进入值域。
- source-to-action 的组件关系只是一条显式 composition contract，不允许在缺失事件边界/组件实测时自行相加；closed-loop 与 core 始终分开。
