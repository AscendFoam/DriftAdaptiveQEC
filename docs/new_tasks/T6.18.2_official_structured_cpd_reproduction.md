1. 固定官方实现和可复现环境：导入 `third_party/LatticeAlgorithms.jl`，锁定 commit `01f9bf1f6970b3e229b43aac9da3325c75518db8`、Apache-2.0 license、Julia 1.10.11、`configs/literature/t6_18_2_julia_env/Project.toml` 和 `Manifest.toml`。官方源码未修改。

3. 建立四层 exact audit：1–4 维 certified brute-force CVP 312 个；d=3 official fast CPD 对 generic exact CVP 64 个；single-mode boundary 10 个；final-list logical classification 对 canonical lattice coordinates 384 个。所有比较均为 0 mismatch。
4. 独立执行 d=3/5/7、9 个 `sigma`、32 个 paired seed、每 seed/cell 2000 trials，共 1,728,000 paired trials。CPD 与 analog-MWPM 共享 syndrome、topology、shift 和 logical classification，只有 edge weights 不同；analog 路径明确标为 source-transcribed adapter，不冒充官方仓库原生函数。
5. 对官方 Fig. 5 JLD2 聚合数据重新拟合，用作作者数据的 aggregate reanalysis；独立小距离 Monte Carlo 与官方聚合结果分列，禁止相互填数。
6. 报告 steady-state runtime、allocation 和外部 working-set 采样；三尺寸指数只标为 diagnostic，不替代论文的渐近 scaling。

## 主要结果

- 官方聚合数据逐位重算：CPD `0.6024563484 ± 0.0003776410`，analog-MWPM `0.5995937637 ± 0.0004433259`，与冻结 anchor 最大差为 0。
- 独立小距离 crossing：CPD d3/d5=`0.601232`、d5/d7=`0.597364`、均值 `0.599298 [0.596451,0.602584]`；analog-MWPM 对应 `0.602435`、`0.598056`、`0.600245 [0.598032,0.602991]`。两者均进入预注册 anchor 的 ±0.02 tolerance。
- 27/27 个 d×σ cells 中 CPD LER 低于 analog-MWPM；平均 paired `CPD−analog` LER=`-0.0116209491`，范围 `[-0.016578125,-0.006]`。该结果只属于冻结的小距离 stationary family，不是全局 decoder 排名。
- steady median runtime（d=3/5/7）：CPD `194.7/465.2/904.5 μs`，analog `184.2/451.6/881.5 μs`；CPD allocation `56.6/155.9/334.0 KiB`。三点经验 time exponent=`1.804`、allocation exponent=`2.086`；论文 `d^3.020` 仍为 literature-only。外部进程观察到的 working-set 高水位为约 `864.3 MiB`，不是精确 peak RSS。

## 深度检查与非 demo 修正

- Julia `PythonCall 0.9.35` 在本任务要求的 `--compiled-modules=no` 下触发 world-age 问题；按官方 Project compat 精确固定为 `0.9.10` 并重新生成 manifest，而不是绕开官方包。
- 官方 package 重复 include 导致常规 precompile 失败，因此固定使用 `--compiled-modules=no`，并在报告中披露；没有改写第三方源码。
- 官方 generic `closest_point` 在 n=1 存在 BoundsError；n=1 使用同仓库 exact `closest_point_scaled_Zn`，n=2–4 仍使用 generic，并以 certified brute force 独立核验。
- analog 权重按一手文献 Appendix B 使用 `-log2(p)`，没有改成直觉上的 log-odds；同一 trial 的 syndrome 和 logical classification 完全共享。
- seed-cluster bootstrap 跨整个网格复用相同 32 个 seed ID，并显式报告 missing fraction；没有把逐 cell trials 当独立 cluster 夸大显著性。
- 小距离 mean threshold 的方法次序与 d>13 官方聚合相反。该反直觉结果不删除、不增大距离追求有利交点，只降级为 coarse finite-size reproduction，并登记 R-N138。
