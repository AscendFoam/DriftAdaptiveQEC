## 实际完成内容

1. 对完整 GRU 重算 72,853 parameters、72,266 weight MACs 与 float32/float64 storage；参数 alone
   已分别需 127/253 BSRAM，连 core 后 135/261，故保持 offline teacher，不构造删层 demo 综合；
2. 从 selected checkpoint 生成全部 int8 weights 与 Q3.14 biases，588,694 parameter bits，hash 绑定；
3. 建立 manual-GRU-vs-PyTorch equation 校验和 522,240 个 action scalar comparisons 的 functional
   fake-quantized shadow；最大 action error `5.5199e-4`，但 physical gain 明确为 null；
4. 实现只用于否决的 optimistic lower-bound RTL：保存全部参数、真实消费全部 72,266 weights/587
   biases，不伪装成 functional GRU；
5. CXXRTL 验证 72,854-cycle exact completion，Yosys 保留 33 parameter ROMs + 8 core BSRAM；
6. 独立 bit-vector signature 复核发现 bias0 重复/terminal bias 遗漏与地址 587 越界；修复 prefetch/clamp
   后，CXXRTL signature `730990968` 与 72,266+587 顺序 reference 完全一致；
7. 修复 bias 与共享 core harness modulo-257 地址后重跑三 seed P&R，均过 27 MHz，最差 Fmax
   `39.1527 MHz`，最大 BSRAM/LUT4/DFF `41/3904/1011`；
8. 量化 GRU lower-bound 为 `2698.30 us`@27MHz / `1860.76 us`@min Fmax，远超 5 us；
9. 新增 toolchain provenance 与 deterministic gzip netlist，绑定当前 inputs/netlist/每 seed report/log；
10. 冻结 student 为唯一 eligible route，optional quantized GRU 标记 Dropped，full GRU 仅离线 teacher。
