## 非简化实现复核

首轮实现按口头估算使用 48 formal clusters；专项测试按 90% power 的正确 `z=1.2816` 重算后证明 48 只是最低 N，而非有余量设计。未降低 power 或比较数，seal 前将 N 提升到60并真实重建 1612 cells、3,194,880 rounds/method 与 38,338,560 decode cap，功效升至0.9631。第二轮复核又发现“报告内 audit 字段可能自证”，因此 validator 现从 compact config 和 cells 独立重算 opened/disjointness/cells/balance/power；直接改 seed 或 cell 即被拒绝。该任务没有生成或读取任何 registered pilot/formal outcome。
