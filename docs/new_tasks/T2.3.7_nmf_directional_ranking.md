## 实际完成内容

实现 standard、70,159 参数 memoryless MF、72,853 参数 NMF 三条同模型 lane，冻结
10-cycle area-equivalent lifetime、严格 train/validation/test/confirmation seed split 与
validation-only checkpoint selection。每个 trainable family 训练 5 个 agents、9,000 条
update trajectories，正式测试每 agent 512 条，cutoff 16 confirmation 每 agent 128 条。
同时实现 hidden-reset 反事实、paired bootstrap、逐 agent gate、physical fidelity/code
survival/ancilla/control/density diagnostics、schema-v3 checkpoint 和 source/config/model hash。

审计中发现 V2 用 validation final fidelity 初始化 score baseline，遂废弃整批 V2 结果并以
train-only no-grad warm-up 完整重做 V3。V3 原子替换发生一次 Windows transient failure，
仅在逐模型 SHA 与 source/schema 全部核验后从 8 个合法 V3 checkpoints 恢复，剩余 2 个
重新训练；恢复目录和 provenance 均保留，未静默拼接或复用污染结果。

## 是否需要插入新 task

不插入。现有 T3.2.7/T3.2.11 负责 same-budget memory ablation，T4.4 负责 teacher 与
hidden-state 审计，T5.0.1/T5.4.5 负责论文趋势和长时外推，足以承接 R-N044。

## 对论文 claim 的影响

可将 NMF > MF > standard 写成当前 finite-cutoff、10-cycle、strict-split 模型内方向性
证据；不得写成 PRL 幅度或机制的完整复现，不得声称跨 cutoff 的 memory-specific gain、
optimizer optimality、真实 QPU 或 FPGA 结果。
