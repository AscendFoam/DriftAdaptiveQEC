# 延申理论精简版

本文是 `docs/reference/延申理论.md` 的压缩版，只整理理论脉络与可写作表述，不升级当前仓库的实验、`.tflite`、真板 HIL 或 benchmark 证据等级。

## 1. 核心定位

当前思路可以概括为：

```text
慢回路 CNN：从 syndrome history / calibration / noise proxy 中估计当前噪声状态
快回路 FPGA：执行低延迟仿射 GKP 线性估计
```

数学形式是：

```text
(K_t, b_t) = g_phi(X_{t-L:t})
e_hat_t = K_t s_t + b_t
```

其中 `s_t` 是当前连续 GKP syndrome，`e_hat_t` 是相空间位移误差估计，实际恢复通常施加 `-e_hat_t` 或更新 displacement / Pauli frame。

这不是让 CNN 直接替代 GKP 解码，而是让 CNN 预测当前噪声条件下更合适的仿射估计器参数。更准确的论文定位是：

> Two-timescale CNN-adaptive affine decoder for approximate GKP codes.

## 2. 为什么会出现 `K s + b`

GKP syndrome 是连续变量的模格点测量，不是普通 qubit 稳定子码中的 0/1 syndrome。多模误差可写作相空间位移向量 `e`，综合测量近似满足：

```text
s ~= H e mod Lambda
```

在小噪声区域内，先局部展开 modulo 格点结构，可近似为线性高斯模型：

```text
s = H e + eta
```

此时最自然的估计器是线性最小均方误差估计器。若真实误差 `e` 与 syndrome `s` 近似联合高斯：

```text
[e, s] ~ N([mu_e, mu_s], [[Sigma_ee, Sigma_es],
                          [Sigma_se, Sigma_ss]])
```

则最优线性估计为：

```text
e_hat = mu_e + Sigma_es Sigma_ss^{-1} (s - mu_s)
```

写成仿射形式：

```text
K = Sigma_es Sigma_ss^{-1}
b = mu_e - K mu_s
e_hat = K s + b
```

所以 `K` 表示 syndrome 与真实位移误差之间的相关结构，`b` 表示均值漂移、测量偏置、syndrome 零点偏移或格点分支 offset。

## 3. `b` 与 GKP 格点分支

GKP syndrome 具有周期性。一维情况下可写作：

```text
s = e mod sqrt(pi)
e = s + m sqrt(pi), m in Z
```

同一个 syndrome 可能对应多个候选误差。固定某个 lattice branch 后：

```text
e_hat_m = K (s + m sqrt(pi))
        = K s + K m sqrt(pi)
```

因此：

```text
b_m = K m sqrt(pi)
```

这说明完整 GKP 解码通常不是单个全局线性函数，而更像多个局部仿射函数的组合：

```text
e_hat = K s + b_m
```

其中 `m` 由最近格点、最大似然或 MMSE 权重决定。

## 4. 与 ML / MMSE / 最近格点解码的关系

完整 GKP 解码必须处理 modulo folding。真实后验通常是多个 lattice branch 的高斯混合：

```text
p(e | s) ~= sum_m w_m(s) N(e; mu_m(s), Sigma_m)
mu_m(s) ~= K_m s + b_m
```

因此不同 decoder 的关系可以压缩为：

| 方法 | 含义 | 优缺点 |
| --- | --- | --- |
| fixed affine | 使用一个固定 `K,b` | 最快，适合硬件；不能处理多分支后验 |
| piecewise affine | 先选 branch，再用对应 `K_m,b_m` | 更接近 GKP lattice 结构；控制逻辑更复杂 |
| MMSE | 对多个 branch 做加权平均 | 理论更强；实时成本更高 |
| nearest-lattice / CVP | 显式求最近格点 | 小规模或结构化码可强；通用情形复杂度高 |

`K s + b` 可以看作 MMSE / ML 解码在某个局部单分支区域内的低复杂度近似。

## 5. CNN 在这里学什么

噪声条件变化会改变：

```text
mu_e, mu_s, Sigma_es, Sigma_ss
```

因此也会改变：

```text
K*(theta) = Sigma_es(theta) Sigma_ss(theta)^{-1}
b*(theta) = mu_e(theta) - K*(theta) mu_s(theta)
```

CNN 的任务不是凭空学习量子纠错规则，而是从 `X_{t-L:t}` 中近似学习：

```text
X_{t-L:t} -> theta_t -> K*(theta_t), b*(theta_t)
```

这可以称为 adaptive LMMSE、amortized linear decoder 或 hypernetwork-style parameter generation。它的物理含义是：根据 syndrome 图样、校准信息、有限能量效应和噪声漂移，在线生成当前更合适的仿射 GKP displacement estimator。

## 6. 为什么适合 CNN + FPGA 双回路

该方案的工程合理性来自时间尺度分离：

| 回路 | 职责 | 约束 |
| --- | --- | --- |
| 快回路 FPGA | 对每个 syndrome 执行 `K s + b` | 低延迟、确定时序、定点矩阵乘加 |
| 慢回路 CNN | 周期性更新 `K,b` | 可用较复杂模型吸收噪声漂移 |

这比把完整 CNN、MMSE 或 mixture decoder 放进 FPGA 快回路更稳。实时路径保留为矩阵乘加，CNN 只影响参数更新。

推荐默认结构：

```text
K = K_0 + Delta K_phi(X)
b = b_0 + Delta b_phi(X)
```

其中 `K_0,b_0` 来自解析 LMMSE 或标定模型，CNN 只学习残差。这样比直接输出完全自由的 dense `K` 更稳定，也更容易解释。

## 7. 主要风险与适用条件

单个全局 `K,b` 的主要风险是无法表达 GKP 的周期非线性。当 syndrome 靠近 `+-sqrt(pi)/2` 等 modulo 判决边界时，后验可能多峰，单个仿射估计器会把多个分支平均。

因此当前架构更适合：

1. 噪声较小或多数样本远离 modulo 边界；
2. 噪声漂移慢于 CNN 更新周期；
3. CNN 输入包含足够的 syndrome history、calibration 和 hardware/noise proxy；
4. FPGA 定点位宽不会显著破坏 `K,b` 稳定性；
5. 目标是性能、延迟、资源之间的折中，而不是离线 Bayes-optimal decoder。

如果后续发现主要误差来自 modulo branch ambiguity，可以把 mixture-of-affine 作为离线上界或后续增强：

```text
e_hat = sum_m pi_m(X, s) (K_m s + b_m)
```

但不建议一开始把完整 mixture 放入 FPGA 快回路。

## 8. 训练目标

最基础的监督目标是 displacement regression：

```text
min_phi E[ || e - (K_phi(X) s + b_phi(X)) ||^2 ]
```

更合理的版本包括：

| Loss | 用途 |
| --- | --- |
| MSE | 最简单的位移误差拟合 |
| Mahalanobis loss | 按输出协方差加权残差 |
| lattice-aware loss | 不惩罚等价稳定子位移 |
| logical loss | 直接约束 logical failure / frame error |

一个更稳的训练策略是联合优化：

```text
L = L_disp + alpha L_logical + beta L_stability
```

其中 `L_stability` 可限制 `Delta K, Delta b` 的幅度，避免慢回路输出过激参数。

## 9. 公平 baseline

为了避免“不公平比较”，baseline 应分层设置。

### GKP 内层 baseline

| Baseline | 目的 |
| --- | --- |
| no correction | sanity check |
| closest-integer GKP decoder | 基础硬判决 |
| fixed analytic `K_0,b_0` | 静态线性估计 |
| static trained linear decoder | 排除“只是训练更充分”的因素 |
| oracle linear `K*(theta),b*(theta)` | 线性族上界 |
| MMSE / nearest-lattice 小规模上界 | 理论强 baseline |

### 自适应 baseline

| Baseline | 目的 |
| --- | --- |
| sliding-window LMMSE | 传统统计自适应 |
| Kalman / RLS 更新 `K,b` | 对比 CNN 是否必要 |
| LUT by noise bin | 对比 CNN 是否优于查表 |
| MLP 输出 `K,b` | 对比 CNN 的局部归纳偏置 |
| CNN 直接输出 `e_hat` | 对比物理结构约束是否有益 |

### 外层码 / MWPM baseline

MWPM 更适合作为 surface-GKP、GKP-surface concatenation 或 QLDPC-GKP 的外层 baseline，而不是单模内层位移估计的唯一 baseline。

推荐至少比较：

| MWPM 版本 | 目的 |
| --- | --- |
| hard MWPM | 基础传统 baseline |
| static-weight MWPM | 固定噪声模型 |
| adaptive-weight MWPM | 公平比较自适应软信息 |
| oracle-weight MWPM | MWPM 类上界 |

核心表述应是：

> 本方法不声称在所有噪声模型下替代 MWPM；它主张在非平稳、相关、带 analog GKP syndrome 的复杂噪声场中，用 FPGA 友好的方式逼近自适应软信息解码。

## 10. 评价指标

不要只报告 logical error rate。建议至少覆盖：

| 指标 | 作用 |
| --- | --- |
| logical error rate / frame error rate | 主要纠错性能 |
| residual displacement variance | 内层 GKP 解码质量 |
| threshold / pseudo-threshold | 可扩展趋势 |
| latency / throughput | 实时 QEC 关键指标 |
| FPGA LUT / FF / DSP / BRAM | 可部署性 |
| fixed-point bitwidth sweep | 排除浮点幻觉 |
| stale-parameter penalty | 慢回路延迟影响 |
| train/test noise mismatch | 泛化能力 |
| drift / burst / correlated noise | 证明自适应必要性 |

## 11. 论文叙事建议

建议按以下顺序组织：

1. 先说明 `K s + b` 是 GKP syndrome-informed displacement 的局部线性 / LMMSE 形式。
2. 再说明近似 GKP、有限能量、测量噪声和硬件漂移会改变最优 `K,b`。
3. 提出慢回路 CNN 预测 `Delta K, Delta b`，快回路 FPGA 执行仿射估计。
4. 用 fixed `K,b`、统计自适应、oracle linear、MMSE / nearest-lattice、MWPM 类方法做分层比较。
5. 最后强调性能-延迟-资源折中，而不是宣称超过 oracle MMSE / ML。

一句话版本：

> 该方法用 CNN 在慢时间尺度上估计当前有效噪声通道，并把实时 GKP correction 压缩为 FPGA 可执行的仿射 syndrome-informed displacement；它的目标是在复杂漂移噪声下接近 oracle linear decoder，同时保持确定低延迟。
