\section*{Evidence Boundary of This Note}

This note is a theory-facing draft for the front matter of a future paper. It
does not claim real-board validation, true \texttt{.tflite} runtime validation,
or paper-grade expanded benchmark completion. The current validated execution
boundary remains mock-backed software HIL with \texttt{artifact\_npz} and
\texttt{inproc} inference for the recovered paths. Existing frozen-set evidence
supports a bounded software revalidation claim, while the post-T55 mechanism
story remains partial and should not be written as causal closure.

\begin{abstract}
Approximate Gottesman--Kitaev--Preskill (GKP) quantum error correction relies on
continuous-valued syndrome information to infer displacement errors in an
oscillator. In nonstationary hardware settings, however, the effective noise
statistics that determine the best syndrome-to-correction map can drift over
time, making a fixed decoder suboptimal. This note outlines a two-timescale
decoding framework in which a low-latency fast loop applies an FPGA-friendly
affine correction, while a slower learned calibration loop updates the affine
parameters from recent syndrome statistics. The fast loop executes
\(\Delta_t = K_t s_t + b_t\), where \(s_t\) is the current GKP syndrome and
\((K_t,b_t)\) are quantized runtime parameters. The slow loop uses a classical
teacher estimator as a stable anchor and trains a lightweight CNN only to
predict residual calibration terms, with the current mainline focusing on
residual corrections to \(b_t\). This design is motivated by local linear-MMSE
approximations to GKP displacement estimation, by the modular learned-decoder
trend in recent QEC literature, and by the need to keep the real-time path
deterministic and low latency. The intended contribution is not a generic
neural replacement for GKP decoding, but a deployment-constrained, teacher-
anchored residual calibration layer for drift-adaptive GKP correction.
\end{abstract}

\section{Introduction}

Bosonic codes provide a route to protecting quantum information by encoding a
logical qubit into the Hilbert space of an oscillator. Among them, the GKP code
is especially attractive because small displacement errors in phase space can be
diagnosed by continuous-valued modular syndrome measurements
\cite{gkp2001}. In an idealized setting, a decoder can map each syndrome to a
corrective displacement. In realistic devices, however, finite-energy code
states, measurement inefficiency, ancilla noise, drift, and calibration error
make the syndrome distribution time dependent.

This time dependence creates a practical tension. A high-quality decoder may
need to exploit analog soft information and nonstationary noise statistics, as
emphasized in recent GKP and concatenated-GKP decoding work
\cite{noh2022,borah2025,roy2025}. At the same time, real-time quantum error
correction imposes strict latency and determinism requirements. Recent surface-
code work shows that learned modules can be useful when they are inserted as
local, modular, low-latency components rather than as unconstrained replacements
for the whole decoding stack \cite{chamberland2026}. Hardware-conditioned
decoders and decoder-prior optimization further suggest that slow calibration
signals and hardware statistics can be exploited to improve fast decoding
decisions \cite{stein2026,sivak2024}.

The central idea of this project is to apply that systems principle to
drift-adaptive GKP decoding. The proposed decoder separates the problem into two
timescales. The fast loop is deliberately simple: it performs an affine
syndrome-informed displacement estimate,
\begin{equation}
    \Delta_t = K_t s_t + b_t ,
\end{equation}
using fixed-point arithmetic and a double-buffered parameter bank. The slow loop
observes recent syndrome histograms, estimates the current effective noise
state, and updates \((K_t,b_t)\) at a much lower rate. Instead of asking the CNN
to learn the entire decoder from scratch, the current mainline keeps a
classical teacher as the baseline estimator and learns only a residual
calibration term.

This framing is intentionally narrower than ``a neural GKP decoder.'' The
method should be understood as a teacher-anchored residual calibration layer for
a runtime-constrained affine GKP fast path. That narrower claim is both more
faithful to the current implementation and better aligned with the strongest
nearby literature.

\section{Summary of Contributions}

The target paper can be positioned around four contributions.

\paragraph{1. A two-timescale adaptive affine formulation for approximate GKP
decoding.}
We formulate the real-time correction path as an affine estimator
\(\Delta_t=K_t s_t+b_t\) whose parameters are adapted from recent syndrome
statistics. This links the GKP continuous-syndrome picture to a hardware-
compatible runtime contract: the expensive inference problem is moved out of the
per-shot path, while the fast loop remains a quantized matrix-vector operation.

\paragraph{2. A teacher-anchored residual calibration strategy.}
Rather than train a CNN to output all noise parameters or all decoder parameters
directly, the mainline uses a classical teacher estimator to produce a stable
baseline \((K_t^{\rm teacher},b_t^{\rm teacher})\). The learned model predicts a
small residual, currently
\begin{equation}
    \delta b_t = f_\phi(H_{t-c+1:t},\Delta H_t,z_t^{\rm teacher}),
\end{equation}
and the runtime uses
\begin{equation}
    K_t = K_t^{\rm teacher}, \qquad
    b_t = {\rm EMA}\!\left(b_t^{\rm teacher}+\delta b_t\right).
\end{equation}
This design treats the learned module as a calibration layer, not as a full
decoder replacement.

\paragraph{3. A deployment-aware runtime architecture.}
The architecture maps naturally onto a fast/slow implementation. The fast loop
uses fixed-point arithmetic, clipping, saturation diagnostics, and a staged
parameter bank. The slow loop consumes 32-by-32 syndrome histograms, teacher
features, and histogram deltas, then writes new parameters through a
stage-and-commit interface. This makes latency, stale-parameter effects,
overflow, and commit behavior first-class evaluation objects.

\paragraph{4. A bounded evidence protocol for software-HIL evaluation.}
The current repository supports a recovered mock-backed software-HIL path and a
frozen-set formal software revalidation. These results should be reported with
their exact boundary: they support software-level comparison under the frozen
scenario/mode set, but they do not yet constitute true \texttt{.tflite} runtime
validation, real-board validation, or an expanded paper-grade benchmark. A
future full paper should add stronger comparator lanes, unseen drift families,
runtime deployment checks, and mechanism-hedged ablation tables before making
broader claims.

\section{Brief Review of the GKP Code}

\subsection{Ideal and approximate code states}

The GKP code encodes a qubit into an oscillator by arranging logical code states
as periodic combs in phase space \cite{gkp2001}. In the convention used by this
project, the lattice constant is
\begin{equation}
    \lambda=\sqrt{2\pi}.
\end{equation}
An ideal logical state may be represented heuristically as an infinite comb,
for example
\begin{equation}
    |\bar 0\rangle \propto \sum_{n\in\mathbb{Z}} |n\lambda\rangle_q .
\end{equation}
Physical GKP states must be approximate finite-energy states, so the comb peaks
are broadened and enveloped. This finite-energy structure is not a detail: it
sets an intrinsic noise floor and affects the syndrome statistics seen by the
decoder.

\subsection{Syndrome measurement as modular displacement information}

Let the accumulated phase-space displacement error before correction be
\begin{equation}
    e_t=\begin{bmatrix}e_{q,t}\\ e_{p,t}\end{bmatrix}.
\end{equation}
An ideal GKP syndrome measures this displacement modulo the lattice:
\begin{equation}
    s_t = e_t \bmod \lambda,
    \qquad
    s_{q,t},s_{p,t}\in[-\lambda/2,\lambda/2).
\end{equation}
Real measurements add finite-squeezing, inefficiency, shot, and ancilla
contributions. The measured syndrome is better viewed as
\begin{equation}
    \tilde{s}_t = {\rm mod}(e_t,\lambda)+\eta_t^{\rm meas}.
\end{equation}
Thus the decoder does not observe the absolute displacement; it observes a
noisy modular representative of that displacement.

\subsection{Local affine decoding and its limits}

The modulo structure makes exact GKP decoding nonlinear and branch dependent.
Within a local branch and under a Gaussian approximation, however, the error
\(e\) and syndrome \(s\) can be treated as jointly Gaussian:
\begin{equation}
\begin{bmatrix}e\\s\end{bmatrix}
\sim
\mathcal{N}
\left(
\begin{bmatrix}\mu_e\\\mu_s\end{bmatrix},
\begin{bmatrix}
\Sigma_{ee} & \Sigma_{es}\\
\Sigma_{se} & \Sigma_{ss}
\end{bmatrix}
\right).
\end{equation}
The linear-MMSE estimate is then
\begin{equation}
    \hat e
    =
    \mu_e+\Sigma_{es}\Sigma_{ss}^{-1}(s-\mu_s)
    =
    Ks+b,
\end{equation}
where
\begin{equation}
    K=\Sigma_{es}\Sigma_{ss}^{-1},
    \qquad
    b=\mu_e-K\mu_s.
\end{equation}
This explains why the affine form is a reasonable fast-path approximation.
It also explains its limitation: near lattice decision boundaries, the posterior
may be multimodal, and a single global affine estimator may average over
branches. The proposed architecture therefore does not claim Bayes-optimal GKP
decoding; it seeks a low-latency adaptive approximation.

\subsection{Logical failure criterion}

After applying a correction, the residual displacement is wrapped back into the
GKP fundamental cell. A logical error occurs when the residual crosses the
logical decision boundary, for example
\begin{equation}
    |r_{q,t}|>\lambda/2 \quad \Rightarrow \quad X_L\ {\rm error},
\end{equation}
and similarly for the \(p\)-quadrature. This is why closed-loop logical error
rate is a stronger evaluation target than offline parameter-regression error.

\section{Model Architecture}

\subsection{Fast loop: affine fixed-point decoder}

The fast loop receives the current measured syndrome \(s_t\) and reads the
active parameter bank. Its runtime computation is
\begin{equation}
    s_t^{\rm clip}={\rm clip}(s_t,-s_{\max},s_{\max}),
\end{equation}
\begin{equation}
    \Delta_t^{\rm raw}=K_t s_t^{\rm clip}+b_t,
\end{equation}
\begin{equation}
    \Delta_t=Q\!\left({\rm clip}(\Delta_t^{\rm raw},
    -\Delta_{\max},\Delta_{\max})\right),
\end{equation}
where \(Q(\cdot)\) denotes fixed-point quantization. The project convention is
an FPGA-oriented Q4.20 representation for syndrome values and runtime
parameters. The fast loop also accumulates syndrome histograms and records
diagnostics such as histogram-input saturation, correction saturation, and
aggressive-parameter events.

\subsection{Effective noise state and parameter mapping}

The slow loop models the current noise condition by a low-dimensional effective
state
\begin{equation}
    \theta_t^{\rm noise}
    =
    (\sigma_t,\mu_{q,t},\mu_{p,t},\vartheta_t).
\end{equation}
Given an estimate of this state, the parameter mapper constructs an error
covariance
\begin{equation}
    C =
    R(\vartheta)
    \begin{bmatrix}
        \sigma_q^2 & 0\\
        0 & \sigma_p^2
    \end{bmatrix}
    R(\vartheta)^\top ,
\end{equation}
and a measurement covariance
\begin{equation}
    R_{\rm meas}=(\sigma_{\rm meas}^2+\Delta_{\rm eff}^2)I.
\end{equation}
The raw gain is
\begin{equation}
    K_{\rm raw}=C(C+R_{\rm meas})^{-1},
\end{equation}
followed by eigenvalue clipping and optional gain scaling. The bias target is
\begin{equation}
    b_{\rm target}=\alpha(I-K_{\rm target})\mu,
    \qquad
    \mu=\begin{bmatrix}\mu_q\\\mu_p\end{bmatrix}.
\end{equation}
Finally, exponential smoothing produces the staged runtime parameters:
\begin{equation}
    K_t=(1-\beta)K_{t-1}+\beta K_{\rm target},
    \qquad
    b_t=(1-\beta)b_{t-1}+\beta b_{\rm target}.
\end{equation}

\subsection{Teacher estimators}

The teacher family provides stable, interpretable estimates of
\(\theta_t^{\rm noise}\) from recent syndrome history. The simplest teacher
computes first- and second-order moments from the histogram window. Stronger
teachers such as EKF, UKF, RLS, or particle-filter variants add a state-space
prior over time. Abstractly,
\begin{equation}
    \hat{\theta}_t^{\rm teacher}
    =
    {\rm Teacher}(H_{1:t}),
\end{equation}
and
\begin{equation}
    (K_t^{\rm teacher},b_t^{\rm teacher})
    =
    {\rm ParamMapper}(\hat{\theta}_t^{\rm teacher}).
\end{equation}
The teacher is not a rhetorical device; it is the stability anchor that prevents
the learned module from becoming an unconstrained decoder.

\subsection{CNN residual branch}

The CNN consumes a short context of normalized syndrome histograms and histogram
deltas:
\begin{equation}
    X_t^{\rm hist}=[H_{t-c+1},\ldots,H_t,\Delta H_{t-c+2},\ldots,\Delta H_t].
\end{equation}
Teacher-side features are represented as
\begin{equation}
    z_t^{\rm teacher}
    =
    (\hat{\theta}_t^{\rm teacher},
     K_t^{\rm teacher},
     b_t^{\rm teacher},
     \Delta b_t^{\rm teacher},\ldots),
\end{equation}
although the current gated branch narrows this to a small set of teacher-\(b\)
and teacher-\(\Delta b\) scalars. The learned branch predicts
\begin{equation}
    \widehat{\delta b}_t
    =
    f_\phi(X_t^{\rm hist},z_t^{\rm teacher}),
\end{equation}
then clips the result:
\begin{equation}
    \delta b_t
    =
    {\rm clip}(s_b\widehat{\delta b}_t,-b_{\max},b_{\max}).
\end{equation}
The committed parameter is
\begin{equation}
    K_t=K_t^{\rm teacher},
    \qquad
    b_t={\rm EMA}(b_t^{\rm teacher}+\delta b_t).
\end{equation}
The residual formulation is important: it makes the CNN responsible for a
small deployment-relevant correction rather than for the full GKP decoding
problem.

\subsection{Stage-and-commit runtime contract}

The slow loop does not directly mutate the active fast-loop parameters. It
stages a candidate \((K,b)\) into an inactive bank and commits it at a safe
epoch boundary:
\begin{equation}
(K_t,b_t)=
\begin{cases}
(K^A,b^A), & t<t_{\rm commit},\\
(K^B,b^B), & t\ge t_{\rm commit}.
\end{cases}
\end{equation}
This contract is central to the deployment story. It allows the paper to
evaluate not only logical error rate, but also update latency, stale-parameter
effects, commit success, rollback/fallback behavior, and fixed-point stability.

\section{Current Evidence Status and Near-Term Paper Plan}

The current safe result story is bounded. The repository supports a recovered
mock-backed software-HIL path and a frozen four-scenario, five-mode software
revalidation in which \texttt{hybrid\_\-residual\_\-b} ranks first within that
frozen set. The claim must remain tied to that frozen set and to the software
HIL boundary. It should not be generalized to true \texttt{.tflite}, real-board
HIL, or a broad state-of-the-art comparison.

The mechanism story also requires care. Earlier trace analysis suggested that
committed-\(b\) amplitude and residual clipping were involved in seed-dependent
Gated-v5 behavior. The T55 lower-clip intervention, however, was mixed and
mostly harmful across the locked six-seed pack. Therefore the correct paper
wording is not that ``large committed \(b\) is the root cause.'' A safer
statement is that the learned residual branch can enter seed- and scenario-
dependent high-amplitude regimes whose effect is not captured by a simple
monotonic amplitude explanation.

Before a full submission, the most important additions are:
\begin{enumerate}
    \item a benchmark expansion lane that keeps the frozen-set anchor but adds
    unseen drift families and stronger calibration/statistical baselines;
    \item a mechanism table that distinguishes retained, weakened, retired, and
    still-open hypotheses after T55;
    \item true runtime-boundary evidence for \texttt{.tflite} if the dependency
    environment becomes available;
    \item fixed-point and latency evidence that treats deployment constraints as
    measured quantities rather than prose assumptions.
\end{enumerate}
