# Protocol Documents

本目录保存未来执行任务前必须遵守或引用的 protocol / gate 文档。

## 子目录

| 子目录 | 内容 |
| --- | --- |
| `benchmark/` | P4 benchmark development/formal protocol and paper benchmark expansion protocol |

## 使用规则

Protocol 文档定义边界和执行前置条件；它们不是执行结果本身。任何新 benchmark、扩展矩阵、baseline 集合或 stopping rule 都必须先任务化并经过 review。
