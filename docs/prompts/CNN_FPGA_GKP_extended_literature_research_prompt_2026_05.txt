一、项目背景

项目名：DriftAdaptiveQEC

当前研究主题：

面向近似 Gottesman-Kitaev-Preskill（GKP）量子纠错中的非平稳噪声漂移，构建一套 teacher-anchored residual calibration 的双时间尺度解码框架。

当前最核心的技术形式：

1. 快回路 fast loop
   - 运行在 FPGA / FPGA-like runtime 侧。
   - 每个 fast cycle 接收 GKP syndrome `s_t = (s_q, s_p)`。
   - 执行低延迟仿射校正：
     `Delta_t = K_t s_t + b_t`
   - 强调 fixed-point、低延迟、确定性、clip/saturation 诊断、双缓冲 parameter bank、stage-and-commit。

2. 慢回路 slow loop
   - 周期性读取最近窗口的 syndrome histogram。
   - 典型输入是多窗口 `32 x 32` histogram、histogram delta、teacher 估计和少量 scalar features。
   - 输出用于更新 fast loop 真正消费的 runtime parameters，当前主线聚焦 `b_t` 的 residual correction。

3. teacher-anchored residual calibration
   - 不把 CNN 作为完整 GKP decoder 的替代品。
   - 保留经典 teacher / estimator 作为稳定锚点，例如 window variance、EKF/UKF/RLS 类估计器。
   - CNN 只学习对 runtime control bias `b` 的残差修正：
     `b_next = teacher_b + delta_b`
   - 目标是让 learned module 成为硬件友好的 residual calibrator，而不是无约束 black-box decoder。

4. 当前证据边界
   - 已有的是 mock-backed software HIL 和 frozen-set software revalidation。
   - 不要默认已有真实 FPGA board validation。
   - 不要默认已有真实 `.tflite` runtime validation。
   - 不要把 software smoke、mock HIL 或历史 run 写成真实板级完成。
   - 当前机制解释仍需 hedge：T55 后不能简单写成“high committed-b is harmful”的单调因果故事。

二、请重点围绕的调研目标

目标 1：扩展相关工作谱系

请不仅查“GKP + neural decoder”，还要稍微放宽范围，覆盖所有与本项目背景和技术原理贴近的方向：

1. GKP / bosonic codes / continuous-variable QEC
   - GKP encoding、finite squeezing、shift-error decoding、analog syndrome information。
   - surface-GKP、concatenated GKP-surface、GKP-QLDPC、cat/binomial/GKP bosonic code。
   - noisy auxiliary states、circuit-level GKP soft information、多模 GKP decoding。

2. soft information decoding
   - GKP analog information decoding。
   - superconducting qubit readout soft information。
   - decoder priors、LLR、measurement confidence、calibration-conditioned decoding。
   - 如何把 continuous measurement / confidence 传给外层 decoder。

3. learning-assisted QEC decoders
   - CNN / RNN / transformer / graph neural decoder。
   - neural pre-decoder、neural MWPM、learned edge weights、learned priors。
   - hybrid classical-neural decoder，而不是纯黑盒 decoder。
   - teacher-guided、residual learning、calibration layer、low-dimensional conditioning、FiLM/gating。

4. drift-adaptive / calibration-aware QEC
   - hardware drift、calibration-conditioned decoder、online prior optimization。
   - reinforcement-learning control of QEC。
   - decoder prior tuning、noise model learning from syndrome statistics。
   - 时间尺度分离：慢校准 / 快解码。

5. real-time / low-latency / FPGA or ASIC QEC
   - FPGA-based neural-network decoder。
   - real-time surface-code QEC。
   - deterministic latency、closed-loop feedback、QEC cycle time。
   - fixed-point、resource budget、hardware/software co-design、HIL protocol。

6. benchmark and evaluation methodology
   - frozen-set benchmark、paired seeds、multi-scenario evaluation。
   - latency, stale update, commit failure, fallback, saturation, overflow。
   - code-capacity vs phenomenological vs circuit-level noise。
   - 如何公平比较 learned decoder 与 classical baseline。
